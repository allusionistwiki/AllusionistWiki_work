# ゆらぎアンテナ

## 概要
「ゆらぎの神話」関連サイトを登録する「ゆらぎアンテナ」に関する案内と運営報告が行われたスレッドです。管理人による募集告知に対し、参加者からポータルへのリンク設定や更新頻度に関する質問が投げかけられました。また、東方Projectのアンテナを模した茶化し投稿や、特定サイト（KIYURA）の管理状況の共有など、コミュニティ内での雑談と実務的な報告が混在しています。

## 流れ
g000 で管理人がゆらぎアンテナへの自薦・他薦を呼びかけ、g001 で参加者がポータルからのリンク有無を質問しました。これに対し g002 で「うとさん」による整理の可能性が示唆されました。g003 と g004 では、募集の煽り揚げや東方名産のアンテナ調理を模した茶化し投稿でスレッドが賑わい、g005 でからすとうさぎが KIYURA の URL 変更と管理状況を報告しました。最後に g006 から g008 にかけて、更新されないサイト（ゼノフィリア）の上位表示対策について議論され、からすとうさぎによる試みとそれへの感謝で締めくくられています。

## 主要な話題・設定
【ゆらぎアンテナ】は「ゆらぎの神話」に関するあらゆるサイトを登録する場所であり、自薦・他薦を問わず募集が行われている。【ポータル】へのリンク貼付については、「うとさん」による整理作業が関与している可能性がある。東方Project の【アンテナ】を料理に例えた茶化し投稿（煮込み、油揚げ）が見られる。サイト【KIYURA】の URL が変更され、からすとうさぎが管理していることが報告された。更新されないサイト【ゼノフィリア】の上位表示対策として、からすとうさぎが何かを試みている。
