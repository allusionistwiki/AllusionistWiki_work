# 死せる森のキュトス上演化

- 掲載文脈: 記述投稿で月秀がラダムストンのキュトスを上演化する。

**312** 月秀 2008-10-19T16:19:00+09:00 [#312](https://allusionistwiki.github.io/YuragiWiki/full/YJ-M2706511/p4#post-312)

「ラダムストン先生」
「ん？なんだい？」
「読ませていただきましたよ、《死せる森のキュトス》」
「おぉ、それはありがたい。で、どうだったかな？感想は？」
「演りましょう」
「……え？」
「知り合いに風梨何(フリカ)という劇団を主宰している男がいます。そいつにやらせましょう」
「えーと……舞台にする、ってこと？」
「そうです。ロングラン間違いありません」
「君がそう言うならねぇ……まあ、やってみようか」


斯くして、初回公演以来長きにわたり人々の感動を誘い、今尚喝采を浴び続ける伝説の舞台《死せる森のキュトス》は、一人の戯曲作家とやや強引なその助手から始まった。





「ってのはどう？」
「だからお前独り舞台って言われんだよ」
