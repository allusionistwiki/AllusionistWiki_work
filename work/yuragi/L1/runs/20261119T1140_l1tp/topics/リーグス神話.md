# リーグス神話

## 概要
『リーグス神話』はケイナズ地方を基盤とする神話体系である。紀元神群や精霊を実在の人物とみなし、その子孫が同地方の王族・豪族であると主張する「神人説」に類する性質を持つ。神国ディスカレイリーグの聖なる勢力と魔族との争いが主軸をなす。アルセス教の成立以前から存在した現地伝承の影響を受け、後にアルセス教神話と融合して成立した経緯がある。

## 主要な設定
*   **地域と起源**: ケイナズ地方の神話体系。ワリバーヤ王朝以前からの現地伝承が、後に国教となったアルセス教神話の影響を受けることで成立した。
*   **世界観**: 紀元神群や精霊を実在の人物と見なし、それらの子孫がケイナズ地方の王族・豪族であるとする「神人説」に類する。
*   **宇宙論**: 死後昇天したディスカレイル王が天上に建てた【神国ディスカレイリーグ】を原型とし、地上のディスカレイリーグで起こる事柄は天上の神国でのそれと密接に結びついていると考えられている。
*   **主要な対立軸**: 神国ディスカレイリーグの聖なる勢力と魔族との争い。
*   **元魔（げんま）**: 火、風、水、地などの属性を持つ存在が「元魔」と呼ばれる。
    *   **メクセト**: 炎の元魔。「十八魔族」の名前の由来となる。群れをつくる性質ではないとされる。
    *   **ゼルディーオ**: 風の元魔。かつて珠の中の虜囚であり、騎士を乗っ取ってレストロオセの騎士となった。四十四騎士の中でも強者。
    *   **メレキウス**: 水の元魔。魔人メクセトの異母妹でリク＝テロテ＝キュラッタの娘。膨大な量の水（洪水・津波）の形をとる。
    *   **ギガマル**: 地の元魔。第一次地獄開放事件の際、過ちを悔いて「南方の草原の勇者」に協力し鎮圧を成功させた。憔悴しきっている。
*   **関連する宗教・宗派**:
    *   **リーグシル派**: アルセス教の宗派の一つ。アルセス教典とリーグス神話文書、宗祖リーグシルの著作を聖典とする。他宗教を邪教、他宗派を邪宗とする。
    *   **ソリス派**: アルセス教の宗派の一つ。リーグス神話を教義にとりいれていない非リーグス系。ヘレゼクシュでリーグス神話成立前に国外進出しており、アルセミットの国教となっている。
    *   **ムベイル教**: リーグス神話における【火の元魔】を崇拝する拝火教。開祖はアリーヴィタ。
*   **文献**: 【天上の神国ディスカレイリーグの年代記】、【地上の王都ディスカレイリーグの年代記】。
*   **分類**: 三角大福仮説において「福」カテゴリに分類される。
