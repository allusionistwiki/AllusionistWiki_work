# 救世主（ゆらぎの神話）

## 概要
『ゆらぎの神話』における「救世主」は、単なる宗教的・神話的な英雄像にとどまらず、多層的な意味を内包する概念として描かれている。世界を維持する神格化された存在や終末に現れる予言者としての側面がある一方、「偽りの救世主」の量産、業界構造における競争対象、あるいは「偶像（アイドル）」への置換といったメタフィクショナルな要素を含む設定も散見される。また、グノーシス世界観に基づく「最も不幸な存在」としての定義や、人類の尊厳を神に依存しないための対概念としての言及も含まれる。

## 主要な設定
*   **神器**: 「神滅ぼしの槍」の一つに【救世主の聖槍】が存在する。公に保管されているものは偽物であり、真物は特定の組織に保管されているという噂がある（YJ-T001）。
*   **儀式・合成**: 【世界樹】と【生命の木】に【知恵の戦神】と【救世主】を重ね合わせ、神の【永遠の生命】を【黄金の果実】として奪い取ろうとする試みがある（YJ-T001）。
*   **偽りの救世主**: 真なる救世主の到来を人工的に引き起こすため、十二人の「偽りの救世主」（ダミー・メサイア）が創り出された。また、十三人の【偽救世主】（デミ・メサイア）も存在する（YJ-T026, YJ-T031）。
*   **終末の化身との対立**: 終末の化身であるコルセスカを消そうとした存在の中に「救世主」が含まれている。彼女を消すことは無駄であり、彼女は世界の終わりを告げるものとして存在し続ける（YJ-T023）。
*   **人類の尊厳**: 人類の尊厳は神にも王にも救世主にもいかなる指導者に対しても保証を頼ってはならないと考えられている。人は己と拠って立つ法にのみ従うべきである（YJ-T023）。
*   **グノーシス定義**: 救世主は地上で最も不幸な者として降り立つ。世界を作った者の定めであり、意識信仰の罰として「意識の無い神」となった存在でもある（YJ-T029）。
*   **業界構造**: 「救世主業界」が存在し、ライバルを乗り越え生き延びていく競争社会である。世界の維持神と習合した黒き英雄や神格化された預言者が大きな影響力を持つ（YJ-T031）。
*   **解体の概念**: 「救世主を解体するための救世主」という概念が存在する（YJ-T031）。
*   **イースターとの関連**: サクソンの女神エオストレの名が訛った「イースター」は、東より伝来した他宗教の救世主の復活祭の呼び名となった（YJ-T031）。
*   **終末の予言**: 世界の終末に現れる救世主として「エアル・バクスチュアル・オー」が世界各地で予言されている。これは自らの土地を礼賛するために歪められた形である場合が多い（YJ-T039）。
