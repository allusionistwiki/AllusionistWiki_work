# 最大神（チュ・ク・ワイ）

## 概要
『ゆらぎの神話』におけるチュ・ク・ワイの神話世界に存在する、秩序の外側にいる「ただただ強大な神」。世界の始まりにおいて最高神を生み出した起源的な存在であり、既存のルールや序列には加わらない。人前に顕現する際は、その強大な力を「美しさ」に変換するため少女の姿をとる。

## 記述の流れ
スレッド YJ-T022 において、「言理の妖精」による語りとして登場する。
まず [YJ-T022:697] で最高神との対比を通じて、最大神が「統括者ではなく強大な存在であり秩序に属さない」と定義される。[YJ-T022:698] では、これを縛る秩序も絡め取る混沌も存在しないことが述べられ、[YJ-T022:699] で「最も小さな神には勝てない」という逸脱がルールの外側にある証明とされる。
起源については [YJ-T022:700] で語られ、最大神が自らの角を折り投げたことで最高神が生まれ、そこから他の神々が湧出したとされる。対抗概念として最小神の存在も言及される（[YJ-T022:701]）。
顕現形態については [YJ-T022:705] と [YJ-T022:706] で詳しく描写され、少女姿であり孔雀（アナスズメ）を従えることが記される。
