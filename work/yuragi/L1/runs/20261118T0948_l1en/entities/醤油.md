# 醤油（ゆらぎの神話）

## 概要
『ゆらぎの神話』における「醤油」は、単なる調味料ではなく、世界観を規定する根源的な要素として描かれる。类型: 物品・武具 の観点では、初期には食文化や生物学的処理（オスの【かき】の下処理など）に関わる「物品」として登場するが、物語の進行に伴い、その性質は劇的に変化する。特に YJ-T030 以降では、科学燃料としての側面が強調され、兵器「オルガンローデ」の動力源となる「武具・エネルギー資源」としての地位を確立する。さらに、宇宙論的な文脈では「物質の性質（味）を変える力」と定義され、物理法則そのものを支配する概念へと昇華している。

## 記述の流れ
醤油はスレッド YJ-T003 で、生物学的な処理工程や食品製造の材料として最初に登場する。オスの【かき】を食用にするための漬け込み液（YJ-T003:220）や、スタンドヘッドの毛と信号機を煮込んで「亜豆腐」を作る際の添加物（YJ-T003:252）、そして巨大豆の木との関連性（YJ-T003:378）が語られる。

YJ-T005 では、シュガーハット君の生成過程において「体を固める」ための材料として言及される（YJ-T005:143）。

YJ-T012 では、醤油が「失われた化石燃料」として位置づけられ、その枯渇による恐慌と、それに代わる「死者の水戻し」技術への移行が歴史的事実として記述される。

YJ-T015 と YJ-T019 では、納豆との対比や神話的起源（血液を調味料とする神話）の中で醤油の存在意義が論じられる。

転機は YJ-T030 である。ここで「納豆、豆腐、味噌の三元力」に対する第四の概念として再定義され、「科学燃料」としての性質が明示される。飲むと毒であるという警告や、オルガンローデ（機械）の動力源としての高性能化（YJ-T030:32-35）が語られ、味噌との対比の中で「メカとの相性」が強調される。

YJ-T064 では、醤油は「物質の性質すなわち味を変えること出来る力」として、豆腐力、味噌力と並ぶ基本力のひとつとして記述され、その希少性と影響力が説かれる。

## 関連する实体
*   **納豆**：醤油と最も頻繁に対比される存在。「納豆の敵‐対性」や「三元力」の一員として語られる。
*   **味噌**：醤油の対極にある存在。「マジックアイテム」として分類され、初期のオルガンローデの動力源であったが、醤油に取って代わられたとされる。
*   **豆腐 / 亜豆腐**：醤油を用いて作られる食品、または「豆腐力」の関連概念。
*   **オルガンローデ**：醤油を燃料として飛行する機械（メカ）。
*   **【かき】**：オスの個体が醤油と塩に漬けられて処理される生物。
*   **シュガーハット君**：七つの仔山羊の死体から生まれた存在。体を固めるために醤油を用いる。
*   **大豆弾**：醤油恐慌後の時代における懐古コレクション品。
*   **言理の妖精**：これらの記述を行う語り手。
