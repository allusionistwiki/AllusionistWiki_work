# 翼持つ者クロウサー

## 概要
『ゆらぎの神話』に登場する飛来神群の一柱であり、空を統べる女神。天を覆うほどの白い翼と地表を眺める金の眼を持ち、右腕は身長七倍の長さで四つの関節を持つ。左手には黒い帽子を持っている。異界の神群【アウター】や放逐された神群【ヴィジター】から構成される邪神群の第一統率者とされるが、強力な神々が多いため主神としての区別は曖昧である。言語魔術や論術体系を汲む独自の魔術により、光よりも速く飛ぶ権能を持つ。
