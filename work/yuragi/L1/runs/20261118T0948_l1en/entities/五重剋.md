# 五重剋

## 概要
『ゆらぎの神話』に登場する妖刀（物品・武具）。狂鍛冶師・観栄明が走神の滝の麓で五匹の魔性を素手で絞め殺し、その呪われた血を吸わせて作り上げた「恐刀」の一つである。刃は闇よりもなお黒い漆黒の光を放ち、血を吸い取る性質を持つ。七天八刀第五位・伐辰一刀斎の愛刀として知られ、「三ツ狂ノ惨刀」の一員に数えられる。
