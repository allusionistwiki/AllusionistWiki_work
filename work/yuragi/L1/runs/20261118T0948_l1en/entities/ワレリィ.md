# ワレリィ

## 概要
ワレリィは、キュトスの姉妹の十四女（14番目）であり、魔族の一人である。彼女は「扉の暗示」を持つ存在として知られ、宇宙の反対側に通じる【扉】を生み出す能力や、槍を突き立てて世界を作るほどの力を持つ魔王級の実力者として描かれる。また、交通事故を象徴する魔女としても言及される。その性質は多面的であり、ディシルセス派では聖女・巫女としてアレ神に仕える存在とされる一方、ヘレゼクシュでは邪悪な女怪と見なされている。さらに、3Dプリンターでコピーされた個体には自我が芽生えるという特異性も持つ。
