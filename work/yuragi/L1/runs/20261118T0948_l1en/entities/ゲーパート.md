# ゲーパート

## 概要
『ゆらぎの神話』に登場する架空の世界の一つであり、もう一つの世界「キュベルフォウル」と対をなす場所である。大地が砕け散り、広大な世界の上を漂っているという物理的特徴を持ち、浮力によって陸地が浮かんでいるとされる。この世界では「機械神ラクルラール」の秩序が支配しており、住民は飛行機乗りや狼神など、キュベルフォウル側とは異なる役割や性別で存在する者が多い。
