# 竜覚

## 概要
『ゆらぎの神話』における、人間が「創生竜」の力を受け入れ、交信するための潜在能力および状態。竜神信教ではこれを「創世竜の恩寵」として宗教的に尊ぶ一方、アザミ機関では研究対象としての「人の持つ潜在能力の一つ」と捉えている。
この能力を持つ者は「九頭竜の巫女」への適性を持つとされるが、器（身体）の容量が宿す「竜性」を下回った場合、肉体が壊れるリスクがある。また、ヒッポクラトスによる『人』性の書き換えとは全く別の現象であり、「猫」などの紀性を持たない生物には存在しない。
