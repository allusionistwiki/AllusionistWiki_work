# 大地の球化

## 概要
『ゆらぎの神話』において、平たい大地が球形（地球）へと変貌した大規模な現象を指す。単なる地形の変遷にとどまらず、世界の物理法則や地理構造を根底から書き換える「宇宙規模の改変」であった。球化に伴い多くの土地が切り離されて宇宙空間へ放逐されたり地底へ引き込まれたりしたほか、支配者である妖精皇帝エフラスとその領土アヴロニアも天に置き去りにされた（これが後の精月である）。また、大地を支えていた神々や獣たちも追放されるなど、世界全体の勢力図と生態系を激変させた出来事として描かれている。

## 記述の流れ
この現象は複数のスレッドにおいて、歴史背景、地理変化、そしてそれに伴う政治・宗教混乱の文脈で語られている。

*   **起源と目的**: [YJ-T004] では、平たい大地の時代に魔法使いが塔から邪視で世界を支配していたことに対し、妖精王エフラスがその支配を恐れて球化を起こしたという伝承が語られる。[YJ-T037] では、球化後の形が「ドルネスタンルフ」の形に倣ったものであると記述されている。
*   **地理・物理変化**: [YJ-T008] や [YJ-T022] では、大地が丸められたことで世界が狭くなり、人口密度が増加した状況や、散らばった大地が結い合わされる過程が言及される。[YJ-T017] では、球化の際に天へ放り出されたものが「飛来神群」の起源となったことが語られ、[YJ-T022] でも同様に宇宙へ追放された存在たちが記述されている。
*   **地底と切り離された土地**: [YJ-T006] では南東の都市ハルムシオンが大地の果てから切り離され宇宙の彼方へ遠ざけられたことが語られる。[YJ-T017] と [YJ-T029] では、球化により地球内部（地底）に引き込まれた国々（マキコ＝マレタ等）が「詰め物」にされたことへの民草の絶望と、その後の矜持について記述されている。
*   **政治・宗教影響**: [YJ-T008] ではアヴロニアの消失による力の均衡崩壊と難民流入が語られ、[YJ-T021] では球化直後の混沌の中で新興宗教教祖ラドマレルが現れたことが記される。[YJ-T039] ではエフラスに神の力を与えた紀元神群との関係や、アヴロニア島（精月）への追放劇が詳述されている。
*   **戦闘力と影響**: [YJ-T025] では、キュトスの姉妹が球化に伴う巨大な地震エネルギーを中和し被害を抑えたことが語られ、[YJ-T037] ではセルラ・テリスの戦闘力が惑星を丸める程度であり宇宙破壊は不可能であるという記述から、球化のスケール感が示されている。
