# ノウフェイスマンの冒険

## 概要
『ゆらぎの神話』スレッド「ノウフェイスマンの冒険」は、bothhandsが主宰するテキストベースのゲーム実況である。参加者は顔のない男の砂漠旅を体験し、「这って進むか諦めるか」「村か屋敷か」「約束を守るか破るか」といった選択肢で物語を分岐させた。多数決やダイスによる裁定を経て結末が決定され、果樹園での恐怖と追跡というホラーな展開で幕を閉じた。

## 流れ
g000でゲーム開始の告知があり、g002からg009にかけて参加表明が行われた。g010で「顔のない男」の砂漠旅が始まり、g011-017では「這って進むか諦めるか」が議論された。g018で洞窟通過後、g019-024で「村か屋敷か」の選択が行われ、多数決により屋敷へ向かうことが決定した。g025で四季の部屋と禁忌が提示され、g026-034では「女性との約束を守るか破って覗くか」が論争となった。最終的に投票同数となり、g035でダイスによりA（守る）が採用されたが、g039でbothhandsがB（破る）の結末である果樹園での恐怖を補完的に記述し、g040で参加者がその行方を語って終了した。

## 主要な話題・設定
【顔のない男】が主人公であり、砂漠を旅する存在として描かれる。【ゆらぎラジオ放送時】にゲームが開始される。選択肢には【A「参加する」】【B「参加しない】といったメタ的なものから、【這ってでも前へ】【あきらめる】【村】【屋敷】【女性との約束を守る】【覗く】などの物語上の行動が含まれる。【四季の部屋】と【禁忌】が屋敷内の設定として登場し、結末では【果樹園】で【顔付き実】や【顔を奪われる】というホラー要素が提示される。
