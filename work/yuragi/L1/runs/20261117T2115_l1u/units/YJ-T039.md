# 紀人・新しき神に関するスレッド

# 『ゆらぎの神話』(BBS 実況コーパス)

## 概要
このスレッドは「紀人・新しき神」に関する記述を行う場として、エフラスやデーデェイアなど多数の新しき神の伝承が語られている。紀元神群との関係性、坂本による彫刻像の設定、そして墓標船ゲーム説に基づくメタ的な考察が展開された。後半ではナプラサフラスとマロゾロンドの共闘や、簒奪者グレンデルヒを巡る物語が進む。神々の能力値分析や世界構造に関する議論も交わされている。

## 流れ
g000で新しき神の列挙と紀神との比較が行われ、g001からg004にかけてエフラス、レストロオセ、カーズガン、ナプラサフラス、ゲヘナ、レメス、ティーアードゥらの伝記が記述された。g005では紀竜クルエクローキとの珍事が語られる。g006からg012にかけてデーデェイア像と彫刻家坂本に関する設定が深掘りされ、g013以降は空使いリーナや猫殺しの剣などの個別エピソードが続く。g016からg024ではマロゾロンドやアルセスの能力、そしてSix・ピストンズ（デーデェイア）の殲滅技が詳細に描写された。g025以降はカツマやメクセトといったキャラクターの登場と紀人化の仕組みが語られる。g034では最終敵である簒奪者グレンデルヒが登場し、g036からg038にかけてオーの到来を巡る予言と反論が交わされた。g042以降はナプラサフラス・サーガの展開が中心となり、マロゾロンドとの共闘や具象言語の獲得が描かれる。g051以降はペレケテンヌルの逆ピラミッド挑戦へと移り、g056では『退屈をもてあました神々の遊び』に関する記述が見られる。

## 主要な話題・設定
*   **新しき神**: エフラス（妖精皇帝）、呪祖レストロオセ（暴君の妻）、勇神カーズガン（草の民の英雄）、ナプラサフラス（巡礼英雄）、ゲヘナ（流浪集団の祖）、レメス（弓使いの神）、ティーアードゥ（魔導軍将軍）、フリグメルタ、デーデェイア（有翼の大蛸）
*   **紀人・紀神**: 紀元神マロゾロンド、紀元神アルセス、紀仙、紀械神
*   **坂本**: 天賦の彫刻家であり、デーデェイア像を彫り妻の死後に災いを免れる。高速彫法を用いる。
*   **Six・ピストンズ**: デーデェイアの別称。6本の男根と28の睾丸を持つ設定から、六本の槍を二十八連射する殲滅技を持つ。
*   **墓標船ゲーム説**: 神々が物語上の駒へ転落するという考察。上位世界により神を駒として扱う存在が示唆される。
*   **ナプラサフラス・サーガ**: ナプラサフラスとマロゾロンドの共闘、喉笛吹きの館での戦い、具象言語の獲得。
*   **簒奪者グレンデルヒ**: 最終敵として登場し、紀元槍を通じて紀人化を促す存在。
