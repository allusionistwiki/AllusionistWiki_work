# 納豆・豆腐・味噌スレッド

# 『ゆらぎの神話』納豆・豆腐・味噌スレッド

## 概要
このスレッドでは、納豆・豆腐・味噌を「神」として崇める独特な世界観が語られています。紀納豆や生体豆腐といった特異な生物学的設定に加え、紫衣のメクセトによる神々の捕食と『一者』再出現の企みが描かれました。また、イークィ・ノークィスなどの魔術師や、高麗牛蒡を世界の軸とする地理的記述も展開されています。

## 流れ
g000 で納豆・豆腐・味噌の生態と「紀納豆」の存在が定義され、g001-g002 では「おやすみ豆腐」「めざまし豆腐」という生体豆腐の機能性が紹介されました。g003 で神々の関係性（飛来神群との対立・友好）が示された後、g004 で紫衣のメクセトが神々を喰い『一者』出現を狙う動機が語られます。g005 では「魔人＝メクセト」の辞書的定着への批判が入りました。
g006-g009 では紀大豆を秘宝とするナットゥー、アルス・アルトゥール、人体爆弾を使うイークィ・ノークィスといったキャラクター設定が深掘りされました。g010 で醤油の燃料化と神々の争い（ルウフェウス伝）が語られ、g011-g012 では高麗牛蒡を納豆神の本拠・世界の軸とする記述で締めくくられています。

## 主要な話題・設定
*   **紀納豆**: 唾液で溶ける性質を持つ糸を持ち、高齢者には辛い食材として言及される。
*   **おやすみ豆腐 / めざまし豆腐**: 疲労回復や寝坊解消効果のある生体豆腐。併用で効能1.8倍。
*   **紫衣のメクセト**: 神々を喰い体内で一つに還すことで『一者』出現を狙う魔人。
*   **イークィ・ノークィス**: 人体を爆弾に変える納豆魔術師。弱点は人体限定であること。
*   **高麗牛蒡**: 納豆根とも称され、納豆神の本拠および世界の軸とされる。
