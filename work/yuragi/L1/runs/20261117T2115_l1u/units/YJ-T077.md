# もぅ今日で人生終わった！！

## 概要
「もぅ今日で人生終わった！！」というスレッドにおいて、借金の完済を機に新たな人生の始まりを宣言する投稿から始まった。その後、「ウツセミサービス」という死後の擬人化・アーカイブサービスの宣伝や、神格化（アセンション）に関する哲学的な記述が展開された。さらに、生々しい日記サイトへのリンク共有や掲示板の動作確認など、実況的な要素も混在している。スプーキーエンデバーというキャラクターの紹介と、その背景にある「掃除屋」や「死神」といった設定が語られている。

## 流れ
g000 では、言理の妖精語りて曰く氏が借金の完済を報告し、「グレンデルヒ」ことスプーキーエンデバーという市公認の掃除屋（実質的な死神）の設定を紹介した。g001 でどっぺる氏による「ウツセミサービス」の擬人化プラン広告が投稿され、死後の維持再現について案内された。g002 と g003 では無名および空飛ぶ魔王軍艦氏がテストや借用の挨拶を行い、g004 でこの子です。氏が日記サイトの衝撃と中毒性を警告しつつ URL を共有した。最後に g005 および g006 で言理の妖精語りて曰く氏がアセンション（次元上昇）と神の純粋な力、そしてラナ信仰やスーパーバーディメイトビップの崩壊について記述している。

## 主要な話題・設定
【スプーキーエンデバー】は HN「グレンデルヒ」であり、市公認の「掃除屋」と呼ばれる存在である。彼は夜を生活時間とし、猥雑な繁華街を餌場とする「公権力で武装した現実の死神」として描かれている。【ウツセミサービス】はソルキレウスヒコ・アーカイバを用いて故人を 99.9999999876％の再現度で維持する擬人化プランを提供するサービスである。【アセンション】は自らの存在階位を高めて神の位まで登りつめることを指す概念であり、神とは知性を持たない純粋な力そのもの（暴風、炸薬、情報処理機構）であったと定義されている。また、【ラナ信仰】や【スーパーバーディメイトビップ】といった用語が記述の中で登場し、崩壊の昔を語る文脈で使用されている。
