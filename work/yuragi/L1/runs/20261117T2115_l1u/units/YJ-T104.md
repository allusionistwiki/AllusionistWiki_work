# キーワード作成用スレッド

## 概要
『ゆらぎの神話』ポータルにおけるキーワード作成用スレッドであり、はてなアカウントを持たない参加者がキーワード案を投稿し、管理者やユーザーがそれを反映させるための場として機能した。メアリー・スー（セラティ）などの用語定義に加え、参加者の名簿登録や信仰表明、外部サイトへのリンク申請など、コミュニティのインフラ整備と交流が同時に行われた。投稿者間の軽妙なやり取りを通じて、名簿の用途確認や古語表記の議論、URL誤りの指摘といった実務的な調整がなされている。

## 流れ
g000 ではキーワード編集の仕様説明と追加依頼が行われ、g001 から g003 にかけて「メアリー・スー」や「相手」といったキーワードの定義と書き直しが試みられた。g004 で管理人が参加者名簿を作成し、g005 から g008 でその用途（スタッフロールか点呼かなど）や多重登録に関する議論が交わされた。g009 から g021 にかけては zeno や UG774、チングらが名簿への登録申請や信仰表明を行い、管理者による反映と確認の応答が続いた。g022 以降は削除投稿が含まれている。

## 主要な話題・設定
【メアリー・スー】はセラティの別称であり、猫の国では一般的な呼び方として記述された。【相手】は「つよくってがんじょうでひきょうでながいき」であり、王さまを石にし姫を牢に閉じ込めるなど世界じゅうの悪を集めた存在と定義され、「えたーならふぉーすう゛りざーど」で倒される設定である。【名簿】は参加者詳細確認と自己満足の為に使われ、多重登録は好ましくないが別人格なら禁止されない。【信仰表明】ではマロゾロンドを名乗る参加者が登場した。
