# 『猫の国』スレッド

## 概要
『猫の国』スレッドは、BBS実況コーパスにおいて「言理の妖精語りて曰く」を筆頭とする投稿者群が展開した、独自の世界観と神話体系を構築する実験的なスレッドである。猫が存在しない「猫の国」を舞台に、岐阜本一家やレムリアンジャーナルといった架空の家族・組織の記述から始まり、クトゥルフ神話やゴエティアを引用した設定が連投された。後半ではアーサー・マクドナルドやプロセスド納豆といった特異な用語が導入され、宇宙史や神々の政治を巡る壮大かつ混沌とした物語が形成されている。

## 流れ
スレッドは g000 で「猫の国に猫がおらず岐阜本一家を記述する」という前提で開始される。g001 から g002 では揚羽醇とサルタケの喧嘩、クラインフィニティ（アザトース）の設定が語られる。g003 から g005 は宮崎純人による質問やミント味・イチゴ味の雑談といった日常風のやり取りが挟まる。g006 から g012 ではヨハン・ヤンセン、アルテマイス、第二・第三ゴエティアといった創作設定と実況風記述が交錯する。g013 で「心羅万象フランベルジュ・サーガ」への批判があり、g014 で岐阜本求輝が捏造慣習を開き直る。g015 から g023 ではモトキじいちゃん、夜明けの敵、ヌアランダーラ、尾村徳太郎などの設定が展開される。g024 から g031 では心羅万象の登場人物案、コルンバ・ジョンソン、猫の根絶現象などが解説される。g033 から g040 ではワレリイやアーサー・マクドナルド、プロセスドチンパンジーが神々に供給される世界観が語られる。g041 から g050 では納豆神由来のネットワーク、エイジ・オブ・カプリコーン、ヴィーナスと猫の国の対比が論じられる。g051 から g059 ではユーヘメール、プロセスド納豆、エルフジュエル、そしてプロセスド種族と神々の争いが記述され、スレッドは壮大な宇宙史へと収束していく。

## 主要な話題・設定
*   **猫の国**: 猫が存在しないカオスな国家。猫の根絶現象や猫の王らの社会が語られる。
*   **岐阜本一家 / レムリアンジャーナル**: 猫の国に記述される架空の家族および組織。ミッタケ失踪後の日々が描かれる。
*   **揚羽醇 / サルタケ**: 国会図書館での漫画破り取り事件に関わる人物。「バーサーカー」を自称する揚羽醇と、占いが得意なサルタケの喧嘩が語られる。
*   **クラインフィニティ**: アザトースの隠語であり、異次元神メビウスゼロのライバル的な超存在。本能のままに活動する動的な存在として位置づけられる。
*   **アーサー・マクドナルド**: プロセスドチンパンジーを神々に供給した人物。エイジ・オブ・カプリコーンや火星出現のジャイアントに対する鉄槌を下す役割を担う。
*   **プロセスド納豆 / プロセスド種族**: 神々が信徒を統御するために用いるもの、および旧人類生き残りの捜索対象となる大豆生命体ナッラー公園に関連する存在。
*   **心羅万象フランベルジュ・サーガ**: 捏造権威付けへの批判対象となった創作設定。登場人物案として両面坊、ウェルキエル、ガムビエルらが解説される。
*   **エイジ・オブ・カプリコーン / エイジ・オブ・パイシーズ**: 神話学隠匿や神々の資本管理、月と火星のテラフォーミングが関わる時代区分。
