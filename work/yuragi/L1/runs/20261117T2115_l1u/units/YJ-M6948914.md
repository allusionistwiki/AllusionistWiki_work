# 第二の神話 記述トピック

## 概要
『ゆらぎの神話』は、mixi上のBBS実況コーパスにおいて展開されたスレッドであり、独自の世界観と神話設定を共有する。メクセトやドゥリグァといった既存の神話要素を引用しつつ、「異世界便利屋」や「紀神」といった作者自作のキャラクター・概念を記述し、相互補完的な形で物語が構築された。実況形式での対話を通じて、哲学的考察と詩的表現が混在する独特なテキスト群が形成されている。

## 流れ
スレッドはg000で人類最古の英雄メクセトの設定提示から始まる。g001では作者の過去作品（メビウスゼロ）への批評が挟まれ、g002-003ではクトゥルー神話や神秘学に基づく神の定義が論じられる。g004以降は「ゲベル」や「異世界便利屋」といった独自設定の詳細な記述と考察が中心となる。g006にはヌアランダーラの実況描写があり、g008-010では呪歌「ガーデニア・レクイエム」やデーデェイアの変貌が語られる。g012-015ではアルセス神への復讐と一族の滅亡という悲劇的展開が描かれ、g017-020では「紀神」と「哲学的ゾンビ」に関する哲学的記述へと移行する。最後にg021-022で詩や紹介文によってスレッドは締めくくられる。

## 主要な話題・設定
*   **メクセト**: 人類最古の英雄。「神に逆らうもの」とされ、天と地の争いで神々を滅ぼしたが軍神ケモスに敗北し、死体は封印された。
*   **ドゥリグァ (Driguha)**: クトゥルー神話の水性邪神。ヨグ＝ソトースの子で、ダゴンの妻ハイドラが必要。顕現体は超巨大なスライム状の渦。
*   **メビウスゼロ / 聖勇**: 作者が小学生時代に考案した異次元神と勇者。無の空間を治める邪神と、それを倒す存在として批判的に語られる。
*   **ゲベル / 異世界便利屋**: 「隙間」に落ち、「鏡映しの賢人」と出会い学んだ人間。「凡才」として「狭間」で得た知識を本にするが、その解釈にはズレがある。
*   **独眼竜スライム**: 作者の小学生時代のモンスター設定。眼帯と刀を持ち、すばやさが高い雑魚敵だが主人公のライバル役。
*   **デーデェイア / キュトス**: デーデェイアがキュトスに祈り醜い大蛸神になる話、およびキュトスを侮辱した男が怪物へ変えられる報復劇。
*   **アルセス / パンゲオンの一族**: 復讐を試みた一族がゲルシェネスで滅ぶ。「エル・ネ・クローザンド」は獣の子宮を意味する。
*   **紀神 / 哲学的ゾンビ**: 「紀神様」を覗く禁忌とプロフィトロールの呪文、および紀神が作った世界におけるシャルマーキヒュの裁き。
