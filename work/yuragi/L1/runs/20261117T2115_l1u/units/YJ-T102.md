# 言語を作ろう

## 概要
『言語を作ろう』スレッドでは、架空の北方帝国で使用される「グラナリア語」の文法や特徴が詳細に解説された。単語連結による命名文化や、指示代名詞「アレ」の地域的な意味の変遷など、世界観に根ざした言語設定が共有されている。また、文字体系であるキューヴェレートや、発音・表記の地域差に関する議論も展開された。

## 流れ
g000 でメアレン語などの参考資料が提示され、g001 から g002 にかけてグラナリア語の語尾変化と単語連結という特徴が入門的に解説された (g001, g002)。g003 では指示代名詞「アレ」の地域差と姓名連結文化が論じられ、g004 で慣用句「猫の額」の意味が定義された (g003, g004)。
g005 から g009 にかけては、グラナリア文字（キューヴェレート）のアルファベット構成やその歴史的変遷、兄弟名・姉妹名の発音と表記の地域差が記述された (g005-g009)。g010 から g012 では「エルト」「ラク」「スール」といった語彙の語源や擬音的起源が議論され、g013 で言語生態系論が抜粋された (g010-g013)。
g014 から g016 にかけてはヌト語語源や接頭語に関する質疑応答が行われ、g017 と g018 で投稿が削除されて終息した (g014-g018)。

## 主要な話題・設定
【グラナリア語】北方帝国のジェニム系で使われる言語。不定動詞の語尾を人称により変化させる（e/en など）。神の名前などに付く「nil/ett」は複数形かつ尊敬語である。最大の特徴は単語連結であり、基本単語を繋げて一つの単語として扱う文化がある。これにより名前は異常に長くなる傾向がある。
【アレ】ale/are/alle などの指示代名詞。ヌト語では気温の単位、メアレンでは神、旧義国圏では情報、セタリム系言語では蛇などを指すなど、地域によって意味が異なる。
【キューヴェレート】グラナリア語におけるアルファベットの呼称。qwertyuiopasdfghjklzxcvbnm の 26 文字から成る。最初の九文字から「キューヴェレート」または「クヴェート」が生じたという記述がある。猫の国からの流入が歴史的に考察されている。
【猫の額】パンゲオン世界の慣用句。「相手の術中にはまること」を意味する。
