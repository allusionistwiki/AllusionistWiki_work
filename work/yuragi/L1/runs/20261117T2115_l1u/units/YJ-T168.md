# 歌曲・歌詞スレ

## 概要
『ゆらぎの神話』は、JBBS の「歌曲・歌詞スレ」において展開された実況コーパスです。当初は魂の奔流を叩きつけるための告知から始まりましたが、言理の妖精語りて曰くによる詩的創作が中心となりました。少女と少年の運命、剣や竜を巡る戦いなど、幻想的な世界観を持つ歌詞が連投されました。一部には二次創作への批判や改稿も含まれており、多様な詩作が共有されたスレッドです。

## 流れ
g000 で歌や歌詞を書く板としての告知が行われました。g001 から g003 は削除投稿が続きます。g004 では言理の妖精語りて曰くが詩の抵触を批判し、二次スレでの投稿を提案しました。g005 から g012 にかけて、「少女と少年」「再会≠再開」「焔竜と銀の少女」など、キャラクターや情景を描いた詩的創作が連投されました。g013 では「騎士と魔女」の終焉を書きつつ、二次創作利用を批判する投稿がありました。g014 で UG774 が詩を投稿し、g015 から g016 にかけて飛行する意識に関する詩とその改稿が行われました。最後に g017 でダンジョンやアルセスなどを題材とした詩が投下されました。

## 主要な話題・設定
「少女と少年-Silverone-」では、錆に覆われた空ろな槍銘 (Corsesca) を持つ少年と、虚ろな葬名 (Corsesca) を持つ少女の巡り会いが描かれました。「再会≠再開-Goldtwo-」には、英雄の刃 (Gramr)、再生の刃 (Nothung)、破壊の刃 (Balmunc) という三本の剣が登場し、黄昏の戦の再開が記述されています。「焔竜と銀の少女-Siroganethree-」では紅き暴君と銀の少女の対峙が描かれました。「崩落の回廊-Goldfour-」には、児神が差し出した優雅な灯 (トーチ) と少年が受け取った誘蛾な灯 (トーチ)、そして茨回廊 (いばらみち) や荒回廊 (あばらみち) が登場します。また、「十一重奏曲-Goldseven-」では神剣と冒険が語られています。
