# 主アルセス（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T111|YJ-T111]]

紀神教では許されない呼称だが、科学を操ることを禁じ創造論を支持する神として言及される。紀神聖教的な解釈では受け入れられる可能性がある。
> 「科学を操ろうとするでない、と主アルセスは言われる。」 [[full/YJ-T111|YJ-061]]
