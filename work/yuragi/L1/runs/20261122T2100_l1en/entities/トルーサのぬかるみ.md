# トルーサのぬかるみ（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T100|YJ-T100]]

バキスタ地方の平原にある足場の悪い湿原地帯。大雨により騎兵が落馬し、戦局に影響を与えた。
> 「あの平原には一箇所ものすごい足場の悪い湿原地帯があってな。

【トルーサのぬかるみ】と呼ばれたそうなんだが、折悪くそこで大雨が降った。」 [[full/YJ-T100|YJ-007]]
