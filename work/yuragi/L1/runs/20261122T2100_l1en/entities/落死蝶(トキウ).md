# 落死蝶（トキウ）（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T058|YJ-T058]]

リクシャマー帝国東部および草原地方の信仰において、肉体から離れた魂に死を告げる存在。告げ忘れた魂は幽霊になる。
> 「落死蝶（トキウ）がその魂に死を告げ、蒼天駆ける馬（ムランカ）がその魂を天にある死者の国に連れて行く、と信じられている。」 [[full/YJ-T058|YJ-T058]]
