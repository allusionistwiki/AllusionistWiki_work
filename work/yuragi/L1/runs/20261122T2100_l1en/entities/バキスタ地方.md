# バキスタ地方（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T017|YJ-T017]]

草の民とリクシャマー帝国の国境周辺地域。「間の土地」を意味する。交易が盛んであったが、後に城塞都市が作られた。
> 「【バキスタ地方】草の民の西方の生活地域とリクシャマー帝国の国境周辺地域。語源はリクシャマー帝国の公用語、および草の民の言葉で「間の土地」」 [[full/YJ-T017|YJ-022]]
