# 金色の繭（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T127|YJ-T127]]

中庭の台座に置かれた、人間の頭部ほどの大きさを持つ奇怪な物体。竜（災厄）が孵化する直前の状態であり、粘性の糸で包まれている。
> 「その中央。急ごしらえの台座の上に、奇怪な繭がある。金色の繭などというものがあるのならば、それは確かに繭であり、しかしながら同時に卵でもあった。」 [[full/YJ-T127|YJ-T127]]
