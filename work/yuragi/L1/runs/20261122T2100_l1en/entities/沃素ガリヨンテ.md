# 沃素ガリヨンテ（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T024|YJ-T024]]

作物や豊穣の神とされるが、地域によって肥沃さの賜物から貧乏神的な役割まで千差万別な実態を持つ。
> 「作物の神、豊穣の神とされることのおおいガリヨンテではあるが、その実態を突き詰めてみるとそのあり方は千差万別であることがわかる。」 [[full/YJ-T024|YJ-139]]
