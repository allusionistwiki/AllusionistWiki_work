# フォルガ（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T100|YJ-T100]]

バキスタ卿の代官が進軍した都市。ハルバンデフの欺瞞作戦により救援に向かった代官軍が壊滅し、最終的に陥落した。
