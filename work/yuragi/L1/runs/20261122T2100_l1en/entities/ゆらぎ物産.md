# ゆらぎ物産（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T083|YJ-T083]]

ムランカ社長が経営する企業。電話対応で「ゆらぎ物産だ」と名乗る。
> 「事務員（眼鏡っ娘、新人、彼氏なし）にプロレス技をかけるムランカ社長。

　そしてそれを脇目に、「せっかく肉人形を手に入れたのに進歩が無いお母さん……」と人形遊びに興じながら毒舌を吐くアンリエッタ。

　まぁ、スレッドが変わってもゆらぎ物産はいつものゆらぎ物産のようです。」 [[full/YJ-T083#post-31|YJ-001:31]]
