# ソーマ島（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T024|YJ-T024]]

ソーマ湖中央に浮かぶ無人島。暴君メクセトが天の階段を建設し、神滅ぼしの武具を作った地と伝承される。
