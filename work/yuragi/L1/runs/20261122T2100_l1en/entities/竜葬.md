# 竜葬（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T058|YJ-T058]]

体を竜に返す、供物とする、竜の力を得るための俗信としての3つの意味を持つ葬儀形態。
> 「竜葬には３つの意味がある。」 [[full/YJ-T058|YJ-T058]]
