# 賢者の岩（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T008|YJ-T008]]

獅子王が異界の知識を得るために利用した場所。都市国家の名前や稲の栽培方法などの知識がここから得られたとされる。
> 「彼らの技で王は【賢者の岩】に込められた異界の知識を手に入れることができた、と伝説は語る。」 [[full/YJ-T008|YJ-014]]
