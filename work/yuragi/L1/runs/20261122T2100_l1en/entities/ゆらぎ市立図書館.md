# ゆらぎ市立図書館（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T169|YJ-T169]]

地上555階、地下777階建ての巨大図書館。本の迷宮のような構造で遭難者が出る。地下にはニリモの花が自生している。
