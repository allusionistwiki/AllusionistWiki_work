# コル・ポニー（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T051|YJ-T051]]

ポニー教の開祖。「第一のポニー」を意味する名を持つ聖者であり、天界から地上へ遣わされたとされる。
> 「コル・ポニーこと[以下数行は塗りつぶされている。] ポニー教の法灯の繁栄はかの教祖の思惑とは違うものであります。」 [[full/YJ-T051|YJ-29]]
