# ピタゴ（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T005|YJ-T005]]

蒸気型呪力精製装置。錆に喰われ朽ちていたが、油を差すことで再稼働し、弾を転がして高圧蒸気を噴出させる機械への信仰の象徴。
