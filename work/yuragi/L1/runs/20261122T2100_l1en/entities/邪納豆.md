# 邪納豆（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T064|YJ-T064]]

強烈な悪臭（シュールストレミング等）を発する納豆の一種。武器にすると粘つきと穢れで相手を行動不能にする。
> 「潰れた邪納豆は周囲にシュールストレミングとクサヤとドリアンを掛けたような１０００パワーの匂いを発揮した。」 [[full/YJ-T064#post-22|YJ-22:22]]
