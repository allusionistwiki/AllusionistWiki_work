# 王蟲（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T054|YJ-T054]]

竜族の一種であり、怒涛の勢いで押し寄せる洪水のような存在。アリの口腔から迸る焼けたタングステンの奔流によって撃退される。
> 「怒涛の勢いで押し寄せる王蟲の洪水を迎え撃つはアリ。あまりにも無謀に思えるその迎撃は王蟲の陣列がアリの口腔から迸る焼けたタングステンの奔流に呑み込まれるまでだ。」 [[full/YJ-T054|YJ-042]]
