# ポニー＝ツインテ戦争（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T051|YJ-T051]]

ポニー派とツインテール派の間で勃発した全面戦争。「ポニー大戦」とも呼ばれる。
> 「後の大惨事ポニー大戦において活躍したのがベンジャミンだ。」 [[full/YJ-T051|YJ-T051]]
