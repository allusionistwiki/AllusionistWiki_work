# るるぽのポニー（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T051|YJ-T051]]

世界三大ポニー巡礼地の一つとされる事件・地名。幼女が純白のポニーに祈りを勧められた場所として名高い。
> 「せせらぎで遊んでいた幼女の目の前に純白のポニーが現れ、ポニーの祈りをするように薦めた。この地の名前をとり、この事件は【るるぽのポニー】として世界に名高い。」 [[full/YJ-T051|YJ-28]]
