# 神跡（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T154|YJ-T154]]

主人公がマロゾロンドと共にたどり着いた場所。大きな館が存在する。
> 「歩み続けてきた君は今【神跡】にいる。途方もない距離をあるき続けた君の目の前に、大きな館が立ちはだかるように存在していた。」 [[full/YJ-T154|YJ-T154]]

主人公がマロゾロンドに付き従い辿り着いた場所。大きな館が存在する地点として描かれている。
> 「神々の伝令マロゾロンドに付き従い、歩み続けてきた君は今【神跡】にいる。」 [[full/YJ-T154|YJ-T154]]
