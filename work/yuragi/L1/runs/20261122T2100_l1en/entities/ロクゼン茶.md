# ロクゼン茶（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

強い甘みを持つ茶で、子供にも好まれる菓子飲料。神々への捧げものや猫が好む飲み物として登場する。
> 「特に強い甘みを持つロクゼン茶は、菓子飲料として子供たちにも好まれている。」 [[full/YJ-T019|YJ-T019]]
