# マロンゾロンド（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T135|YJ-T135]]

単性繁殖で一直線の家系図を持つ大家族の存在。一柱につき一回だけ子を産む。
> 「マロンゾロンドは一柱につき一回だけ子を産みます。(ちなみに単性繁殖です)

つまり連中の家系図を書くと、先祖から子孫までが完全な一直線になるんです。」 [[full/YJ-T135|YJ-003]]

一柱につき一回だけ子を産む単性繁殖の生物で、家系図が一直線になる。最も最初の個体は凄まじく大きいとされる。
> 「実はね、マロンゾロンドは沢山いるんです。

あたくし、連中が列になって歩いてるのを見たから本当です。」 [[full/YJ-T135|YJ-003]]
