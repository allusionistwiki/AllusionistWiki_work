# 聖なるフォース（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

法王が用いる能力。地下のマントルから地核、空中の電離層に至るイオンを操作し、アースクェイクや落雷誘導を行うとされる魔法/超能力体系の一部。
