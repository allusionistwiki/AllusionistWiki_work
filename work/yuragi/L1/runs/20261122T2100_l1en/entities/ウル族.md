# ウル族（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T138|YJ-T138]]

草の民の部族の一つ。騎兵として暴動を扇動し、領主への傭兵提供を通じて軍資金を得る計画に関与する。
> 「彼らこそが草の民の部族のひとつウル族だった。」 [[full/YJ-T138#post-1|YJ-24:1]]
> 「先日、国境を越えて旧叛徒領内へ侵入しようとした草の民はウル族の一群を補足しました。」 [[full/YJ-T138#post-1|YJ-23:1]]

草の民の部族の一つ。騎兵として活動し、暴動扇動者を通じて領主に雇われ、軍資金を得るための工作に利用された。
> 「彼らこそが草の民の部族のひとつウル族だった。ウル族の首領は私に向かってうなずくと金の入った袋を投げて寄越し、命令を一斉、騎兵をともにボヘル市へ向かった。」 [[full/YJ-T138#post-1|YJ-24:1]]
