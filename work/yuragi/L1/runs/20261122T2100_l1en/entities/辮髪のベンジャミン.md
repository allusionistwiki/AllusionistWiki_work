# 辮髪のベンジャミン（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T051|YJ-T051]]

ポニー四天王の一角を狙った人物。「ベンジャミン・ザ・トレイター」とも呼ばれ、真のポニーを追求するあまりあらゆる束髪を憎み、断髪してスキンヘッド（丸禿）へと変化した。
