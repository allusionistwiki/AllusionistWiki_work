# テリス韻（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T164|YJ-T164]]

セラティス詩篇に見られる独特の韻律。極めて無駄のない音数で構成され、当時の詩人に衝撃を与えた。
> 「その韻律の持たせ方は当時のものとは異質であり、極めて無駄の無い音数であったことから当時の詩人達に衝撃を与えた。この独特の韻律をテリス韻と呼ぶ。」 [[full/YJ-T164|YJ-010]]
