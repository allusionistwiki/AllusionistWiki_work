# 亜納豆（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T064|YJ-T064]]

紀納豆の原料となる豆の一つ。ティアテラが食す納豆の種類の一つであり、失敗作は腹を壊す原因となる。
> 「手元に僅かに残った亜納豆に醤油を書け、一粒口に運んだあと、顔をしかめた。」 [[full/YJ-T064#post-22|YJ-22:22]]
