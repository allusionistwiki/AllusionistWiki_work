# 泡虫（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T141|YJ-T141]]

沼に浮く透明な泡に擬態する生物。アメンボなどを捕食し、求愛ダンスでは幾何学的な図形を描いて移動する。
> 「沼には泡虫の群れが浮かんでいた。泡虫は外目には透明な泡としか見えないが、それは自然の光学迷彩というべきものの作用で、沼に浮く泡そっくりの色に擬態しているためだ。」 [[full/YJ-T141#post-1|YJ-006:1]]
