# 天使猫アリエル（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T012|YJ-T012]]

巨大な獅子のような天使猫で、軽乗用車と同程度のサイズを持ち、地上の敵に向けて突進し打ち砕いた。
> 「天使猫アリエルは巨大な獅子のようだった。その重量とサイズは天使猫中でも規格外。

その全身を動かす馬力もまた、並大抵のものではない。」 [[full/YJ-T012|YJ-024]]
