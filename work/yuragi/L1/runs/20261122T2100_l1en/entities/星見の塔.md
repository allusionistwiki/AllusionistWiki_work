# 星見の塔（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T075|YJ-T075]]

> 「強い願いを抱いた者が、星見の塔に集うとき、何かが起こる……！！！」 [[full/YJ-T075#post-1|YJ-005:1]]

### [[units/YJ-T084|YJ-T084]]

> 「虚空の間を退出し、控えの間に入った長姉を二人の妹が迎えた。」 [[full/YJ-T084#post-144|YJ-144:144]]
