# ふりかーBBS（portal）

## 概要
『ゆらぎの神話』のポータルスレッド「ふりかーBBS」は、用途未定として立てられた雑談・質問用の場である。ここではヘリステラへの自動リンク不具合や、キーワード記述のまとめが趣旨に反するか否かの議論が行われた。また、ポータル記事における自己トラックバックの発生原因と仕様についても確認されている。

## 流れ
スレッドは Erlkonig が用途未定で立てた雑談投稿（g000）から始まる。その後、Niv-Mizzet が「ヘリステラ」が「ステラ」に自動リンクされる不具合を報告し（g001）、Erlkonig が二重大括弧での対症療法と運営への連絡を提案する（g002）。deillumination は「ゲヘナ」等の記述まとめがゆらぎ趣旨に反するか質問した（g003）。runa_way はポータル記事の自己トラックバック原因を質問し（g006）、Erlkonig がはてな内の URL へのリンクによる自動トラックバック仕様であると回答する（g007）。runa_way は URL なしの例を挙げて反論したが（g008）、最終的に Erlkonig が仕様修正を確認して報告した（g009）。

## 主要な話題・設定
【ヘリステラ】が【ステラ】に自動リンクされる不具合、【ゲヘナ】【亜大陸】【高麗ニンジン】などのキーワード記述まとめの妥当性、ポータル記事における【自己トラックバック】の発生メカニズム。はてな内の【URL】へのリンクによる【自動トラックバック】仕様と、その修正に関する確認が主要な話題である。
