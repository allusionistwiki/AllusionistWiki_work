# 汎用記述スレッド 2

# 『ゆらぎの神話』 (BBS 実況コーパス) - 汎用記述スレッド 2

## 概要
「言理の妖精語りて曰く、」を主軸に据えた総合記述スレッドであり、ルウフェウスやドラゴニュートスレイヤーといった既存設定の断片から、慈愛少女アテナの物語構想まで多岐にわたる神話的要素が投稿された。匿名魔女やahzなどの参加者によるメタ的な雑談や定義論争も交えながら、世界観の拡張と実況的な対話が並行して進行した。記述決闘という形式での他者との競作や、ゆらぎ大学を舞台にしたドラマ脚本の連載など、実験的なコンテンツが多数見られる。

## 流れ
スレッドはg000でルウフェウスらの神話断片から始まり、g001ではドラゴニュートスレイヤーの設定が詳細に記述された。g002〜g007では匿名魔女との造語や「便乗」の定義を巡る雑談が行われた後、g008以降はフレナフェレ、天使猫アズラーイール、サマエルなどキャラクター設定が連投される（g011-g013）。g014ではデューク・レメゲトンの記述転載があり、g020〜g035にかけてahzによる寄生と名乗りを巡る論争が発生した。

中盤のg056〜g059では「人類破滅の小箱」や超人・英雄の設定が語られ、g070以降は「決闘記述」というテーマで複数の作者が一ノ瀬、cob、nivなどが参加する競作形式の投稿が続いた（g083-g114）。g142〜g157ではシルバリアースの精霊交代と風の帰還を巡る物語が展開され、g166〜g179にかけては「慈愛少女アテナ」のプロット構築過程が詳細に記述された。終盤のg204以降はオレオレやコルセスカを主人公としたアクション・ドラマ形式の記述が増加し、g239で猫の国古事記の補正をもってスレッドの主要な記述が締めくくられた。

*   **用語・概念**: 紀元槍、パ音語、便乗、大閉鎖、人類破滅の小箱、超人/英雄、くり/カメレオン騎士団、透刀/封魔研、知神の盾、決闘記述、最果ての二人、ヴォルカの書、グロリアの開示録、エンダーグリッド、記士/記葉/記乗、世界記述(ワールド・コード)、幻写眼、航空相撲。
