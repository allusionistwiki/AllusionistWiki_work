# 訓練場

## 概要
『ゆらぎの神話』BBSにおける「訓練場」スレッド（YJ-T113）は、TRPG『りゅうたま』の世界づくりルールをテンプレートとして採用し、参加者が架空世界の記述を行うための実況・練習の場として機能した。投稿者 bothhands が導入したテンプレートに基づき、言理の妖精語りて曰く、 や ｃ。 らが、球形空間、地下文明、邪悪の中枢、閉鎖された部屋、そして読者の存在そのものから成る「文章世界」など、多様かつ独創的な世界観を展開した。これらの記述は単なる設定の羅列にとどまらず、世界の物理的構造、歴史の不透明さ、住民と媒体の関係性といったメタ的な考察を含んでおり、スレッド全体が一つの連作的な世界構築実験として位置づけられる。

## テンプレートの導入と『りゅうたま』ルール
本スレッドの基礎は、投稿者 bothhands によるテンプレート提示に始まる。2008年8月16日、bothhands は「このスレッドで訓練を行います。」と宣言し、続けて以下の項目からなる世界観作成の練習用テンプレートを公開した YJ-T113:1,2 。

> しばらくのあいだは以下のテンプレートを使って世界観を作るための練習をします。
> ●世界の名前
> ●世界の形
> ●この世界の歴史
> ●代表的な国
> ●世界を脅かす者
> ●世界の謎 YJ-T113:2

このテンプレートは、TRPG『りゅうたま』のルールブック掲載の「世界づくりルール」および「世界づくりシート」に準拠したものであり、公式ブログへのリンクも添付されている YJ-T113:2 。以後、スレッド内の主要な投稿はこの6項目に沿った形式で構成されることとなる。

## 番号付き世界群：球形空間と閉鎖構造
テンプレート導入直後、bothhands は「番号」を冠した複数の世界を連続して投稿し、物理的な形状や社会構造のバリエーションを示した。

### 番号100：板状大陸と技術回収の卵
最初の具体的な記述は「番号100」である。この世界は「球形の空間の内部にしきりのような板が設置されている」と定義され、その巨大な板の上で生物が生活している YJ-T113:3 。歴史としては、アマゾン川をイメージした大河沿いに文明が発祥し、川沿いの都市国家が周辺を支配して大規模国家化する傾向が記述される YJ-T113:3 。
この世界の最大の特徴は「世界を脅かす者」と「謎」にある。言語の分裂を意図する組織が存在する一方で、「世界は一種の卵だ」という設定が提示される。世界を作った存在は住民が外側へ出ることを期待しており、そのために使用された技術の回収を目的として世界を作成したとされている YJ-T113:3 。

### 番号99・98：製造者と外殻
続いて投稿された「番号99」では、「複数の閉鎖空間が連結している」という形状が提示される。この世界の住民は、閉鎖空間を製造する「製造者」の存在を認識しているが、その正体は不明である YJ-T113:4 。住民が開拓や施設増設を行うと製造者によって破壊されるという脅威が存在し、「書いている私にもわからないが。」という投稿者のメタ的な発言も記されている YJ-T113:4 。
「番号98」では、球形の大地を覆う「外殻」が出現した世界が描かれる。外殻の出現により星の気候が変化し、資源戦争が続いている状況が描写される。既知のエネルギー資源を持つ国やテロリスト、外殻調査団体が存在するが、「世界はあるとき外殻で覆われてしまった」という謎を残して幕を閉じる YJ-T113:5 。

### 番号97・96：地下文明と技術戦争
投稿8では「番号97」が提示される。この世界は球体であり、生物は地表に生息するが、「地下は機械たちの巣」である YJ-T113:8 。歴史において、生物は荒廃した地上を離れ地下へ逃げ延びた後、再び地上へ出ることを選択した。「生物は地下世界をすて、地上へでた。このとき歴史をやり直すという意味合いがあったので高度な技術を持つ地下世界は封印された。」という記述は、文明の断絶と再構築の動機を示している YJ-T113:8 。
「番号96」では二つのバリエーションが投稿される。一つ目は超大国同士の争いが技術開発による代理戦争として行われた世界である。超大国の瓦解により技術戦争は頓挫したが、その技術は生活に入り込み、「最終目的を知りかつ今も向かっている人々はほとんどいない」と記される YJ-T113:9 。二つ目の「番号96」では、複数の大陸が橋で繋がれた世界が描かれ、「何者かが道を造った。道を造った者は去り、他の者がこの道を利用して繁栄した。」という歴史と、「道の終わりはどこか？」という謎が提示される YJ-T113:10 。

## 壁と超大国：現実世界との対比
投稿者 言理の妖精語りて曰く、 は、閉鎖された国家や現実世界を模した記述を投稿し、テンプレートにおける「歴史」の不透明さや「国境」の物理的制約を強調した。

### 壁に囲まれた単一国家
投稿6では、名前が住人の好きに呼ばれる世界が描かれる。「恐らくは球状だろう、いいやドーナツ型だ、となかなか意見が一致しない。」という記述は、世界の形状に対する住民の認識の曖昧さを示す YJ-T113:6 。この世界には「国境を物理的に閉鎖する非人工物の壁」が存在するため、国家は一つしかなく、住人は産まれた地域の集団に属して生きる。歴史は「闇に隠れた部分が多く」、明るみに出たものは同国民による破壊と収奪に占められている YJ-T113:6 。
脅威は外部ではなく内部にある。「壁を越えられないため国土内ですべてをまかなうしかないのだが、その総量はとても全国民分には行き渡らない。」という資源の不足と、自己集団のために流通を阻害する者たちが「世界の敵」と定義される YJ-T113:6 。謎としては、「何故私たちはこの国にいるのか。」「壁の向こうはどうなっているのか。」が挙げられ、閉鎖空間における存在論的な問いが投げかけられる YJ-T113:6 。

### 現実世界：地球と超大国
投稿7では「現実世界」がテンプレートに則って記述される。形は「宇宙の外れの銀河系の外れの太陽系の第3惑星地球」と定義され、歴史は150億年前の宇宙誕生から20万年前の人間の誕生、そして文明の興亡までを簡潔に辿る YJ-T113:7 。
代表的な国として「アメリカ：世界唯一の超大国。世界の警察。」が挙げられ、かつてほどの勢いはないことが記される。EUは平和裏に構成された国家連合体として描かれる YJ-T113:7 。脅威としては、戦争よりも環境問題・エネルギー問題・人口問題など「資本主義のもたらした問題」が世界を脅かしつつあると指摘される YJ-T113:7 。謎は「われわれはどこから来たのか？われわれは何者か？われわれはどこに行くのか？」という哲学的な問いで締めくくられる YJ-T113:7 。

## 邪悪の中枢：シャザーダール
投稿12では、ザ・ロード（The Lord）を名乗る存在による「シャザーダール」が描かれる。この世界は「冥府の体現、虚無の穴、邪悪の中枢」と呼ばれ、「ブロッコリーのような形をしている」と定義される YJ-T113:12 。
歴史は神話的な起源を持つ。「まず闇があった。闇は別の世界とぶつかり合い、その世界を壊してしまった。」「闇はとても後悔し、その世界をまるごと作り直した。闇しかなかったので、闇によって。」という記述により、「闇の、闇による、闇のための世界」が形成された経緯が語られる YJ-T113:12 。
代表的な国として「セルシティ」と呼ばれる軍隊組織が存在する。「彼らの社会はアリに似ているが、さらに知的で、徹底的である。」と記される YJ-T113:12 。
この世界の脅威は外部からの攻撃である。無数の世界探索枝（プローブ）によって接触した他世界から「邪悪なものである」と誤解され、問答無用で攻撃を仕掛けられることである。住人の義務は、それらの攻撃者を「大脳生理学的に解消し、安全かつ無害な同胞へと化学変化させる」ことだと記される YJ-T113:12 。
謎としては、「一体、誰がこの世界の友達になってくれるのだろう？」「闇はずっと待ち続けている。」という孤独と渇望が提示される YJ-T113:12 。

## 部屋単位の世界：シルビア
投稿13では、投稿者 ｃ。 による「シルビア」が記述される。この世界は「小さな窓と大きな窓がひとつつずつある四角い部屋」と定義され、家具や光の描写が詳細に行われる YJ-T113:13 。
歴史は日常の異変として描かれる。「ある日の朝、ぜんまいねずみがどこからともなく現れた。」「ある日の夜、肖像画の貴婦人が話しかけてきた。」「ある日の昼、食べようとしたクッキーが突然動き出して命乞いをした。」といった事象が列挙される YJ-T113:13 。
代表的な国は「ベッドの上」や「宝箱の中」といった部屋内の特定の場所であり、ねずみは部品になり、貴婦人の場所には骨の人形が潜んでいる YJ-T113:13 。
脅威は「夢。」「叫ぶほどの夢。」である YJ-T113:13 。謎としては、窓の外にある「無数の十字」が突き刺さる草原や、「合う鍵のないドア。開かれ、閉まる度、部屋が小さくなる。」という空間の収縮現象が挙げられる YJ-T113:13 。

## 文章世界：読者と媒体
スレッドの最後を飾るのは、投稿者 言理の妖精語りて曰く、 による「文章世界」である。この世界は「本来は特に名前がないが暫定的に」と名付けられ、「世界自体に形はない」と定義される YJ-T113:14 。
アクセスには「何らかの文章の体を為す物質（多くは本、最近ではディスプレイが増えた）」が必要とされる YJ-T113:14 。
歴史および代表的な国（ここでは空想や幻視）は、「文章を書いている間、或いは、文章を読んでいる間、また読み終わったあと、それにアクセスしている(いた)者の知識や記憶、心を動かす(動かした)何かとして存在。」すると定義される。これにより「媒体は同じでも、歴史は一つとして同じにはならない」という相対性が提示される YJ-T113:14 。
脅威は読者の消滅である。「読者の存在が無くなるのと、文章世界が亡くなるのは同義であるから、読者の存在を脅かすもの（本を読む風習が廃れる、本が廃刊になる、など）」が挙げられる YJ-T113:14 。
謎は「ネタバレになるので書けません。」と記され、メタ的な閉鎖で幕を閉じる YJ-T113:14 。
