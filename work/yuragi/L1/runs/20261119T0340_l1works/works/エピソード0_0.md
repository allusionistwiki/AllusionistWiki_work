「なに！？

 この世界のトントロポロロンズとは木になるものではないのか！？」

　ヘリステラは素っ頓狂な声を上げた。

「なんで豆腐が木になるんだよ。豆腐は大豆から作るんだろ」

「その大豆というのが、トントロポロロンズの種なのか……？」

「何か話が噛みあわないんだが……」

「いや、しかしトントロポロロンズは……」

　言いかけたヘリステラの口が突然止まる。

慌てて振り返った視線の先にあるのは、先ほどすれ違った少女の後姿だった。

「お……おい。どうした？」

　ヘリステラの顔に浮かぶ驚愕の表情。

「魔法少女きゆら……ここにいたのか……」
