# 第一大地（ゆらぎの神話）

## 概要
『ゆらぎの神話』に登場する地域の一つ。「命を分け合う」ことで全体の永遠性を保つ者達が住む土地として記述される。この地の住人は一個体あたりに膨大な生命量を持つことが特徴であり、命が欠けたり少なくなった者に命を分け与え活力を得させることで永続な存在を実現している。第三大地や第四大地といった他の大地との関係性の中で語られることが多い。

## 記述の流れ
第一大地の概要は YJ-T061 の投稿において、第二大地（現時点では記述なし）、第三大地（フィシ・リ・フィシらがいた場所）と並列して定義された [YJ-T061:40]。その生命分配の仕組みについては YJ-T136 で詳細に語られ、「ヴォルカの書」を引用する形で「分け合う命」の原理が説明されている [YJ-T136:956, 957]。
また、第一大地から来た存在として『無貌の狼』と『燃える単眼』が登場し、後者は第四大地へ移動した後に第一大地からのアウターによって連れ去られるという経緯が YJ-T134 と YJ-T135 で描かれた [YJ-T134:111, 112; YJ-T135:414]。
さらに、第一大地を拠点とする中立な存在である「絡め取る楽園」が、パッゲットムジャッリーによって捕縛される顛末が YJ-T022 で記述されている [YJ-T022:131]。
