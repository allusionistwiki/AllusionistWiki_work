# 純神族

## 概要
『ゆらぎの神話』に登場する、とある平行世界を支配していた神々の総称である。最も数の多い神族であり、特定の要素（種族）を取り込むことで、その種族の支配に特化した存在へと変化する性質を持つ。具体には「猫神族」「竜神族」「魔神族」「人神族」などがこれに該当する。

## 記述の流れ
スレッド YJ-T017 では、第三級から第一級の異界災害【鏖殺戦鬼】の故郷とされる世界線「パンゲオン」において、かつて純神族が支配していたことが言及されている。同世界は妖刀に魅入られた剣鬼によって滅亡したポストアポカリプス世界である。
スレッド YJ-T022 では、言理の妖精により、純神族が要素を取り込むことで種族を支配する特化型となる仕組みと、猫・竜・魔・人の各神族への分化について解説されている。
スレッド YJ-T068 では、これらの神々が「千呪」という存在によって滅ぼされた経緯が語られ、その起源や世界のバグに関する記述が含まれている。
