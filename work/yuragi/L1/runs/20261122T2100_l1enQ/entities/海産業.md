# 海産業（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T027|YJ-T027]]

海の誕生後に発生した産業群。海鳥、海風、海霧、海草、海百合、海林檎、海鳴り、海猫などの生産・加工を含む。
> 「すなわち、【海】産業の発生である。」 [[full/YJ-001#post-94|YJ-001:94]]
> 「【歓喜】の触手たちはそれらの生成物を組み合わせ、加工して【海鳴り】【海猫】などの様々な便利な道具や楽しい玩具を作り出した。」 [[full/YJ-001#post-95|YJ-001:95]]
