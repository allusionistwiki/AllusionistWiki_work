# 無限の剣（はてなきのつるぎ）（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T001|YJ-T001]]

メクセトの武具の一つ。投擲命中で結界を張り、他次元から多数の剣を召喚して標的を襲う。使用者も巻き込まれる。
> 「相手に呪文を唱えながら投剣として投げつけて命中するとその周囲に結界が張られ、同様の剣が多数の他次元（一説には数億）から召喚され一斉に標的に対して襲い掛かるという点である。」 [[full/YJ-T001#post-|YJ-007]]
