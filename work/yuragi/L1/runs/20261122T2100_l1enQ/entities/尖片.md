# 尖片（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T001|YJ-T001]]

魔術師が投擲用として多用する小型短剣。遠隔操作や密集させて盾にするなど多用途に使用される。
> 「２リーデ程（人差し指２本）の長さの小型の短剣。投擲用の短剣だが、その使用者の大半は魔術師である。普段はローブやコートの中に70〜100本程度忍ばせ、魔術による遠隔操作、あるいは射出による物量攻撃を行うのが基本仕様となっている。」 [[full/YJ-T001#post-|YJ-006]]
