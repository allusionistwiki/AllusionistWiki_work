# 騎人（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T012|YJ-T012]]

レプト国独自の風習で人間種族が騎乗用に訓練されたもの。幼体の竜を人に乗せる（逆騎乗）を行う。
> 「人間種族が騎乗用に訓練されたもの。レプト国独自の風習であり、【Ｍ男】とは根本的に異なる存在であると当地では主張されている。よって、竜が成長するまでは、逆に人に竜を乗せるのだ。」 [[full/YJ-T012#post-|YJ-054]]
