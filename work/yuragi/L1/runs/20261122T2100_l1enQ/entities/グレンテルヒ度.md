# グレンテルヒ度（ゆらぎの神話）

## 使用状況（篇横断・逐語引用＋ref 付き）

### [[units/YJ-T023|YJ-T023]]

グレンテルヒが考案した温度単位。ビークレットの焔の温度を200度の基準にしている。200度までの目盛りしかなく、それ以上はB度と呼ぶ。
> 「グレンテルヒ考案のグレンテルヒ度（現在ハイダル地方の一部で現在も使われている）では、 ビークレットの焔の温度を200度の基準にしてるらしいよ。 グレンテルヒ度には200度までの目盛りしかありません。 それ以上を表すときはＢ度と呼びます。」 [[full/YJ-T023#post-|YJ-79, YJ-81]]
