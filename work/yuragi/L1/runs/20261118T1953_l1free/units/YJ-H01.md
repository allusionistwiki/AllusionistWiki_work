# ふりかーBBS（portal）

## 概要
『ゆらぎの神話』におけるポータルスレッド「ふりかーBBS」は、2006年2月に Erlkonig によって用途未定として開設された雑談・質問用の場である。ここでは、はてな記述におけるキーワードの自動リンク不具合（ヘリステラがステラにリンクされる現象）への対処法、ゆらぎの趣旨に合致するキーワード記述のまとめ方に関する議論、そしてポータル記事において発生する「自己トラックバック」の謎とその仕様確認が行われた。

## 開設と目的
スレッドは2006年2月28日、Erlkonig によって「用途がどうなるか分かりませんけど、とりあえず立てるだけ立てときます。」という投稿から始まった {1}:1。この時点では具体的なテーマは設定されておらず、「質問でも記述でも雑談でも、何でも書いてもらえれば」という自由な利用を呼びかける形での開設となった {1}:1。

## はてな記述の不具合と対症療法
スレッドが稼働し始めて約2ヶ月後の2006年4月28日、Niv-Mizzet によって具体的な技術的な不具合が報告された。Niv-Mizzet は「にて、[ヘリステラ](http://flicker.g.hatena.ne.jp/keyword/%e3%83%98%e3%83%aa%e3%82%b9%e3%83%86%e3%83%a9)が[ステラ](http://d.hatena.ne.jp/keyword/%a5%b9%a5%c6%a5%e9)に[リンク](http://d.hatena.ne.jp/keyword/%a5%ea%a5%f3%a5%af)を貼られてしまいます。」と報告し、キーワード「ヘリステラ」を含む記述が意図せず「ステラ」へのリンクとして処理されてしまう現象を示した {2}:2。

これに対し、Erlkonig は2006年4月28日、「対症療法ですけど、二重大カッコで括ると直るかもしれません。」と回答し、キーワードを「[[ヘリステラ]]」のように二重括弧で囲むことで自動リンクを回避できる可能性を示唆した {3}:3。さらに Erlkonig は「とりあえず[はてな](http://d.hatena.ne.jp/keyword/%a4%cf%a4%c6%a4%ca)の偉い人に言っときます。」と述べ、運営側への報告も同時に行う姿勢を見せた {3}:3。

## キーワード記述まとめの妥当性
2006年5月9日、deillumination によってゆらぎの神話におけるキーワード記述のあり方について質問が投げかけられた。deillumination は「とりあえず、[キーワード](http://d.hatena.ne.jp/keyword/%a5%ad%a1%bc%a5%ef%a1%bc%a5%c9)「[ゲヘナ](http://flicker.g.hatena.ne.jp/keyword/%e3%82%b2%e3%83%98%e3%83%8a)」「[亜大陸](http://flicker.g.hatena.ne.jp/keyword/%e4%ba%9c%e5%a4%a7%e9%99%b8)」「[高麗ニンジン](http://flicker.g.hatena.ne.jp/keyword/%e9%ab%98%e9%ba%97%e3%83%8b%e3%83%b3%e3%82%b8%e3%83%b3)」で各所の記述をまとめてみたんですが、これってゆらぎを求めるっていう趣旨に違反してたりしないでしょうか。」と問いかけた {4}:4。

deillumination は「だったら自粛しますが、個人的にはこの手のまとめは絶対必要だと思うんですが。ここでやるのがダメだったら、他所で[wiki](http://d.hatena.ne.jp/keyword/wiki)でも借りてやりたいです。」と続け、ゆらぎの神話という枠組みにおいてキーワードを整理・集約することが許容されるのか、それとも外部ツールを用いるべきなのかについて判断を求めた {4}:4。

## 自己トラックバック問題とその解決
2006年10月17日、runa_way によってポータル記事特有の現象である「自己トラックバック」に関する質問が投稿された。runa_way は「ポータルの自分のページで記事を書くと、自己[トラックバック](http://d.hatena.ne.jp/keyword/%a5%c8%a5%e9%a5%c3%a5%af%a5%d0%a5%c3%a5%af)が発生することがあるみたいです。」と報告し、「と言っても、現状確認しているのは私の書いたあれこれ（削除済）と、[烏兎紀](http://flicker.g.hatena.ne.jp/keyword/%e7%83%8f%e5%85%8e%e7%b4%80)だけなのですが。」と具体的な事例を挙げた {7}:7。

runa_way は「私の記事もからすと[うさぎ](http://d.hatena.ne.jp/keyword/%a4%a6%a4%b5%a4%ae)さんの記事も、[トラックバック](http://d.hatena.ne.jp/keyword/%a5%c8%a5%e9%a5%c3%a5%af%a5%d0%a5%c3%a5%af)[URL](http://d.hatena.ne.jp/keyword/URL)を書いているようには見えないのですが原因が分かる方はいますでしょうか。」と、明示的なトラックバック URL が記述されていないにもかかわらずトラックバックが発生する原因を尋ねた {7}:7。

これに対し、Erlkonig は2006年10月24日、「えーと、[はてな](http://d.hatena.ne.jp/keyword/%a4%cf%a4%c6%a4%ca)内の[URL](http://d.hatena.ne.jp/keyword/URL)に[リンク](http://d.hatena.ne.jp/keyword/%a5%ea%a5%f3%a5%af)を貼ると、[自動トラックバック](http://d.hatena.ne.jp/keyword/%bc%ab%c6%b0%a5%c8%a5%e9%a5%c3%a5%af%a5%d0%a5%c3%a5%af)が発生するのは[仕様です](http://d.hatena.ne.jp/keyword/%bb%c5%cd%cd%a4%c7%a4%b9)けれど、それのことでしょうか？」と回答し、はてな内の URL へのリンクが自動トラックバックを発生させる仕様であることを説明した {8}:8。

しかし runa_way は同日、「違います。」と否定し、「例えば<http://flicker.g.hatena.ne.jp/TimeTide/comment?date=20061017#c>を見てください。何も[URL](http://d.hatena.ne.jp/keyword/URL)を貼っていないにも関わらず、この記事からこの記事に対して[トラックバック](http://d.hatena.ne.jp/keyword/%a5%c8%a5%e9%a5%c3%a5%af%a5%d0%a5%c3%a5%af)が発生しています。」と具体的な URL を提示して反論した {9}:9。runa_way は「具体的な実害は大きくないですが気持ち悪いので。」と、この現象がユーザーにとって不快感を伴うものであることを強調した {9}:9。

最終的に2006年11月10日、Erlkonig は「<http://i.hatena.ne.jp/idea/12202> これですね。現在修正作業中とやら。」と回答し、はてな側のアイデアページで報告されているバグ（自己トラックバックの発生）であることを確認し、運営側による修正作業が行われていることを報告してスレッドの主要な技術的問題への対応が完了した {10}:10。
