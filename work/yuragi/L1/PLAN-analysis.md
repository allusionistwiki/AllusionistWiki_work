## 目的
『ゆらぎの神話』は参加者が**実世界の参照**（神話体系・宗教・文学・音楽・歴史・科学…）を持ち込んで共同神話を組んだ。その参照関係を抽出し、
「作中記述 ↔ 実世界の元ネタ」を結ぶ解析ページを層として整備する（アリュージョニスト wiki の allusion 層に相当）。

## 設計骨格（層の恒久構図に一致）
- 単位: 篇ごとの抽出（窓=100 投稿）→ 機械ゲート（逐語引用・ref 実在・CN）→ `allusions/<uid>.jsonl` 台帳。
- 页面:
  - `allusions/<uid>.md` — 篇の参照一覧（対象名・使われ方・逐語引用＋ref 導線）
  - 対象正規ページ `allusions/a/<term>.md`（将来）— 篇をまたいだ対象集約（「この神話は N 篇でこう使われた」）
  - `allusions_index.md` — 類型別索引
- 引用アンカー: 100 字以内逐語＋ref 実在（投稿 body 正規化後 substring 検査）を機械保証。
- 信頼度 3 値: 明言 / 蓋然性高 / 推測（推測は「仮説」表示・統合主張に使用禁止）。
- 来歴: run 単位（`<ts>_l1allud`）、抽出→監査→改訂は新 run 派生（derived_from）。

## v0.4 方針（ユーザー是正 2026-11-22 二度:「坂本とかも創作」「創作以外で実際引用していない」）
- **実世界参照の判定基準 = 原文の明示**: 実在作品名+作者/媒体の提示（「THIRD EXCALIBURってゲーム」）・実在書物の書誌引用（「沖浦和光『陰陽師の原像』を参照のこと」）・実在の出来事/制度/学術概念/ジャンル名の説明を伴う言及のみ対象。
- **同名の実在名があるだけでは創作**: 貴族【坂本】・山田太郎 型は作中人物の命名であり実世界引用ではない → 対象外。ブランド・商品名も「命名素材に借用しているだけ」は対象外、比喩・言及としての明示がある場合だけ対象。
- confidence=推測 は同一文脈に実世界対象の明示がある場合だけ（命名類似・言い換え）。
- 過剰抑制の検出を恒久化: ゲート drop を `gate_drops.jsonl` に全件記録し、落とした語を実読して誤 drop / 誤 adoption 双方を監査する。OBJ ゲートは 4 字以下一般語限定（固有名・台帳語は落さない）。

## 全件実読で確立した規則（v0.2→v0.3）
- 対象 = 命名源・概念・ジャンル・体系・作品・人名・地名・ブランド・用語。**場面の物体/素材/食品/道具/衣類/乗り物は対象外**（usage 表現 `実在の素材/食品/…` で DROP:OBJ）。
- **作中創作は対象外**：作中名詞（实体台帳 799 名）を窓毎に prompt 注入。usage に「架空」を含む自己申告は DROP:FICTION。作中引用文献（『作中書名』・作中著者）は実在が明白な時だけ出力させる。
- usage は引用文脈の機能記述のみ。**外部知識帰属（X は Y の作者・Z を想起）は原文に明記がある時だけ**（pilot で捏造多数：ブギーポップ=上橋菜穂子、アルコー=ポー 等）。
- term は kind ラベル名・一般名詞・40 字超を機械 DROP。同一対象は norm（・除去）で統合。
- 404 全滅の真因は llm base_url（/v1 含む）への /v1 二重連結。Strata serving=1 直列・workers=1 実走で完走。
