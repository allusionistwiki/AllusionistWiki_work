# 観察ページ ch00343__4-112　嵐の前.md

### トリシューラ
- 何であるか: 球技大会の運営・主催に関わる人物。伸縮性のあるトレーニングウェア（ジャージっぽい服）を着用しており、シャープな豚の鼻がプリントされている。
- 関係: アキラくんの主。「きぐるみの魔女」と呼ばれる。ルバーブと対話する。前第六位ミスカトニカお姉様、アーザノエルお姉様、ラクルラールお姉様らとの関係を持つ。
- 引用: 「トリシューラが満足げに呟いた。」 / 「本日のトリシューラは伸縮性のあるトレーニングウェアを着ているのだが、何故かシャープな豚の鼻がプリントされていた。」

### アキラくん（俺）
- 何であるか: トリシューラの従者であり、球技大会の参加者。サイバーカラテ道場のユーザー。冷静さを保ちつつも闘争への興奮を自覚している。
- 関係: トリシューラに仕える。ルバーブと対話する。パーン・ガレニス・クロウサーらを敵視・警戒している。
- 引用: 「俺は空を見上げながら疑問を口にする。」 / 「（アキラくん？　ちゃんとクールダウンできてる？）」

### パーン・ガレニス・クロウサー
- 何であるか: 箒競技で圧倒的な速度を見せる男。「最速のガレニス」と呼ばれる。四角い眼鏡をかけ、前髪が風圧で逆立つ。野獣のような印象を与える。
- 関係: クロウサー家当主リーナ・ゾラ・クロウサーと競い合う予定。六王の一人（敵に回すことを回避された）。再演呪術の影響を受けづらい。
- 引用: 「他を圧倒する速度での飛翔。……男の名はパーン・ガレニス・クロウサーといった。」 / 「最速のガレニスと呼ばれたパーンを殊更に煽るような惹句――『空の最速は誰だ』みたいなやつだ――が奏効したということなのだろう。」

### ルバーブ
- 何であるか: ラフディの王マラードに仕える忠臣。不器量な乱れ髪の男で、力士のような屈強な肉体を持つ。「醜」が力強さを強調する形容となる。
- 関係: マラードを第一に考えている。アレッテ・イヴニルを警戒し、トリシューラに情報を求める。マラードへの裏切りともとれる行動を取る可能性がある。
- 引用: 「美しきラフディの王マラードとは対照的に不器量な乱れ髪の男――ルバーブは声を潜めるようにしてそう言った。」 / 「ルバーブは忠臣だ。俺はマラードよりも、むしろ彼に惹き付けられるものを感じていた。」

### アレッテ・イヴニル
- 何であるか: 星見の塔に所属する魔女。「邪眼の人形姫」と名乗る。ミヒトネッセと並ぶラクルラールの高弟であり、最高傑作の一つ。
- 関係: ラフディの正統なる後継者を自称している。マラードに取り入り心を許させている。元となった呪具があるという噂がある。
- 引用: 「星見の塔に所属する魔女についての情報が欲しい。アレッテ・イヴニルという名に聞き覚えは？」 / 「邪眼の人形姫と名乗った魔女はラフディの正統なる後継者を自称しているという。」

### ラクルラール
- 何であるか: 前第六位ミスカトニカお姉様が隠居した後、アーザノエルお姉様の推薦で代理となった存在。「群」を構成する一部。人形を手足のように操る。
- 関係: ミヒトネッセとアレッテ・イヴニルの作者（最高傑作）。トリシューラやリールエルバの姉妹機でもある。正体不明。
- 引用: 「前第六位ミスカトニカお姉様がお隠れになった後、アーザノエルお姉様の推薦で代理となったのがラクルラールだって聞いてる。」 / 「ラクルラールお姉様は人形を手足のように操って第六位代行としての役目を果たしていた。」

### ミヒトネッセ
- 何であるか: ラクルラールの高弟。完全にゼロから生み出された作品。
- 関係: アレッテ・イヴニルと並ぶ存在。
- 引用: 「ミヒトネッセとアレッテ・イヴニルは近年になって作られた最高傑作と言われているよ」

### マラード
- 何であるか: ラフディの王。「美しき」と形容される。アレッテ・イヴニルに心を許している。
- 関係: ルバーブの主君。
- 引用: 「美しきラフディの王マラードとは対照的に不器量な乱れ髪の男――ルバーブは声を潜めるようにしてそう言った。」 / 「マラードもまたすっかりアレッテ・イヴニルに心を許しているとのことだ。」

### リーナ・ゾラ・クロウサー
- 何であるか: クロウサー家当主。「空使い」と呼ばれる。
- 関係: パーン・ガレニス・クロウサーと競い合う相手。
- 引用: 「約束しただろうが。クロウサー家当主、『空使い』リーナ・ゾラ・クロウサーとの競い合いは血の流れないものにしてやるとな。」

### 第五階層
- 何であるか: 物語の舞台となる閉ざされた箱庭。天井に抜けるような青（快晴）が広がっている。南西ブロックには特設競技場がある。
- 関係: ガロアンディアンとラフディが支配権を争う場所。現ラフディ領を含む。
- 引用: 「第五階層の天井に、抜けるような青が広がっていた。」 / 「第五階層南西ブロック――つまり現ラフディ領に特設された即席の競技場では、至る所で様々な競技が行われていた。」

### 球技大会
- 何であるか: ガロアンディアンとラフディの一時的な休戦下で開催されるイベント。賞金付きで賭博も存在する。ガロアンディアンの技術力と再生者の肉体の利点を示すプレゼンテーションの場でもある。
- 関係: トリシューラが主催・運営に関わる。対六王戦の代替手段として機能している。
- 引用: 「今回は球技大会だから一種目限定だけど、元々箒を使った競技は人気だからね。」 / 「この大会は、互いの勢力の利点を広める為のプレゼンテーション、デモンストレーションの場でもあった。」

### ラフディーボール
- 何であるか: ラフディの国技の一つ。棘付きの球を投げ合う危険な競技。「地上で最も激しい球技」と呼ばれる。実力差がそのまま反映されるため八百長の余地がないとされる。
- 関係: トリシューラがガロアンディアンの価値を示すために仕掛ける最終競技。ルバーブが得意としている。
- 引用: 「もう一つは棘付きの球を投げ合う危険な競技、ラフディーボールだ。」 / 「本日最後に行われるラフディの国技、『ラフディーボール』で私たちガロアンディアンの価値を示す。」

### サイバーカラテ道場
- 何であるか: オンライン上のコミュニティ・プラットフォーム。対六王トピックなどで議論が盛ん。認定コーチによる遠隔指導やデータ蓄積が可能。
- 関係: アキラくんを含むユーザーが利用している。スポーツの練習にも使われている。
- 引用: 「サイバーカラテ道場の対六王トピックは常に侃々諤々だ。」 / 「サイバーカラテ道場は、効率的なスポーツの練習すら可能にする。」

### 再生者
- 何であるか: 【愛情の断章】や【道徳の断章】によって甦った人々。死んでいるため怪我をしても平然としており、肉体の力を限界まで発揮できる。
- 関係: ラフディの大地の民（丸々とした体型）。竜王国の再生者もいる。高位再生者（オルクス=ハイ）という分類がある。
- 引用: 「彼ら彼女らはラフディの大地の民――【愛情の断章】によって甦った再生者たちだ。」 / 「既に死んでいる再生者は平然としている。肉体の力を常に限界まで発揮させることができる再生者の運動量は明らかに生者たちを上回っていた。」
