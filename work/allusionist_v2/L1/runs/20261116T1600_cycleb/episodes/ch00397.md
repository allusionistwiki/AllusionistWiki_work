# 観察ページ ch00397__4-166　檻の感触だきしめて②.md

### シナモリアキラ（アキラ姫）
- 何であるか: 物語の語り手であり、地下アイドルランキング11位のモデル。感情を凍結させてパフォーマンスを行う。
- 関係: トリシューラの主。カーインに修行の成果を受け取る。コルセスカと共にステージに立つとされる。
- 引用: 「俺の主はやる気に満ちあふれていた。」 / 「頑張ろうね、アキラ姫」

### トリシューラ
- 何であるか: シナモリアキラの主であり、小さな妖精。衣装のデザインや技術面を担い、「きぐるみ妖精」のブランドイメージ（破壊）を体現する知性体。
- 関係: シナモリアキラに指示を出す。カーインと対立・協力関係にある。「杖」技術の粋を持つ。
- 引用: 「長い黒髪をトリシューラに任せて身支度を行う。」 / 「主役は、あくまでトリシューラだ。」

### スマルト
- 何であるか: 地下アイドルランキング10位から11位へ転落した夜の民。形の曖昧な身体を持ち、「霧状の衣服」を操るモデル。ボロームピクチャーズと専属契約。
- 関係: シナモリアキラの対戦相手。ラリスキャニアに利用され、シナモリアキラに敗北する。
- 引用: 「十位がラリスキャニアで十一位がスマルトになっている。」 / 「仮面の奥で青い炎が燃え上がる。」

### ラリスキャニア
- 何であるか: 地下アイドルランキング10位の存在。シナモリアキラに勝越している。分身と変身、疑似餌（ルアー）の能力を持つ。
- 関係: スマルトを「牽制」や「疑似餌」として利用し、シナモリアキラの必殺技を観察・研究した張本人。
- 引用: 「十位がラリスキャニアで十一位がスマルトになっている。」 / 「これ、ラリスキャニアの戦略だ」

### カーイン
- 何であるか: 長い髪を束ねた褐色の美男子。シナモリアキラに修行経験（イメージ）を投擲する。オルヴァの弟子。
- 関係: シナモリアキラに「鋼を足す」と助言し、記憶を渡す。トリシューラとは面識があり、評判で引かれている。
- 引用: 「そこには長い髪を束ねた褐色の美男子が少し呆れたような表情で立っていた。」 / 「投擲されたのは、カシュラム十字が刻まれた懐中時計のような呪具。」

### オルヴァ
- 何であるか: カーインの老師。「シナモリアキラの代替品」として活動し、時空をねじ曲げて過酷な修行を行っている。
- 関係: カーインと共にシナモリアキラの成長（サイバーカラテ道場への反映）を支えている。
- 引用: 「老師オルヴァとその弟子カーインがヴァーチャル山奥で滝に打たれたり...」 / 「オルヴァは『シナモリアキラの代替品』として活動し」

### コルセスカ
- 何であるか: シナモリアキラの心の中に根付いている存在。ステージ上には物理的に立っていないが、精神的なパートナーとして「三人で」立つことを意識させる。
- 関係: シナモリアキラの情動を凍結させるきっかけとなる存在。「きぐるみ妖精」として共に戦えない状態にある。
- 引用: 「だから、このステージにはコルセスカと共に臨む。」 / 「ここにいなくとも、『きぐるみ妖精』として共に戦えなくても」

### 架空の道場（サイバーカラテ道場）
- 何であるか: シナモリアキラがイメージ訓練を行う仮想空間。カーインとオルヴァの修行経験がフィードバックされる場所。
- 関係: シナモリアキラの思考速度を加速させ、技術的上積みを行う装置。
- 引用: 「そして俺は、架空の道場でイメージの訓練を繰り返す。」 / 「『サイバーカラテ道場』による上積みでもまだ足りない。」

### 白骨迷宮（地下空間）
- 何であるか: ランキング決定のための対決ライブが行われる場所。大量の白骨が埋め込まれた外壁、コウモリとフクロウが乱舞する天井を持つ。
- 関係: スマルトとシナモリアキラがパフォーマンスを披露する舞台。観客（再生者）が動員される。
- 引用: 「大量の白骨が埋め込まれた不気味な外壁はどこまでも広がり」 / 「ここは死人たちが踊る悪夢の底だ。」

### 霧状の衣服
- 何であるか: スマルトが纏う、形の無い衣。三次元空間に散布され、フォグスクリーンと重なり合う映像投影装置でもある。
- 関係: スマルトの身体を覆い、気流操作ボタンで制御される。ボロームピクチャーズの技術によるもの。
- 引用: 「その正体は『霧』だ。」 / 「スマルトの細い身体の各所についている気流操作ボタンが霧を誘導し」

### 檻（鉄格子）
- 何であるか: スマルトのパフォーマンス中に現れる鋼鉄の構造物。囚人服を着せられたスマルトを閉じ込め、後に砕け散る。
- 関係: スマルトの「解放」と「圧」のアピールのための小道具。
- 引用: 「檻の中に閉じ込められたスマルトは囚人服を着せられて苦しげに身を捩る。」 / 「鉄格子が勢い良く砕け散ると共に」

### 着物（衣装『トリシューラ』）
- 何であるか: シナモリアキラが纏う、十二単のような派手なテイストの重めの衣装。実際は3Dプリンタ出力部品を組み合わせた装甲板であり、「杖」技術の粋。
- 関係: トリシューラの脳内図面に基づき変形し、砲身やミサイルポッドを射出する「強化外骨格（きぐるみ）」となる。
- 引用: 「和風テイストを取り入れた装甲板...それがこの服『トリシューラ』だ。」 / 「広がった布の内側から迫り出した無数の砲身とミサイルポッドが一斉に火を吹いて」

### 再生者
- 何であるか: ライブの観客。脳漿や内臓を飛び散らせるほど感情を露わにする存在。
- 関係: アイドルのパフォーマンスによって「呪力」を牽引し、会場を盛り上げる。シナモリアキラたちのアピールの対象。
- 引用: 「実際に脳漿や内蔵を飛び散らせて感情を露わにする再生者までいるほどで」 / 「再生者という観客相手だからこそできる、全力のアピール。」

### マジカルアピール
- 何であるか: アイドルが持つ「必殺」。シナモリアキラは「アピールをしない」という形式を選択した。スマルトは巨大な幻影と邪視による圧を示した。
- 関係: ランキング決定の勝敗を分ける重要な要素。トリシューラのセンスが必須とされる。
- 引用: 「『マジカルアピール』のイメージは既に固まっていた。」 / 「『マジカルアピール』はアイドルが持つ『必殺』だ。」

### カシュラム十字（懐中時計のような呪具）
- 何であるか: カーインがシナモリアキラに投擲した、カシュラム十字が刻まれた物体。凄まじい量のイメージ（記憶）を流し込む機能を持つ。
- 関係: カーインとオルヴァの修行経験のフィードバック装置。
- 引用: 「投擲されたのは、カシュラム十字が刻まれた懐中時計のような呪具。」

### ボロームピクチャーズ
- 何であるか: スマルトが専属契約を結んでいる企業。「着る立体映像」や「呪的ボディペイント」で知られる。
- 関係: スマルトの衣装技術（霧状の衣服）の提供元。
- 引用: 「スマルトが専属契約を結んでいる企業『ボロームピクチャーズ』はこうした『着る立体映像』で知られており」

### きぐるみ妖精（ブランドイメージ）
- 何であるか: シナモリアキラとトリシューラが所属するアイドルユニットのブランド名。テーマは「滅亡」「物理的暴力」「破壊にして創造」。
- 関係: トリシューラの意志が反映された衣装によって体現される。スマルトに敗北を認めさせるほどのインパクトを持つ。
- 引用: 「『きぐるみ妖精』のブランドイメージは、『滅亡』」 / 「私が一番、私たちが最高、この『きぐるみ妖精』が世界を蹂躙する破壊者の名前だ！」
