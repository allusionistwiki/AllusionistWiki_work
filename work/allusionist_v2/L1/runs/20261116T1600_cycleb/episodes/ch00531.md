# 観察ページ ch00531__5-35　呪文の座として②.md

### エレクトラ
- 何であるか: メートリアンと同一の身体を共有する存在。天眼知覚を持ち、短槍を用いる。純白の翼を持つアストラル体へ変貌する。
- 関係: メートリアンの同居者（ひとつの身体に収まったふたつの心）。クナータの姉。レナリア・Ｖ・オルガナと対峙する。
- 引用: 「短槍を手に廊下へ飛び出し、天眼知覚によって周囲を索敵。」 / 「アストラル体の昂ぶりに呼応して、エレクトラの背から純白の翼が広がる。」

### メートリアン
- 何であるか: エレクトラと同一の身体を共有する存在。杖使いであり合理主義者。亜竜人となった過去を持つ。
- 関係: エレクトラの同居者。チョコレートリリーの仲間。紀神シャルマキヒュに対して激しい敵意（逆鱗）を抱く。
- 引用: 「いつも通りの合理主義者、根っからの杖使いですという態度を貫こうとしているようだが」 / 「いまや亜竜人となった彼女の、逆鱗である。」

### リーナ
- 何であるか: メートリアンが助けたいと願っている異母姉妹。エレクトラにとっては妹（クナータ）の別名あるいは関連する存在として語られる文脈があるが、ここでは「リーナ」と呼ばれる人物を助けることが目的とされる。
- 関係: メートリアンの保護対象。エレクトラの妹・クナータと同義、または密接に関連する存在（原文では「あたしの妹はクナータ」と説明されている）。
- 引用: 「信頼関係を築いて、仲間としてリーナを助けてほしいと願っている。」 / 「あなたの妹のことを教えてくれないと、助ける計画も立てられないんですが？」

### クナータ
- 何であるか: エレクトラの妹。松明の騎士団の聖女。眼球をエストに移植され、生贄にされようとしている。
- 関係: エレクトラの妹。ティリビナ同胞団と太陰の過激派双方から狙われている。救世主トリアイナ誕生のための鍵となる存在。
- 引用: 「あたしの妹はクナータっていうんだけど」 / 「ティリビナ同胞団がクナータの眼球をエストに移植した上で生贄にしようとしてて」

### 機械女王
- 何であるか: 襲撃の背後にいると推測される存在。ターゲット（マレブランケ）を移送せず迎撃を選択する。スーリウムという怪物を従えている可能性がある。
- 関係: エレクトラが「全て機械女王の思惑通りかもしれない」と疑う対象。スーリウムの主？
- 引用: 「実際には全て機械女王の思惑通りかもしれないが」 / 「機械女王はあえてターゲットを移送せずに迎撃を選択した。」

### スーリウム
- 何であるか: 四魔女と紀人の守りすら突破してしまうかもしれないとされる怪物。
- 関係: 機械女王が従えている、または関連する存在としてエレクトラが恐怖している。
- 引用: 「エレクトラはスーリウムの恐ろしさを肌で実感している。あの怪物は四魔女と紀人の守りすら突破してしまうかもしれない。」

### ティリビナ同胞団
- 何であるか: クナータを生贄にし、マレブランケ枠の奪取による都市掌握を企てる組織。病院襲撃計画を立てている。
- 関係: エレクトラが潜伏していた場所（病院）を襲撃した勢力の一つ。クナータとエストを利用し「ティリビナ人の救世主」を生み出そうとする。
- 引用: 「ティリビナ同胞団がクナータの眼球をエストに移植した上で生贄にしようとしてて」 / 「同胞団の現在の目標はマレブランケ枠の奪取による都市の掌握ね」

### 太陰の過激派（守護の九槍のテッシトゥーラ）
- 何であるか: クナータを生贄にしつつ予備の肉体に魂を移す計画を進める勢力。第五階層での言震発生時に全員皆殺しを企てる。
- 関係: ティリビナ同胞団とは別の来訪者勢力。守護の九槍のテッシトゥーラが関与している。
- 引用: 「それとは別の来訪者がクナータを生贄にしつつ予備の肉体に魂を移す計画も進めてるけど」 / 「ちなみに守護の九槍のテッシトゥーラね」

### エスト
- 何であるか: クナータの眼球が移植された対象。母体として「ティリビナ人の救世主」を生み出すために利用される。地上との融和の旗印とされる。
- 関係: クナータの眼球を移植された存在。ティリビナ同胞団の計画の中核。
- 引用: 「ティリビナ同胞団がクナータの眼球をエストに移植した上で」 / 「シナモリアキラの議席数が過半数を超えた状態でエストを母体に『ティリビナ人の救世主』を生み出すのがティリビナ同胞団の目的だよ」

### トリアイナ
- 何であるか: クナータが死ぬことで誕生する救世主。
- 関係: クナータの死によって現れる存在。各勢力が身柄確保を争っている。
- 引用: 「クナータが死ぬことで救世主トリアイナ様がこの世界に誕生するの。」

### レナリア・Ｖ・オルガナ
- 何であるか: 銀髪ツインテール、漆黒ワンピースの女。紀人の暗殺者。ライラと互角の戦いを演じた実績を持つ。
- 関係: エレクトラらに協力（または干渉）しに来た人物。ニアホンを人質として握っている。紀神シャルマキヒュの託宣に関与している。
- 引用: 「その女の名はレナリア・Ｖ・オルガナ。ライラと互角の戦いを演じた紀人の暗殺者だ。」 / 「気安く笑いかけてくる暗殺者の女の手に、何かが握られているのが見えた。」

### ゴーリー
- 何であるか: 口から耳までを覆う鉄マスクと右半身の刺青が特徴的な巨漢。レナリアの一歩後ろに控えている。
- 関係: レナリア・Ｖ・オルガナの同行者。辺境区の迷宮刑罰者たちの一員と思われる。
- 引用: 「その一歩後ろで控えているのは口から耳までを覆う鉄マスクと右半身の刺青が特徴的な巨漢・ゴーリーだった。」

### ニアホン
- 何であるか: 携帯端末化されたエレクトラの仲間。小さな二頭身の人形のような姿。レナリアに握られ、機能停止させられている。
- 関係: エレクトラの仲間（セリアック＝ニアの関連？原文では「共犯者のセリアック＝ニア」とあるが、ここでは「エレクトラの仲間」として描写される）。レナリアによる人質。
- 引用: 「小さな二頭身の人形にも見えるそれは、携帯端末化したエレクトラの仲間である。」 / 「『にあ～』と弱々しい声で鳴くニアホンは、端末機能を停止された上で無力化されているようだった。」

### 紀神シャルマキヒュ
- 何であるか: 天眼の民に道を示す大いなる超越者。隻眼、槍、猫モチーフの耳飾りを持つ女戦士の姿で現れる。
- 関係: エレクトラとメートリアン（白き娘）に対して託宣・命令を行う存在。エレクトラが「くたばれクソ神」と罵倒し殴打する対象。
- 引用: 「紀神シャルマキヒュ。天眼の民に道を示す大いなる超越者の呼びかけだった。」 / 「容赦なく叩き込まれた正拳が、神の顔面をしたたかに打ち据えた。」

### 三角錐
- 何であるか: 精神世界におけるイメージとして現れる存在。女戦士の神（シャルマキヒュ）と一瞬同じもののように錯覚される。
- 関係: エレクトラが隣に見た存在。シャルマキヒュの像と同一視される。エレクトラの正拳で砕かれる。
- 引用: 「そこでは髪と翼とワンピースの全てが真っ白な少女が鋼鉄の三角錐と向かい合っていた。」 / 「三角錐が砕け、女戦士の頬が歪み」

### 八眼七尾の三相女神
- 何であるか: レナリアの背後に現れる異形の神像。ごうごうと吼える。
- 関係: レナリア・Ｖ・オルガナの背後に現れる存在
