# 観察ページ ch00256__4-25　星見の塔トーナメント⑧.md

### 力士
- 何であるか: アキラを抱きしめていた巨大な存在。物語の終盤で「ゾーイ」という名前が判明する。
- 関係: シナモリ・アキラを拘束していた。最終的にケイトに報告書を任せて去る。
- 引用: 「力士は抱きしめたアキラを解放していた。」 / 「ようやく終わりかー。結構長引いたよね、今回の仕事。」

### シナモリ・アキラ
- 何であるか: ガロアンディアンの主力であり、ちびセスカの使い魔。当初は道着姿の力士に抱きしめられていたが、後に壮年の男性（グレンデルヒ）として現れ、さらに元の姿に戻る演出を見せる。
- 関係: グレンデルヒ＝ライニンサルによって存在を上書き・乗っ取りされている対象。ちびセスカとの契約の証（首筋の穿孔痕）を持つ。
- 引用: 「恐るべき外世界からの刺客、力士と戦っていたシナモリ・アキラの身に何かが起きている。」 / 「彼はアキラだ。その筈だ。あらゆる事実がそれを裏付ける。」

### ちびセスカ
- 何であるか: コルセスカが病室から投射したアストラル体を宿した存在。一級言語魔術師。
- 関係: アキラの使い魔（契約者）。ニケ（フェブルウス）を前世・参照元と感じている。グレンデルヒによる記憶改竄に邪視で抵抗するが失敗する。
- 引用: 「コルセスカが病室から投射したアストラル体を宿したちびセスカは対応できずにいた。」 / 「ちびセスカにはこの相手が自分の前世であり参照元であるという事実が、ひどく遠く感じられた。」

### ちびラズリ
- 何であるか: ちびセスカの隣にいる存在。呪文使いとしてニケの呪文を相殺する役割を担う。
- 関係: グレンデルヒの名前（フルネームの一部）を言い当てる。「グレンデルヒ＝ライニンサル」と呼ぶ。
- 引用: 「絶え間なく詠唱されていく呪文を隣でちびラズリが相殺する」 / 「嫌悪感と共にその名を呼んだ。「グレンデルヒ＝ライニンサル」」

### ニケ
- 何であるか: 死人の森の女王。圧倒的な邪視を持つ存在。
- 関係: フェブルウス、カロンなどの別名を持つ同一存在。ちびセスカの前世・参照元。
- 引用: 「死人の森の女王、ニケ。」 / 「命中した無彩色の光は死人の森の女王である『ニケ』を完全に捕捉し」

### ディスマーテル・ウィクトーリア
- 何であるか: ニケの奥に隠されていた存在。ニケと同じ運命（解体）を辿ったとされる。
- 関係: ニケの内部構造の一部、あるいは関連する概念。
- 引用: 「その奥に隠されていた『ディスマーテル・ウィクトーリア』も同じ運命を辿ったのだ。」

### カロン
- 何であるか: 地獄からやってきた黒の色号使いが掌握した名前。ニケの別名の一つとして使われた。
- 関係: 魔将エスフェイルの術（下僕化）によって一時的に支配された状態の名前。水（青い河）を呼び出す呪文の源となる。
- 引用: 「新たなる名『カロン』を掌握した彼は、その手に掴み取った名前に支配力を及ばせて従属を強いる。」 / 「名前が呪文そのものとなって、夥しい量の水が虚空から流れ出す。」

### フェブルウス
- 何であるか: 死人の森の女王の本質を示す最も力のある御名。ニケの真の名前。
- 関係: グレンデルヒ＝ライニンサルと対峙し、最終的にその腕を掴まれる。ちびセスカが「奪われる者」として認識される対象でもある（グレンデルヒの視点）。
- 引用: 「死人の森の女王フェブルウス――その名前は偽名でも数ある異名の一つでもない。」 / 「グレンデルヒは傍らに立つ女王フェブルウスの腕を掴んで引き寄せると」

### (無名) 公社所属の呪術師（言語魔術師集団）
- 何であるか: 公社に所属する数人の言語魔術師。指先に灰色の輝きを宿す。
- 関係: ニケに対して「言理の妖精語りて曰く」を発動し、解体を試みるが失敗する。フェブルウスの宣名によって吹き飛ばされる。
- 引用: 「そこに、公社に所属する呪術師の支援攻撃が加えられる。」 / 「数人からなる言語魔術師の集団。」

### 言理の妖精語りて曰く
- 何であるか: 対象の本質を解析し、あらゆるものを解体する始まりの呪文。
- 関係: 灰色の輝きと共に発動される。グレンデルヒも「大量の描写こそが言語魔術師の力」として言理の妖精を掌握していることを示唆する。
- 引用: 「特徴的な起句と共に万能の呪文が発動する。「言理の妖精語りて曰く」」 / 「言理の妖精語りて曰く、大量の描写こそが言語魔術師の力である。」

### 【静謐】
- 何であるか: 灰色の輝きが構築される枠組み。確立された呪文体系の一つ。
- 関係: ニケ（フェブルウス）に対して発動されるが、「【静謐】で私の解体はできませんよ」と拒絶される。
- 引用: 「灰色の輝きはそれぞれある程度確立された【静謐】の枠組みに沿って構築され」 / 「「【静謐】で私の解体はできませんよ」」

### 魔将エスフェイル
- 何であるか: 過去に存在した魔将。特定の術（名前を掌握し下僕にする術）を得意としていた。
- 関係: その術を無名の呪術師が会得していたことが明かされる。
- 引用: 「魔将エスフェイルが得意としていた術を、この無名の呪術師もまた会得していたのだ。」

### (無名) 黒の色号使い
- 何であるか: 地獄からやってきた呪術師。古代呪術を発動する。
- 関係: カロンの名を掌握し、フェブルウスに宣名させるきっかけを作る（直接的な因果は不明だが、彼の行動後にフェブルウスが名乗り始める）。最終的に青い河に飲み込まれる。
- 引用: 「続いて地獄からやってきた黒の色号使いが今は使う者も少なくなった古代呪術を発動。」 / 「青い河に飲み込まれた呪術師は」

### グレンデルヒ＝ライニンサル
- 何であるか: 四英雄筆頭。地上最強のプロゲーマー、TCG国際大会十連覇の呪術師【カードマスター】、星見の塔トーナメント初代チャンピオン。
- 関係: シナモリ・アキラの深層人格として、キロン戦以降のアキラを演じていた（偽装）。フルネームは「グレンデルヒ＝アキラ＝シナモリ＝ライニンサル」。
- 引用: 「四英雄筆頭、グレンデルヒ＝ライニンサル。」 / 「私のフルネームは、グレンデルヒ＝アキラ＝シナモリ＝ライニンサルとでもしておこうかな。」

### ファル
- 何であるか: 眼鏡の少年。呆然として師範代（アキラ）に何が起きているのか問う。
- 関係: 状況の解説をケイトから受ける側。
- 引用: 「「し、師範代に、何が起きてるんです――？」」 / 「呆然と呟いた眼鏡の少年ファル。」

### ケイト
- 何であるか: 外世界人。トーナメントという呪術儀式を利用した即興作戦の立案者・実行側の一人。
- 関係: ファルの疑問に答える。力士ゾーイに報告書を任せる。サイバーカラテブームを沈静化させることに満足している。
- 引用: 「その疑問に答えたのは、外世界人のケイトだった。」 / 「細かいとこはよろしくね、ケイト」」

### トリシューラ
- 何であるか: きぐるみの魔女。準一級言語魔術師。
- 関係: グレンデルヒと聖婚を為し遂げた（グレンデルヒの証言による）。アキラの精密検査を忘れたとされる。サイバーカラテのステルスマーケティングを実際に行っていた
