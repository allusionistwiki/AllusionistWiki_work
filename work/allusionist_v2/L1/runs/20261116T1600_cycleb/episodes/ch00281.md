# 観察ページ ch00281__4-50　死人の森の断章3　畏怖.md

### ちびシューラ
- 何であるか: 作戦会議を主導し、グラの肉体（口）を借りて発言したり、レオに指示を出したりする存在。カシュラム人に対して偏見を持ち、「手抜き」を推奨する。
- 関係: グラの肉体を操る者。レオの指揮官。「杖の座」であることが示唆される。シューラという呼称を持つ（原文では「ちびシューラ」と「シューラ」が混在）。
- 引用: 「ミーティングは、ちびシューラによる差別発言から始まった。」 / 「グラの口を借りて言った。」

### グラ
- 何であるか: 球体関節人形。肉体を持ち、ちびシューラに操られて舞台袖や楽屋で行動する。レオと共に「書斎劇」を演じるための器となる。
- 関係: ちびシューラが操る肉体。「『下』出身」。ラクルラール（人形）から足にしがみつかれる対象。
- 引用: 「グラの口を借りて言った。」 / 「球体関節を動かしてよじ登ってくる人形は、マラードたちの物語を演じた時と同じように無表情な様子だった。」

### レオ
- 何であるか: 焦げ茶色の猫耳を持つ少年。記憶喪失。「心話」や「書斎劇（クローゼット・ドラマ）」などの呪文を使い、グレンデルヒへの情報爆撃を行う。
- 関係: ちびシューラの指示を受ける。「地獄の貴種」と呼ばれるベアトリーチェが退いた相手。「猫の取り替え子（チェンジリング）」。トリシューラやセージに指南を受けている。
- 引用: 「正体の分からない記憶喪失の少年は、焦げ茶色の猫耳を少しだけ動かして不思議そうに首を傾げた。」 / 「レオは元気よく応じると、目を閉じて精神を集中させ始めた。」

### アキラ（俺）
- 何であるか: 語り手。カシュラム人の文化や歴史を知らない。「ラクルラール」の人形と視線を交わして癒しを得る。舞台袖で暇つぶしをしている。
- 関係: ちびシューラの決定をサポートする立場。「マシュラム人」（カシュラム信仰を理解しない者）の視点を持つ。
- 引用: 「俺が、レオが、チリアットが、グラが、ラクルラールがそれぞれ頷いて」 / 「意識に見えない糸が巻き付いていくのがわかるが、あまり不快ではなく、むしろ気分がいい。ラクルラールは癒しだ。」

### ラクルラール（人形）
- 何であるか: 最高級の球体関節人形。実体があるが「あやふやな存在」であり、アキラと接触できる。足にしがみつき、糸を伸ばしてちびシューラの身体に巻き付けるなど、自律的な動きを見せる。
- 関係: アキラの癒し。「小道具」として置かれる予定。星見の塔の巨大企業体「ラクルラール」の名前を持つ（推測: 人形と組織名が同名）。
- 引用: 「足にしがみつく感触。見ると、ラクルラールが両手でグラの足に触れていた。」 / 「指から伸ばした糸をちびシューラの身体に巻き付けていた。」

### チリアット
- 何であるか: 楽屋の話し合いに参加している人物。裏方としての役割を命じられ、レオに付いてくるよう指示される。魔将の側近であったとされる。
- 関係: レオに同行する。「『下』出身」。グラやレオと同じく、レオ（猫の取り替え子）を見たのは初めてという記述がある。
- 引用: 「ちびシューラはチリアットに裏方としての役割を命じて、レオに付いてくるように言いつけると」 / 「魔将の側近であったというチリアットですらレオを見たのはここに来て始めてのことだという。」

### カシュラム（カシュート＝ラーム）
- 何であるか: 次の舞台となる場所。正式名称はカシュート＝ラーム。主役が王であり、キャカール十二賢者の第一位がいる。
- 関係: 「十九の獣による終末の予言」で知られる。「マシュラム人」と呼ばれる他者から蔑まれる集団。聖獣「槍歯虎（スピアタイガー）」が生息する。
- 引用: 「次の舞台はカシュラム――正式にはカシュート＝ラームだけど、まあどっちでもいいか。」 / 「カシュラムに固有の生物と言われる聖獣、紫色をした槍歯虎（スピアタイガー）を従えたオルヴァ王」

### オルヴァ・スマダルツォン
- 何であるか: カシュラムの王にしてキャカール十二賢者の第一位。「権力の選定者」として君臨し、畏怖されている。孤独で怯えながら暮らしている。
- 関係: 「十九の獣による終末の予言」の主役。神威により王としての権利を与えられている。聖堂で儀式を行い「ブレイスヴァ」に傅く。
- 引用: 「主役はカシュラムの王にして、キャカール十二賢者の第一位、オルヴァ・スマダルツォン。」 / 「オルヴァは【権力の選定者】として君臨し、人々から畏怖されていた。」

### グレンデルヒ
- 何であるか: 敵対勢力（死人の森側）の呪文使い。上級言語魔術師。「言理の妖精語りて曰く」というアズーリア得意の語り直し呪術を使う。
- 関係: レオとちびシューラが「書斎劇」で攻撃・妨害する対象。「冥道の幼姫」にも連絡されている（偽情報）。
- 引用: 「グレンデルヒの声がどこからともなく響く。」 / 「上級言語魔術師たるグレンデルヒは巧みに使いこなす。」

### ブレイスヴァ
- 何であるか: カシュラム人が信仰する「神のようなもの」。カシュラム人以外には説明・理解が不可能。「終端を喰らう」とされる存在。
- 関係: オルヴァ王が傅く対象。オルヴァの涙と昏倒を引き起こす。聖職者たちを発狂させる原因となる。
- 引用: 「おお、偉大なるブレイスヴァ！　我らが終端を喰らい給うな！」 / 「その『神のようなもの』をカシュラム人はカシュラム人以外に説明することができない。」

### 書斎劇（クローゼット・ドラマ）
- 何であるか: レオが唱える呪文。役者不在の演劇呪文であり、膨大な数のダミー演劇（文字情報のみ）をぶつけて相手を撹乱する。
- 関係: レオが構築し、舞台に展開される。ちびシューラも同様の手法で量産する。「アストラル界」または「グラマー界」に展開される。
- 引用: 「【書斎劇（クローゼット・ドラマ）】」 / 「あれは演じられる予定の無い劇の台本――役者不在の演劇呪文。」

### 心話
- 何であるか: レオがチャネリングで開いた伝送路を通じてグレンデルヒに共闘要請と偽の行動予定表を送信するために使う手段。
- 関係: レオが使用する通信技術。「冥道の幼姫」への連絡にも関連する（推測: 同様の通信手段）。
- 引用: 「レオ、こないだ教えたように、チャネリングで伝送路を開いて。【心話】でグレンデルヒに共闘要請と偽の行動予定表を送信」

### 冥道の幼姫
- 何であるか: グレンデルヒとは別に連絡される相手。ちびシューラが「偽の連絡」をする対象。
- 関係: グレンデルヒに傍受されることを織り込み済みの通信先。「死人の森」と手を結ぶ話に関連する（推測）。
- 引用: 「だから【冥道の幼姫】にもそれとは別の、これもまた偽の連絡をするよ。」

### ガロアンディアン
- 何であるか: 第五階層に位置する勢力。生産分野が脆弱で物流に依存している。「松明の騎士団」や「ハルベルトたち」との均衡状態にある。
- 関係: ちびシューラたちが所属・保護しようとしている勢力。「公社（ぼくら）」としても言及される。星見の塔とラクルラールからの支援に依存する。
