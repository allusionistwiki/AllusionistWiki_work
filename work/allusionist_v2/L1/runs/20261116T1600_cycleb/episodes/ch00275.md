# 観察ページ ch00275__4-44　雷が鳴っている間は.md

### 俺（シナモリ・アキラ）
- 何であるか: 物語の語り手であり、チリアットの「師範代」として振る舞う存在。左腕が食いちぎられつなぎ合わされた状態にある。
- 関係: グレンデルヒに名前を悪用されている。レオから「アキラさん」と呼ばれる。トリシューラやコルセスカを取り戻すことを目的とする。
- 引用: 「俺とチリアットは負けたのだ。」 / 「厳密には、その皮をかぶったゾーイ・アキラ。いずれにせよ俺の敵だ。」

### チリアット（牙猪）
- 何であるか: 魔将ダエモデクの側近であり無二の友人だった者。ガロアンディアン第五階層復活に関わる。
- 関係: 「師範代」を呼ぶ。「牙猪」という獣人種族の特徴を持つ。ジャッフハリムへの裏切りと逃亡という罪悪感に苛まれている。
- 引用: 「舞台袖で立ち尽くす牙猪がつぶやく。」 / 「俺はガロアンディアンの、ジャッフハリムの理念から最もかけ離れた振る舞いをしました。」

### 竜王国
- 何であるか: 物語の舞台となる国家の一つ。太陰（イルディアンサ）を襲った災厄により苦境に置かれている。
- 関係: ガロアンディアンと理念を共有する。「神々の図書館」破壊を防ぐための過去の再演が行われる場所。
- 引用: 「竜王国にまつわる物語が幕を下ろした後」 / 「太陰（イルディアンサ）を襲った災厄を解決し、『神々の図書館』が破壊されることを防いで」

### ガロアンディアン
- 何であるか: ジャッフハリムを頂点とする勢力・国家。第五階層の復活が計画されている。
- 関係: チリアットが所属していた場所。ジャッフハリムの理念（誰かの命より自分の命を優先しないこと）を持つ。
- 引用: 「ガロアンディアンを第五階層に復活させるという話を聞いて思いました。」 / 「ジャッフハリム、ひいては地獄全体に広がったということはわかった。」

### ジャッフハリム
- 何であるか: ガロアンディアンの理念を受け継ぐ存在。地獄の総大将が見ている地平とは別の地平にいるトリシューラと対比される。
- 関係: チリアットが裏切った相手（ジャッフハリムを裏切り逃亡した）。ガロアンディアンの理念の象徴。
- 引用: 「ジャッフハリムを裏切り、逃亡してしまった俺に与えられた」 / 「竜王国の、ガロアンディアンの、そしてジャッフハリムに受け継がれた理念に繋がる価値観なのだろう。」

### トリシューラ
- 何であるか: 竜王国に関わる計画を進める存在。チリアットを拾い、贖罪の機会を与えた。
- 関係: 「下方勢力」に厳密には属さない。「ちびシューラ」という小さな妖精のような姿で瞳の中にいた過去がある。コルセスカを取り戻すための鍵となる。
- 引用: 「トリシューラ様とマラコーダに拾われ」 / 「あいつが求めるものは、あの地獄の総大将が見ているものとは別の地平にある。」

### ダエモデク
- 何であるか: 魔将。チリアットの無二の友人であり、チリアットが逃亡したことで見捨てた相手。
- 関係: チリアットの罪悪感の根源。かけがえのない命を失った結果として価値を損なった対象。
- 引用: 「チリアットは魔将ダエモデクの側近であり無二の友人でもあったという。」 / 「逃亡によって、二人の間にあった価値を損なってしまったことが、苦しくてたまらないのだ。」

### 太陰（イルディアンサ）
- 何であるか: 災厄に見舞われた場所。過去の再演で解決されるべき対象。
- 関係: 竜王国が苦境に置かれた原因の一つに関わる。主役「ヴァージル」の出身地に関連する可能性が高い（王子ヴァージル）。
- 引用: 「太陰（イルディアンサ）を襲った災厄を解決し」

### 神々の図書館
- 何であるか: 破壊されることを防ぐべき対象。過去の再演の目的の一つ。
- 関係: 竜王国に降りかかる災禍に関わる重要な場所。
- 引用: 「『神々の図書館』が破壊されることを防いで、竜王国に降りかかる災禍を無かったことにしようと言うのだ。」

### ディーテ
- 何であるか: 人形劇（劇中劇）において干渉し、結末を変えた存在。
- 関係: 「俺」に対して語りかける台詞を発した。不条理な結末の原因。
- 引用: 「ディーテの干渉によって結末が変わってしまった今」 / 「ディーテは、はっきりと俺に対して語りかけてきていた。」

### グレンデルヒ（ゾーイ・アキラ）
- 何であるか: 英雄を自称する男。「死人の森の女王」と対立している。転移能力を持つ。
- 関係: 「シナモリ・アキラ」の名前を利用する。レオとグラッフィアカーネに追われている。魔導書を用いて128人の言語魔術師の力を借りる。
- 引用: 「厳密には、その皮をかぶったゾーイ・アキラ。」 / 「私と手を組まないかと言っているのだよ、シナモリ・アキラ」

### 死人の森の女王（冥道の幼姫）
- 何であるか: グレンデルヒが「あちら」と呼ぶ敵対勢力の女性。現在は「冥道の幼姫」と名乗る。
- 関係: 献身的で従順な振る舞いをして腹に企みを隠す手口を使う。主役を演じる適性がある（幼い少女）。
- 引用: 「【死人の森の女王】――今は【冥道の幼姫】と名乗っているらしい彼女は違う。」 / 「今回と前回、我々はしてやられた。またしてもあの女の一人勝ちだ。」

- 関係: 舞台袖での会話に同席していない状態にある。
- 引用: 「この劇場の女主人にはしばし席を外してもらった」

### キロン
- 何であるか: グレンデルヒと同じ「英雄」の資質を持つ存在。
- 関係: グレンデルヒの制約（最強を証明し続けなければならない）を理解する上で参照される人物。レオと対比される「本物の英雄」。
- 引用: 「つまり、こいつはキロンと同じ英雄だということだ。」 / 「それは、キロンやグレンデルヒといった本物の英雄と対峙しても揺るがない」

### グラッフィアカーネ（グラさん）
- 何であるか: ビークル犬を思わせる頭の若者。トライカラーの虹犬種。ガロアンディアン風の和装を着る。
- 関係: レオと共に「俺たち」を助けるために現れた。グレンデルヒを追跡・攻撃する。魔将サイザクタートの幼なじみでアズーリアへの復讐心を抱く。
- 引用: 「空間が歪み、怒りの声と共に現れたのはビークル犬を思わせる頭の若者だった。」 / 「俺は、ただグレンデルヒを倒したかっただけです」

### レオ
- 何であるか: グラッフィアカーネより若い少年。特徴的な二つの兎耳を持つ。
- 関係: 次の舞台の主役「ヴァージル」役を志願する。「アキラさん」の音を辿って場所を探り出した。純白の耳を持ち、無彩色の服を着る。
- 引用: 「彼がやってきた空間の穴から、もうひとりが「よいしょ」とばかりに現れる。」 / 「レオ？！」

### ヴァージル
- 何であるか: 太陰の王子。耳長の民（兎に似た種族）。次の舞台の主役。
- 関係: 体格や声の問題でチリアットやグレンデルヒには不向きだが、レオが適任とされる。
- 引用: 「それは次の舞台の主役、太陰の王子ヴァージルが線の細い少年であることに起因している。」
