# 観察ページ ch00321__4-90　一時の平穏②.md

### アキラくん
- 何であるか: 物語の視点人物（俺）。義体として存在しており、外見をトリシューラやルウテトから批評されている。髪型が「エム字バング」だと指摘され、マラードによって散髪される。
- 関係: トリシューラの主従関係にある（推測: 「主に付き従う」という記述より）。ルウテトの義体として存在している。レオ・ウィーナーと会話する。
- 引用: 「うーん、なんか違うよねアキラくん」 / 「ドエムしか合ってないよ」

### トリシューラ
- 何であるか: アキラくんの主。ちびシューラの上位概念（推測: 「ちびシューラの検索情報によると」という記述から、ちびシューラはトリシューラの側面・分身と思われる）。戦勝祝賀会やトーナメント表彰式を強引に開催する。
- 関係: ルウテトと対話する。マラコーダの主人（陛下）。アキラくんの主。レオ・ウィーナーとカーインのやり取りを見ている。
- 引用: 「トリシューラとルウテトは、俺の方を見て揃って眉根を寄せていた。」 / 「ちゅうもーく！　これから戦勝祝賀会と星見の塔トーナメント表彰式とガロアンディアンと死人の森同盟の親睦会を開催しまーす！」

### ルウテト
- 何であるか: 六王を従える存在。アキラくんの義体の外見決定権を持つコルセスカが「裏に引っ込んでいる」。髪、耳、口、歯などから六王や配下たちが現れる場所となる。
- 関係: トリシューラと対話する。マラード、オルヴァ、ヴァージル、アルト、パーン、カーティスなどの主（姫君）。クレイの主人。
- 引用: 「義体にはコルセスカのテクスチャ呪術によって現実同然の質感が張り付けられている。」 / 「ルウテトの髪の中から小さな半透明の影が現れる。」

### ちびシューラ
- 何であるか: アキラくんの内側（視界隅など）に存在する、検索情報や補足説明を行う存在。トリシューラのハンドルネーム「ノーレイ」を知っている。法務シューラ直轄のお役所シューラを動かしてレオに姓を与えた。
- 関係: トリシューラの側面・分身（推測）。アキラくんに冷たい視線を送る。マラードの評価について情報を提供。
- 引用: 「ちびシューラの検索情報によると、マラードは決して評価の高い王ではない。」 / （あ、住民登録とか不便だから法務シューラ直轄のお役所シューラが命名しといたよ。）

### マラード
- 何であるか: 六王の一人。ラフディの民。美貌を誇り、ルウテト（姫君）に熱狂的な愛慕を捧げる。「暗君の代表格」として歴史的評価されるが、配下のルバーブからは尊敬されている。散髪が得意。
- 関係: ルウテトの従僕。ルバーブの主。オルヴァと仲が悪い。アキラくんの髪を整える。
- 引用: 「現れるや否や主を口説き始めた六王の一人は、すげなくあしらわれていた。」 / 「ラフディの民が髪を扱わせたら世界一だということを教えて差し上げよう」

### ルバーブ
- 何であるか: マラードの配下。ふっくらとした体型の中年男性。マラードの道具（散髪用の鋏など）を用意し、呪力を込めて実体化させる有能な従僕。
- 関係: マラードの従僕。アキラくんと視線が噛み合い、「世話になった」と挨拶する。
- 引用: 「マラードの言葉に応えてルウテトの頭髪から現れたのは、ふっくらとした体型の中年男性だ。」 / 「陛下は素晴らしいお方だ。愛情深く、美しいものを尊ぶその気質はラフディの華やかな文化をより一層精錬させた。」

### コルセスカ
- 何であるか: ルウテトの裏に引っ込んでいる存在。アキラくんの義体の外見（テクスチャ呪術）の決定権を持つ。感情を吸う機能があるらしい。
- 関係: ルウテトの一部・側面。トリシューラと話し合って取り決めをした（推測: 「トリシューラと話し合ってそういう取り決めにしたとか」）。
- 引用: 「どんな外見にするかはルウテトの裏に引っ込んでいるコルセスカに決定権があるらしい。」 / 「コルセスカに感情を吸ってもらわないと。」

### オルヴァ
- 何であるか: 六王の一人。ブレイスヴァの鼻先を持つ（十字の瞳）。マラードと歴史的経緯により仲が悪く、挑発し合う。
- 関係: ルウテトの従僕。マラードの敵対者。ルウテトの口から現れる。
- 引用: 「ルウテトの口の中から飛び出したのは、十字の瞳を持った男。」 / 「また貴様か老害オルヴァめ。」

### ヴァージル
- 何であるか: 六王の一人（推測: 「小さな王たちが現れ始める」直後に登場するため）。垂れ耳ウサギのような少年。愛らしい美少年で、レオよりかわいいとアキラくんに思わせる存在。
- 関係: ルウテトの従僕。ルウテトの長い耳から現れる。レオ・ウィーナーと比較される。
- 引用: 「垂れ耳ウサギのような少年の名は、ヴァージルといった。」 / 「愛らしい美少年は、長くてふさふさの白い耳を持ち上げて叫ぶ。」

### アルト
- 何であるか: 六王の一人。無骨軍人タイプ（推測: アキラくんの髪型批評で「アルト系の無骨軍人タイプ」と言及されているため）。ルウテトの歯から現れる。
- 関係: ルウテトの従僕。ダエモデクの魂を持つ牙猪の戦士と会話する。
- 引用: 「その後もアルトが特になにも言わずにルウテトの歯の中から現れたり」 / 「おお、アルト王よ。拝謁の栄に浴し恐悦至極にございます」

### パーン・ガレニス・クロウサー
- 何であるか: 六王の一人（推測）。つむじの上に浮遊する存在。レオ・ウィーナーとカーインに対して高圧的な態度を取り、レオに名乗りを要求する。
- 関係: ルウテトの従僕。レオ・ウィーナーと対立する。カーインを所有物だと主張する。
- 引用: 「パーンがつむじの上に浮遊して意味もなく部屋全体を見下ろしたり」 / 「このパーン・ガレニス・クロウサーが問うてやろう。名乗れ」

### カーティス
- 何であるか: 六王の一人（推測）。影から現れる。杖の最新機器に驚き、トリシューラを質問責めにする。
- 関係: ルウテトの従僕。トリシューラに質問する。
- 引用: 「影から出てきたカーティスが室内にあった杖の最新機器に驚いて「これは何だい？」とトリシューラを質問責めにしたり」

### レオ・ウィーナー
- 何であるか: 公社組の一員。子供（赤ちゃんのお世話や躾ができる）。カーインの護衛。法務シューラ直轄のお役所シューラにより姓「ウィーナー」を与えられた。
- 関係: アキラくんの仲間（推測: 「うちのレオの方が絶対かわいい」と言及）。カーインを保護する。パーンと対立する。
- 引用: 「ついでにレオとカーイン、セージという公社組まで追加で到来。」 / 「レオ・ウィーナーです。あと、カーインを足蹴にするのやめてください。」

### カーイン
- 何であるか: 公社組の一員。誇り高い武人。パーンに所有物だと主張されるが、レオに保護されている。
- 関係: レオ・ウィーナーの被護衛者。パーンと対立する。
- 引用: 「ついでにレオとカーイン、セージという公社組まで追加で到来。」 / 「誇り高い武人である彼に屈辱を味わわせる事は僕が許しません」

### セージ
- 何であるか: 公社組の一員。レオ、カーインと共に到来する
