# 観察ページ ch00484__5-10　夜明け前の沈黙①.md

### セラメル
- 何であるか: 松明の火を操り、炎を纏って戦う女性。両腕に炎を纏い、巨大な金槌を振るう。
- 関係: ユディーアの仲間。ノゴルオゴルオと対峙し、挑発的な言葉で応酬する。「とんかちセラメル」と呼ばれる。
- 引用: 「セラメルが霊薬を飲み干しながら叫んだ。」 / 「私がそのディスケイムって姓を見たのはこれで三度目だ。」

### ユディーア
- 何であるか: 鉤爪を用いて戦う亜竜人。「空圧」や「槌」などの呪文を使う。過去視の能力を持つ。
- 関係: セラメルと共に行動する。ノゴルオゴルオから「キニス」と呼ばれる。ディスケイムの血族であることが判明する。
- 引用: 「ユディーアは抗毒呪符を取り出しつつ迫り来るキノコ人たちの成れの果てを迎え撃つ。」 / 「おめえを灰色に使い分けるだよ、キニス」

### キノコ人（マイコニド）
- 何であるか: ティリビナ人の一種。半球状に膨らんだ頭部と傘を持つ巨大な怪物。影の中に霊的菌糸体を持つ。
- 関係: 敵として襲いかかる。カマソッソ氏族に裏切られ、憎しみを抱いている。「陰花族」と蔑称される。
- 引用: 「屹立する巨影はさながら陽光を遮る傘頭巾（パイリアス）。」 / 「キノコ人（マイコニド）という種族はティリビナ人の一種とされているが」

### ハエの使い魔
- 何であるか: 巨大なハエ。毒と瘴気を使うキノコ人に誘われて殺到し、絶命したが後に動き出す。
- 関係: 散布された黒紫の呪毒を浴びて身体の一部が隆起し、脈動している。「瘤」により使い魔化されている疑いがある。
- 引用: 「放し飼いにされていたハエの使い魔たちだ。」 / 「あの瘤が虫たちを使い魔に仕立て上げているのだろうか？」

### ノゴルオゴルオ
- 何であるか: 岩肌種（双頭人）。方言を使う呪術師。「ディスケイム」姓を持つ。巨大な口を開けて笑う。
- 関係: 敵の首謀者。ユディーアと取引を持ちかける。魔将ベフォニスの関係者。大魔将イェレイドの生みの親。
- 引用: 「ノゴルオゴルオはディスケイムとして語りかけてくる。」 / 「ああ、イエレドか？　あれはおらたつの傑作のひとつだよ。」

### カマソッソ氏族
- 何であるか: アヴロノ社会における吸血鬼混じりの氏族。「コウモリ妖精」と呼ばれる。下水道で暮らし死体処理を担う。
- 関係: 「十戒」の構成氏族の一つ。キノコ人を裏切り、利用した。ネビロン氏族の手足となる。
- 引用: 「主に二つの氏族で成り立っている。黒肌のネビロン氏族と吸血鬼混じりのカマソッソ氏族だ。」 / 「彼らが裏社会に吸収され、ネビロン氏族の手足となるのは必然だった。」

### ネビロン氏族
- 何であるか: 黒肌のアヴロノ氏族。「十戒」の構成氏族の一つ。
- 関係: カマソッソ氏族と共に犯罪組織を形成する。カマソッソ氏族はネビロン氏族の手足となる。
- 引用: 「主に二つの氏族で成り立っている。黒肌のネビロン氏族と吸血鬼混じりのカマソッソ氏族だ。」

### ディスケイム
- 何であるか: 秩序派血統魔術師の思想集団。「純血の多様性」を維持しようとする。姓としても存在する。
- 関係: ユディーアとノゴルオゴルオが所属（または由来）する。大魔将イェレイドもこの名を持っていた。
- 引用: 「ディスケイムとは複数系統の秩序派血統魔術師によって『純血の多様性』を維持しようとする思想集団だ。」 / 「あんたの長ったらしい姓の中に混じってる『ディスケイム』ってのは」

### アルティウス
- 何であるか: ガロアンディアンの王候補。「竜牙槍」。ユディーアの予備（保険）として位置づけられている。
- 関係: ノゴルオゴルオ、ライラ、スーリウムが戴こうとしている王。ユディーアと王位を巡って争う予定。
- 引用: 「おらたつ、ライラ、スーリウムは『竜牙槍』のアルティウスをガロアンディアンの王に戴くつもりだ。」 / 「アルティウスがあたしを殺せば裏切りの契約は消えるし」

### ライラ
- 何であるか: 虹犬の貴婦人。ユディーアと交戦した神の子の一人。
- 関係: ノゴルオゴルオ、スーリウムと共にアルティウス擁立を企てる。ユディーアをアルティウスの試練と説明している。
- 引用: 「虹犬の貴婦人ライラと交戦し、過去の一部を読みとったユディーアにはわかる。」 / 「おらたつ、ライラ、スーリウムは『竜牙槍』のアルティウスをガロアンディアンの王に戴くつもりだ。」

### スーリウム
- 何であるか: 神の子の一人。機械女王暗殺を企てている。
- 関係: ノゴルオゴルオ、ライラと共に行動するが、独自に暗殺を企てる。ノゴルオゴルオはスーリウムを抑える役割を担う。
- 引用: 「スーリウムが独自に機械女王暗殺を企ててるのはこっちでも把握してる」 / 「おらたつ、ライラ、スーリウムは『竜牙槍』のアルティウスをガロアンディアンの王に戴くつもりだ。」

### クナータ
- 何であるか: 聖女（救世主）。アルティウスが守っている。
- 関係: ノゴルオゴルオが確保しようとしている存在。「祝祭の終わりまでは誰にも渡さねえし傷つけさせねえ」とされる。
- 引用: 「安心しろ、聖女はアルティウスが守ってる。」 / 「救世主を巡る争奪戦の過程で共闘を選んだ」

### 十戒
- 何であるか: アヴロノによって構成された犯罪組織。主にネビロン氏族とカマソッソ氏族で成り立つ。
- 関係: カマソッソ氏族が裏社会に吸収されることで形成された。キノコ人を迫害・利用する背景にある組織。
- 引用: 「『十戒』はアヴロノによって構成された犯罪組織だが、主に二つの氏族で成り立っている。」

### ティリビナ人
- 何であるか: 樹木系の種族が多数派を占める民族。キノコ人はその一種とされる。
- 関係: 多数派の樹木系ティリビナ人が、陰花族（キノコ人）を蔑視している。ユディーアは亜竜人であり、この文脈で語られる。
- 引用: 「キノコ人（マイコニド）という種族はティリビナ人の一種とされているが」 / 「多数派の樹木系ティリビナ人から陰花族と蔑まれていた。」

### 長老樹（エルダー）
- 何であるか: ティリビナ社会における重要な存在。根に取り付いて養分や穢れを吸い取る対象。
- 関係: キノコ人の習性として、その根から呪力を得る姿が軽蔑の対象となっている。
- 引用: 「キノコ人たちには長老樹（エルダー）の根に取り付いて養分や穢れを吸い取るという習性がある。」

### 燐血の民
- 何であるか: セラメルが所属する民。白い炎で全身を覆い、瘴気を払う加護を持つ。
- 関係: セラメルの肉体を蝕む黒紫の呪力に対し、加護によって対抗している。
- 引用: 「燐血の民としての加護によって白い炎が全身を覆って瘴気を払うが」
