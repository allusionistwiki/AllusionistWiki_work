# 観察ページ ch00308__4-77　トリシューラ・カムバック②.md

### ネドラド
- 何であるか: 修道騎士であり、現在は「再生者」として女王の理想に従って戦う存在。波動のエネルギーを操り、拳で攻撃するが、トリシューラの一撃で拳を砕かれ血を流している。
- 関係: トリシューラの敵として対峙し、アズーリア・ヘレゼクシュと戦闘状態にある。ガロアンディアン（文明社会）の破壊を目的としている。
- 引用: 「必殺の一撃を繰り出したはずのネドラドが大きく飛び退った。」 / 「僕はもう修道騎士であることを捨てた。いずれにせよ、この身は既に再生者だ。」

### トリシューラ
- 何であるか: アンドロイドの魔女。真紅の髪と緑色の瞳を持ち、黒銀の肌に贄の血肉が蠢動する。球形の障壁から上半身を覗かせてネドラドを観察している。
- 関係: ネドラドを「杖の担い手として、観察者（ウォッチャー）として」見つめている。アズーリア・ヘレゼクシュによって治療される対象であり、「ノーレイ」という別名を持つ。
- 引用: 「透徹たる無表情。真紅の髪、緑色の瞳。黒銀の肌に蠢動する贄の血肉。」 / 「トリシューラは球形の障壁から上半身を覗かせて、じっとネドラドを見つめている。」

### アズーリア・ヘレゼクシュ
- 何であるか: 漆黒の全身鎧を纏った黒騎士。頭部から禍々しい呪力を発する枝角が生えている。粗野な口調と少年のような声を操る「文彩（レトリック）の魔女」。
- 関係: トリシューラを治療し、ネドラドと戦う。「アズ公」と呼ばれることもある。ハルベルトの同盟相手であり、ミルーニャやセリアック＝ニアと連携している。
- 引用: 「漆黒の全身鎧を身に纏った物々しい姿をしていた。」 / 「禍々しい呪力を発する枝角が、頭部から伸びているのだ。」

### 黒騎士
- 何であるか: アズーリア・ヘレゼクシュが着用している鎧の形態。松明の騎士団の新型神働装甲を基調とした夜の民仕様のもの。背が低く、足下の影から触手を蠢かせている。
- 関係: アズーリア・ヘレゼクシュの正体を示す外見的特徴（枝角など）を持つ。ネドラドの攻撃を影の触手で回避する。
- 引用: 「影から現れた黒騎士は、鋭角な部品を組み合わせた甲冑の至る所から黒い靄を立ち上らせ、足下の影から触手を蠢かせている。」

### 波動
- 何であるか: ネドラドが操るエネルギー。遠距離からの攻撃や拳に纏わせることで威力を発揮する。神働装甲に触れれば破壊できる性質を持つとされる。
- 関係: ネドラドの主要な戦闘手段。アズーリア・ヘレゼクシュの影の呪術によって減速符などで阻害される。
- 引用: 「自らを奮い立たせるように、怒りを思い出そうとするように雄々しく叫び声を上げる。」 / 「波動を足裏から噴射して上昇しようとするも、減速符が重ねて発動してその動きが遅延。」

### 触手
- 何であるか: 夜の民が得意とする呪術によって生成される影の一部。ネドラドの足を束縛したり、床から奈落のような口を開いて飲み込んだりする。
- 関係: アズーリア・ヘレゼクシュ（黒騎士）が操る。ネドラドを拘束し、戦闘を有利に進めるために使用される。
- 引用: 「夜の民が得意とする呪術。」 / 「重力が触手となって彼を束縛。」

### 呪符
- 何であるか: 爆発を起こす紙片のような物体。ネドラドの体勢を崩したり、影の内部から撒き散らされたりする。
- 関係: アズーリア・ヘレゼクシュが投擲し、戦闘の補助として使用される。
- 引用: 「投擲された呪符が爆発してネドラドの体勢を崩し」 / 「影が爆発して、内部から大量の呪符が撒き散らされる。」

### 神働装甲
- 何であるか: 松明の騎士団が採用している新型の鎧。杖の産物であり、触れれば一撃で破壊できるとされる。アズーリア・ヘレゼクシュはこれを夜の民仕様に変換して着用している。
- 関係: アズーリア・ヘレゼクシュの装備。通信機能（グロートニオン結晶）を備えている。
- 引用: 「鎧の作りは松明の騎士団が採用している新型の神働装甲を基調としたもので、黒い色彩は夜の民仕様のものだ。」 / 「神働装甲は杖の産物ゆえに触れれば一撃で破壊できる。」

### グロートニオン結晶
- 何であるか: 神働装甲に備わった通信機能の一部。呪力を灯して輝き、空間を越えた通信を可能にする。
- 関係: アズーリア・ヘレゼクシュがミルーニャと通信するために使用される。
- 引用: 「神働装甲に備わった通信機能が作動した。ざざっとノイズが走って、空間を越えて通信が入る。グロートニオン結晶が呪力を灯して輝く。」

### ミルーニャ
- 何であるか: アズーリア・ヘレゼクシュと通信する人物（声）。月にいる「きぐるみ女」の監視や、マゼンタの人形兵団への対処を任されている。
- 関係: アズーリア・ヘレゼクシュの協力者。「アズーリア様」と呼ぶ。敵がトライデントであることを報告する。
- 引用: 「（こちらミルーニャ。アズーリア様、確認とれました！　月にいるきぐるみ女、あれやっぱり偽物です。」」

### ハルベルト
- 何であるか: アズーリア・ヘレゼクシュの師匠（お師様）であり、同盟の中心人物。「ハル」と呼ばれる。理想的な世界を作り出すことを約束している。
- 関係: アズーリア・ヘレゼクシュに指示を出し、トリシューラとの関係構築を促している。ファルファレロの指揮官でもある。
- 引用: 「ハルが貴方たちに勝ったら、きっと私のお師様は理想的な世界を作り出す。」 / 「今の名前はファルファレロ、だっけ？」

### ファルファレロ
- 何であるか: ガロアンディアンの内情を探ることを命じられた間諜。第五階層で活動している少年。燃える翼の紋様（アイコン）を通じてアズーリアと会話する。
- 関係: ハルベルトの部下。「師兄」「師姉」と呼ぶことに戸惑いを見せる。トリシューラを「大姐」と呼び、得体が知れないと恐れている。
- 引用: 「今の名前はファルファレロ、だっけ？」 / 「第五階層でファルファレロと呼ばれている少年は、怯えを声に滲ませながら不安を吐露した。」

### 兎（幻獣）
- 何であるか: 黒騎士の影から現れる白と黒に染まった兎。角が生えている。アズーリアに分身のリソース提供や録音などを指示する。
- 関係: アズーリア・ヘレゼクシュの使い魔または幻獣。トリシューラへの「記憶」の封じ込めを指示する。
- 引用: 「その時黒騎士の影からぴょこんと長い耳が現れた。白と黒に染まった兎が、二人に向かってとある提案を行う。」

### 射影即興喜劇（アトリビュート）
- 何であるか: アズーリア・ヘレゼクシュの固有呪術。「真紅玉髄（カーネリアン）」や「真翠玉（エメラルド）」などの宝石を参照して発動し、対象を修復する。
- 関係: トリシューラの機械的な身体を生命の光で治癒するために使用される。「命名規則」はセリアック＝ニアと相談して決められている。
- 引用: 「射影即興喜劇（アトリビュート）――」 / 「その力は、信じがたい奇跡を引き起こしていた。」

### 真紅玉髄（カーネリアン）
- 何であるか: アズーリア・ヘレゼク
