# 観察ページ ch00332__4-101　皆殺しのデーデェイア②.md

### セージ
- 何であるか: 古き神を降臨させる器（依代）となった少女。眼球が裏返り赤一色に染まり、上品な口調で微笑む。下半身が異形化し、最終的に溶けて消失する。
- 関係: デーデェイアの依代。カーインによって経絡秘孔を突かれ解放される。レオが上着をかける。
- 引用: 「セージの眼球がぐるんと裏返る。」 / 「古き神をその身に降臨させたセージは余りにも強すぎた。」

### デーデェイア
- 何であるか: セージに降臨した破壊と殺戮の女神。青い蛸足（触手）を持ち、上品な口調で「皆殺し」を実行する。「殺すな」という命令を詭弁で解釈し、毒注入や間接的な殺戮を行う。
- 関係: セージに憑依している。ブウテトを殺害・再生のループに陥れる。イアテムを殺害する。幻肢による攻撃でセージから追い出される。
- 引用: 「受肉したデーデェイアがブウテトをまじまじと見つめながら両手を合わせた。」 / 「久しぶりの皆殺しですねっ、嬉しいですっ！」

### ブウテト
- 何であるか: 第五階層の女王（キュトス様）。生と死を司る女神としての力を持ち、殺されても即座に再生する。戦闘後、雌の豚の姿に変貌する。
- 関係: デーデェイアに執着され殺害される。ミヒトネッセの「投影」により発情状態（背圧反応）になる。トリシューラが背中に乗る。
- 引用: 「ブウテトの前に立ち塞がったクレイが一撃で吹っ飛んでいき、小さな六王たちもあっさりと薙ぎ払われてしまう。」 / 「そこに豚がいた。豚鼻の美しい女王ではない。雌の豚である。」

### トリシューラ
- 何であるか: 戦闘用ドローンを操作する人物（女性）。悪辣な性格とされるが、天使のような存在として信仰されている側面もある。「ちびシューラ」という二頭身の姿で戦術支援を行う。
- 関係: 俺（アキラ）と背中合わせで戦う。マラコーダを支援する。ブウテトの背中に乗って生理的状態を確認する。
- 引用: 「まずトリシューラが操作する戦闘用ドローンが全てスクラップに変えられて」 / 「視界隅で憤慨した二頭身が翼を生やしてエンジェルシューラになる。」

### ちびシューラ
- 何であるか: トリシューラの二頭身の姿（アバター/側面）。【サイバーカラテ道場】を経由して戦術パターンを展開し、周囲を警戒する。トリシューラと同期して実体行動を行う。
- 関係: トリシューラの側面。ブウテトの発情状態を「背圧反応」として解析・報告する。
- 引用: 「ちびシューラの補足情報によると、神には天災などを司る荒ぶる高次存在としての側面があるという。」 / 「（雌性ホルモンであるエストロゲンやプロゲステロンがドバドバで…）」

### 俺（アキラ）
- 何であるか: 主人公。左腕を義肢（換装可能）としており、【幻肢の力】アプリを用いて水蒸気による攻撃を行う。デーデェイアの霊体内部に幻影の掌打を放つ。
- 関係: カーインと協力してデーデェイアを撃退する。トリシューラと背中合わせで戦う。ブウテト（豚）の足下に立つ。
- 引用: 「俺は銃を構えたトリシューラと背中合わせになって使い魔たちと戦いながら」 / 「幻肢憑依・汽力発勁！」

### カーイン
- 何であるか: 左腕をガードしていたが粉砕された人物。額から血を流しながらも立ち上がり、セージの経絡秘孔を狙う貫手の連撃（44打）を行う。第五階層で並ぶ者無しの実力を持つ。
- 関係: クレイの舞踏で身体能力を強化される。レオに感謝され恐怖する。デーデェイアを追い出す本命の役割を果たす。
- 引用: 「カーインがガードした左腕ごと全身の骨を粉々にされながら吹き飛ばされ」 / 「都合四十四もの打撃を一瞬のうちに放ったカーインはそこで力を使い果たしたかのようにぐらりと倒れ伏す。」

### クレイ
- 何であるか: ブウテトに仕える人物。端整な顔立ちで、ブウテトを「陛下」と呼ぶ。舞踏（肉体言語）によって他者の身体能力を強化する術を使う。
- 関係: デーデェイアの一撃で吹っ飛ぶが、気力で持ち直す。カーインと俺の強化を行う。ブウテトが豚になったことに哀れみを抱く。
- 引用: 「心底忌々しげに吐き捨てたのはクレイ。」 / 「クレイの肉体言語は他者の強化もできる。」

### イアテム
- 何であるか: デーデェイアを呼び出した海の司祭（僣主）。デーデェイアに「殺すな」と命じるが、致死毒を注入され、最終的に触手で握り潰され頭部ごと粉砕される。分身を作る能力を持つ。
- 関係: デーデェイアの召喚者。ブウテトらの怨敵。デーデェイアの詭弁により殺害される。巨大な剣の幻影を通じて遠隔から狙っている可能性が示唆される。
- 引用: 「凄まじい速度で伸縮した触腕が倒れていたイアテムを掴み、デーデェイアの近くに引き寄せる。」 / 「頭部ごと粉砕されたイアテムは、断末魔すら無いまま絶命した。」

### マラコーダ
- 何であるか: 使い魔との戦いを強いられる人物。尻尾を使い魔に突き刺して【呪毒】を発動する。傷付きながらも立ち上がり、【マレブランケ】のメンバーを率いて足止めを行う。
- 関係: トリシューラの射撃支援を受ける。俺と共闘する。
- 引用: 「身を低くして滑るように敵に接近したマラコーダが尻尾を使い魔に突き刺して【呪毒】を発動。」

- 引用: 「ファルファレロはそれを見て失禁しながら気を失った。」

### レオ

- 引用: 「レオがいつの間にか近付いて来ていた。」 / 「猫耳をへなりとさせて項垂れるレオに」
