# 観察ページ ch00132__3-13　言の葉遣いは躊躇わない⑧.md

### アズーリア・ヘレゼクシュ
- 何であるか: 物語の語り手であり、ハルベルトの弟子。顔の認識が苦手だが、声や立ち居振る舞いで個人を識別する能力を持つ。呪文詠唱と杖術を用いる。
- 関係: ハルベルトの弟子。メイファーラ、ミルーニャと共に行動する。ナトから「アズーリア・ヘレゼクシュ」と名指しで罵倒される。
- 引用: 「アズ、調子はどう？」 / 「言わせておけば貴様っ、アズーリア・ヘレゼクシュ！」

### ハルベルト
- 何であるか: アズーリアの師。フードに包まれた顔をしており、辛辣で平坦な口調、常に怒っているようなぶっきらぼうな態度をとる。「天眼の民」ではないが、呪文構成の完成度が高い。
- 関係: アズーリアの師匠であり、試験官。アズーリアに対して「出来の悪い弟子は嫌い」と述べる。メイファーラ、ミルーニャと共にアズーリアを指導・支援する。
- 引用: 「すぐ隣で、師から厳しい視線を向けられているのを感じた。」 / 「ぎりぎり及第点。そのレベルでチャネリングが出来るのなら、最初からやって欲しかった」

### メイファーラ
- 何であるか: 「天眼の民」であり、「松明の騎士団」序列二十九位。軽やかな声と眠たげな目つきを持つ。短槍と盾を用い、カウンター主体の前衛（斥候兼盾役）として戦う。超感覚で敵を察知する。
- 関係: アズーリアの仲間であり、ハルベルトの指導下にある。ナトの攻撃端末を短槍で弾き返すなど、防御と索敵を担う。
- 引用: 「軽やかながらも芯の通った声。すっきりとしていて綺麗めな顔立ちだけど、目だけがいつも眠たげにとろんとしているのがちょっと勿体ない。」 / 「【天眼の民】特有の超知覚は索敵のみならず戦闘においても凄まじい恩恵をもたらす。」

### ミルーニャ
- 何であるか: 童顔だが戦いになると邪視のような眼光に変貌する射手。左手に握り、二又に分かれた棹とゴム紐を持つ投石器（スリングショット）を操る。「豆（ビーンズ）」と呼ばれる呪石の弾丸を発射する。
- 関係: アズーリアの仲間。ハルベルトの指示に従い、空中の敵（天槌虫など）を撃破する役割を担う。
- 引用: 「左手に持った握りを上空に向け、二又に分かれた棹の両端から伸びるゴム紐の枠を強く引っ張る。」 / 「投擲という呪術を発動させた。」

### ナト
- 何であるか: 修道騎士の鎧に身を包んだ男。序列二十六位。背中に取り付けた遠隔操作型の攻撃端末（合計三個）と使い魔（鴉）を操る。アズーリアに対して強い敵意と嫌悪を抱いている。
- 関係: アズーリアたちに対する妨害者（敵）。ペイルたちとは別行動をとっている。「三本足の民」であり、使い魔を自身の一部として認識している。
- 引用: 「修道騎士の鎧に身を包んだ男、ナトが立っていた。」 / 「高度な空間把握能力と繊細な呪具制御能力。複合的な呪術適性が必要とされる遠隔操作型の攻撃端末を三つ同時に扱い、更に優秀な使い魔まで操るナトの実力は序列二十六位と認められるだけのことはあった。」

### 鴉（使い魔）
- 何であるか: ナトの使い魔。太陽から放たれる紫外線を知覚できる「天眼の民」のような視力を持つ。「松明を掲げし者ピュクティエトの子ら」と称される聖なる鳥。金箒花を奪い、アズーリアたちを襲撃する。
- 関係: ナトが操る存在。ナトにとって「三本目の手足」であり、見捨てられることを極度に恐れている。アズーリアによって紫外線操作と拘束呪術で捕獲される。
- 引用: 「大きな鴉が三度目の強襲を仕掛けてくる。」 / 「曰く太陽の使者。曰く松明を掲げし者ピュクティエトの子ら。」

### トントロポロン
- 何であるか: 白いプディング状の長方形をした害獣猛獣。人の頭部ほどの大きさで、のろのろと俊敏、ぷよぷよして硬い。人を襲う凶暴性を持つが、外見は人畜無害そうに見える。
- 関係: アズーリアの呪文小試験の標的。電子レンジ内のレトルト食品のように加熱され、体内の水分を沸騰させて仕留められる。
- 引用: 「白いプディング状のそれは、自然界には滅多に存在しない長方形をした害獣トントロポロン。」 / 「その憤激によりて我が怨敵を電子レンジ内のレトルト食品のごとくチンせしめん！」

### 天槌虫
- 何であるか: 巨大な角と甲殻を持つ巨大な昆虫。鴉によって遠くから追い立てられ、呼び寄せられた怪物の一つ。
- 関係: アズーリアたちに対する敵。ミルーニャの呪石弾による爆炎で焼き払われる。
- 引用: 「天槌虫が三、人面鳥が二！」 / 「巨大な角と甲殻を有する巨大な昆虫」

### 人面鳥
- 何であるか: 乱杭歯から涎を垂らして殺到する霊長類に似た頭部の怪鳥。鴉によって呼び寄せられた怪物の一つ。
- 関係: アズーリアたちに対する敵。メイファーラの短槍の一刺しで仕留められる。
- 引用: 「乱杭歯から涎を垂らして殺到する霊長類に似た頭部の怪鳥がこちらに向かってきてた。」 / 「人面鳥を串刺しにしたメイファーラとハルベルトが手を突き上げ」

### 金箒花
- 何であるか: 群生地が存在する植物。鴉がこれを奪って消え、アズーリアたちがその近くで戦闘を行う場所となる。
- 関係: 戦闘の舞台となる場所の指標。メイファーラが探し当てた。
- 引用: 「メイファーラが探し当てた金箒花の群生地。」 / 「鴉は金箒花を奪って消えた後、さほど長い間を置かずに戻ってきていた。」

### 魔導書
- 何であるか: アズーリアが使用する呪術の媒体。項から呪文の文字列を射出する「平行詠唱」に使用される。
- 関係: アズーリアの所持品。自動鎧（案山子）として機能させるための遠隔操作にも関連している。
- 引用: 「私は身体の陰に隠すようにして魔導書を開き素早く精神集中に入る。」 / 「自ら呪文を唱えながら同時に項からも呪文の文字列を射出する。平行詠唱。」

### 杖
- 何であるか: アズーリアが使用する呪術の媒体。光の帯を操り、拘束の呪術を発動させるために使用される。
- 関係: アズーリアの所持品。自動鎧（案山子）として機能させるための遠隔操作にも関連している。
- 引用: 「二筋の光が杖から伸び上がり、拘束の呪術が広げられた羽に向かって突き進んだ。」 / 「私は高らかな呪文詠唱と共に頭上に掲げていた両手を振り下ろし」

### 呪動装甲（自動鎧）
- 何であるか: アズーリアが遠隔操作する鎧姿の「案山子」。フィリスの掌握により四大系統全ての呪術適性が上昇したことで可能になった。
- 関係: アズーリアの分身として機能し、敵の注意を惹きつける囮となる。抗呪術加工が施されているため物理破壊には強い。
- 引用: 「使い魔の呪術によって自らの呪動装甲を【自動鎧（リビングアーマー）】として遠隔操作した私は」 / 「今まで鴉と相対してきたのは、がらんどうの鎧を利用した案山子である。」

### 攻撃端末
- 何であるか: ナトの背中に取り付けられた水滴状の弾体。合計三個あり、ナトの周囲を回りながら遠隔操作で攻撃を行う。
- 関係: ナトの武器。メイファーラの短槍やミルーニャの防御呪文によって弾き返される。
