# 観察ページ ch00115__2-94　サイバネティクスとオカルティズムの幸福なマリアージュ⑩.md

### アキラくん（シナモリ・アキラ）
- 何であるか: 主人公。左手の義肢を持ち、トリシューラと「聖婚」を行うことで一体化し、戦闘能力を大幅に上昇させた存在。
- 関係: トリシューラのパートナー。「杖」のゼノグラシア。キロンと戦っている。
- 引用: 「アキラくんの死によって【鮮血呪】をトリガー。」 / 「純粋な【杖】のゼノグラシアであるアキラくんが【聖婚】を行うということ。」

### トリシューラ
- 何であるか: 魔女。「きぐるみの魔女」であり、自身を強化外骨格（きぐるみ）としてアキラに装着させる能力を持つ。地母神キュトスの最後の魔女。
- 関係: アキラと一体化する相手。【輪廻】の特性を持つ。
- 引用: 「その特性【輪廻】の呪力が極限まで引き出され、俺という存在をトリシューラが繋ぎ止める。」 / 「きぐるみの魔女の真なる能力とは、彼女自身が強化外骨格（きぐるみ）になることだ。」

### キロン
- 何であるか: アキラとトリシューラの敵。蝶の翅と馬の脚を持つ生物（キメラのような姿）。射撃と刺突を得意とする。
- 関係: アキラ・トリシューラと戦闘中。アキラの強化を「機械仕掛けの【炎天使】」と呼ぶ。
- 引用: 「蝶の翅と馬の脚をばたつかせながら体勢を立て直し、血の唾を吐いてこちらを睨み付けた。」 / 「装備の更新で能力が大幅に上昇している――体力、神経反射、知性、そして打撃力。」

### 鮮血呪
- 何であるか: アキラの死（背後の屍）をトリガーとして発動する呪術。閾値を超えた価値の変動により超常現象を再現する。
- 関係: トリシューラとアキラの「聖婚」を実現し、新たな力をもたらす契機となる。
- 引用: 「背後の屍を生贄に捧げて、鮮血の呪術が発動する。」 / 「そうして、鮮血呪はその使い手に新たな力をもたらしていく。」

### 聖（ヒエロス）――婚（ガモス）
- 何であるか: トリシューラとアキラが口にする誓約の文言。「聖婚」を意味する。
- 関係: 二人の相互補完と一体化を成立させるための儀式の一部。
- 引用: 「「聖（ヒエロス）――」 / 「――婚（ガモス）」」

### ウィッチオーダー
- 何であるか: トリシューラの左腕に現れる装甲・システム。下位六十二形態と上位九形態を持つ。
- 関係: アキラの左手を覆い、トリシューラとの一体化によって上位機能がアンロックされる。
- 引用: 「その上からトリシューラの左腕が覆い被さり、外側から光が収束して再び【ウィッチオーダー】がその姿を現す。」 / 「ウィッチオーダー最強の九形態、最初の一つ。」

### ヘリステラ
- 何であるか: キュトスの姉妹No.1。「車輪の女王」とも呼ばれる。アキラがエミュレート（模倣・展開）した最初の上位形態。
- 関係: トリシューラのシステムの一部であり、【輪廻】の特性を持つ。出力が三割から十割に上昇する。
- 引用: 「No.1【ヘリステラ】エミュレート！」 / 「キュトスの姉妹No.1【ヘリステラ】、またの名を【車輪の女王】」

### 車輪の女王
- 何であるか: ヘリステラの別名。背に巨大な車輪を担ぎ、山羊脚で大地を踏みしめる女性のイメージ。
- 関係: キュトスの姉妹の頂点に立つ長姉。【不死】と【輪廻転生】を司る。
- 引用: 「その背には途方もなく大きな車輪が乗せられ……強靱な山羊脚で大地を踏みしめ」 / 「キュトスの姉妹の長姉が司る【不死】は、【輪廻転生】なの」

### キュトス（地母神キュトス）
- 何であるか: トリシューラが属する「杖」性の神格。その欠片としての最後の魔女トリシューラが存在する。
- 関係: ヘリステラを含む七十一に分かれた不死女神の総称（姉妹）。
- 引用: 「地母神キュトスの【杖】性の欠片である最後の魔女トリシューラ」 / 「私達キュトスの姉妹の頂点に立つ、一番上のお姉様。」

### 輪廻
- 何であるか: トリシューラの特性であり、ヘリステラの能力特性。エネルギーの移転と同一性の画定を行う。
- 関係: アキラの左手（義肢）で回転する歯車によって象徴され、運動エネルギーを再生・最適化する力として機能する。
- 引用: 「その特性【輪廻】の呪力が極限まで引き出され」 / 「呪装機巧【アーザノエルの御手】が参照し、引用する能力特性は【輪廻】。」

### サイバーカラテ（サイバー空手）
- 何であるか: アキラとトリシューラが体現する武術の極意。「人機一体」を指す。
- 関係: トリシューラの「きぐるみ」状態での戦闘スタイル。義肢へのエネルギー伝達経路を含んだ技術体系。
- 引用: 「人機一体の境地。此則ちサイバーカラテの極意也。」 / 「全身全霊の、サイバーカラテの技によって。」

### 紀元槍（アカシックレコードとのダイレクトリンク）
- 何であるか: 神話（ミシック）級の超呪術兵装。あらゆる神話と幻想を貫くイメージの核心を抽出した槍。
- 関係: アキラが「車輪の女王」のイメージを左手で掴み取った際に形成されたリンク。
- 引用: 「それはあらゆる神話と幻想を貫く、世界の始まりと終わりを繋ぐ槍。」 / 「紀元槍――アカシックレコードとのダイレクトリンク形成完了。」

### アダム・カドモン
- 何であるか: トリシューラがアキラの最終到達点として言及する概念。「完全者の創造」に関わる。
- 関係: 二者の合一を経て、いずれ至るべき状態。【アンドロギュヌスの左手】への道筋の一部。
- 引用: 「この段階を経ていずれアキラくんは【アダム・カドモン】に至る」 / 「いつか【アンドロギュヌスの左手】に辿り着く為に」

### 機巧曼荼羅
- 何であるか: アキラの左手の甲に展開される幾何学的な図像。歯車と杖の紋章などで構成される。
- 関係: サイバー空手・呪的発勁【輪廻】を用意するための術式展開。
- 引用: 「幾何学的な模様が重ね合わさっていき、手の甲の歯車を中心として巨大な図像が完成する。」 / 「機巧曼荼羅を展開。サイバー空手・呪的発勁【輪廻】を用意」

### 強制拒絶（リフューズ）
- 何であるか: トリシューラとアキラの一体化状態を解除するためのプロセス。残り270秒で実行される予定。
- 関係: 自己同一性の回復と、互いの存在が毒にならないための「拒絶」の儀式。
- 引用: 「強制拒絶（リフューズ）まであと270秒！」 / 「俺達は互いに拒絶し合わなければならない。」

### 義肢（左手）
- 何であるか: アキラの左腕。トリシューラの左腕と融合し、歯車や魔法円陣を内蔵した呪術的な機械装置となる。
- 関係: 【ウィッチオーダー】の一部であり、【輪廻】のエネルギー変換を行う中心部。
- 引用: 「更に左の義肢が軸たる骨格部分だけを残し、光の粒子となって雲散する。」 / 「左手の甲で回転する歯車に噛み合うようにして回る、架空の歯車。」
