# 観察ページ ch00341__4-110　左右一対の邪眼姫①.md

### ミルーニャ＝メートリアン・アルタネイフ
- 何であるか: 語り手であり、投石器（スリングショット）と呪石弾を操る女性。白とピンクのアウトドアポーチを腰に巻いている。
- 関係: リーナの姉（先輩）。アズーリア様やリールエルバと共に行動する。魔導書『死人の森の断章』の本体を所有している。
- 引用: 「私は左手の投石器（スリングショット）を前に突き出した。」 / 「本体の魔導書は私ことミルーニャ＝メートリアン・アルタネイフの手元にある」

### リーナ
- 何であるか: ミルーニャの相方（妹）。箒の二人乗りで飛翔し、重力制御や空圧による加速を行う。黒い装丁の魔導書（大学ノート）を操る。
- 関係: ミルーニャの妹・相方。セリアック＝ニアを可愛がる。「ドルネスタンルフ系の加護持ち」と呼ばれる。
- 引用: 「三半規管を翻弄する重力の制御を妹に任せ」 / 「名付けてニア姫弾！ ドルネスタンルフ系の加護持ちは死ぬ！」

### アレッテ・イヴニル（邪眼の人形姫）
- 何であるか: 紅紫の髪を持つ人形のような女性。左右から騎士人形と呪術師人形を従える。諦観に満ちた世界観で空間を減速・石化させる「邪視」を使う。
- 関係: ミルーニャたちの追撃対象。「私の方」という言葉を口にする。太陰で儀式を行っていた痕跡がある。
- 引用: 「標的――邪眼の人形姫（アレッテ・イヴニル）が紅紫の髪を靡かせながら嘲笑う。」 / 「『私の方』はここで終わるのね」

### セリアック＝ニア（聖姫／猫姫）
- 何であるか: 黄色い呪石から顕現する、掌サイズ〜子供サイズの猫耳少女。光の刃や爪で戦う。「球神障壁」を破る力を持つ。
- 関係: ミルーニャが召喚する味方。リーナに甘える。公的には死亡扱いだが、生死が曖昧な状態で呪石弾から召喚される。
- 引用: 「とても小さな猫耳の少女になる。掌に乗るほどのサイズだが、それは紛れもなく聖姫セリアック＝ニアだった。」 / 「あらゆる球体は【猫（アウターゴッド）】にとって掌で弄ぶ玩具でしかない。」

### アズーリア様
- 何であるか: ミルーニャたちの合流相手であり、魔導書の管理者権限を持つ一人。第五階層への不用意な関与を避けている立場にある。
- 関係: ミルーニャ、リールエルバと共に行動する予定だった人物。「陥穽」を封じ込めた存在として言及される。
- 引用: 「見失う前に片を付けてアズーリア様と合流します！」 / 「管理者権限は他にもアズーリア様とリールエルバが保有している。」

### リールエルバ
- 何であるか: 魔導書の管理者権限を持つ一人。誘拐されている状況にあるが、その立場から自由になりガロアンディアンを援護できる状態にある。
- 関係: ミルーニャの仲間。カルト教団に囚われているが意志は活き活きしている。
- 引用: 「同時に、魔導書に追記され続ける二人分の『一人称記述』をざっと流し読みして仲間の状況を把握する。」 / 「誘拐されているという状況は、彼女を立場から自由にしている。」

### 太陰（イルディアンサ）
- 何であるか: 地上と天空の回廊で結ばれた場所。月齢によって開閉する軌道昇降機がある。アレッテ・イヴニルが暗躍した場所。
- 関係: ミルーニャたちが突入し、戦闘が行われた舞台。
- 引用: 「夜を貫く光の柱は、太陰（イルディアンサ）と地上とを繋ぐ天空の回廊。」

### 死人の森の断章
- 何であるか: 黒い装丁の魔導書。第七【富（トラスト）】という章が存在する。呪文の自動紡出や状況把握に用いられる。
- 関係: ミルーニャが本体を持ち、アズーリア様とリールエルバが管理者権限を持つ共有物。
- 引用: 「私の意志に応えて黒い装丁の魔導書が目の前に出現。」 / 「【死人の森の断章】――その第七。名を【富（トラスト）】。」

### 呪石弾（ビーンズ）
- 何であるか: ミルーニャが投石器で投射する赤色や黄色の石。熱と衝撃を撒き散らす流星となる。
- 関係: アレッテ・イヴニルへの攻撃手段。セリアック＝ニアを顕現させる媒介にもなる。
- 引用: 「腰に巻いた白とピンクのアウトドアポーチから赤色の呪石を取り出す。」 / 「取り出したのは黄色に輝く呪石。」

### 騎士人形・呪術師人形（双子人形）
- 何であるか: アレッテ・イヴニルの左右から現れる護衛。鉄槌を持つ騎士と爪楊枝のような杖を持つ呪術師の姿をしている。
- 関係: アレッテ・イヴニルの従者。「魔戦人形師団最強を誇る双璧」と呼ばれるが、セリアック＝ニアに敗北する。
- 引用: 「人形姫の左右から玩具の鉄槌を持った騎士人形と爪楊枝のような杖を持った呪術師人形が飛び出してくる。」

### 陥穽
- 何であるか: アズーリア様が封じ込めた呪術的な束縛効果。炸裂した呪石弾が展開する光り輝く帯として現れる。
- 関係: アズーリア様の能力の一部。双子人形の護衛を束縛するために使用された。
- 引用: 「アズーリア様が封じ込めた【陥穽】が威力を発揮していた。」

### 球神障壁
- 何であるか: アレッテ・イヴニルを守る堅牢な防御結界。セリアック＝ニアの爪によって紙のように引き裂かれた。
- 関係: アレッテ・イヴニルの防御手段。「猫」に対して無効化される性質を持つ。
- 引用: 「人形姫の邪視は一撃で粉砕され、堅牢で知られる球神障壁が紙のように引き裂かれてしまう。」

### ゼオーティア（内世界）
- 何であるか: ミルーニャたちが墜落した後の世界。紅紫の夕焼け空と霧に包まれ、広大な霊園が広がる位相の異なる世界。
- 関係: アレッテ・イヴニルが仕掛けた罠によって飲み込まれた場所。「異界監獄」でもある。
- 引用: 「位相の異なる世界、ゼオーティアと隣り合う内世界にでも飲み込まれたようだった。」

### ジンメンイナゴ（人面蝗）
- 何であるか: ゼオーティアの空を埋め尽くす虫の大群。顔や手足を備えた異形の蝗。呪殺刑を受けた亡者たち。
- 関係: ゼオーティアの住人であり、ミルーニャたちを襲う敵。
- 引用: 「空を埋め尽くす色彩の正体は、大挙してやってきた虫の大群だった。蝗――それも顔や手足を備えたジンメンイナゴ。」

### 人面の甲虫・長虫・百足
- 何であるか: ゼオーティアの霊園に生息する異形の生物。霊長類の顔が浮かび上がっている。緑色の液体で墓石を溶かす。
- 関係: ミルーニャたちが着陸直後に遭遇し、戦闘となる敵。
- 引用: 「大地を這い回り、墓石を溶解させる緑色の液体を吐き出す長虫。」 / 「絶叫しながら飛来してくる人面の甲虫。」

### トライデント（使い魔の座）
- 何であるか: ミルーニャたちが介入すべき対象の一つ。「六王」ではないが妨害すべき存在。
- 関係: ミルーニャたちの優先的な敵。ラクルラール派の企みと関連している。
- 引用: 「使い魔の座――トライデント。そしてラクルラール派の企みを妨害することが優先すべき目的だ。」
