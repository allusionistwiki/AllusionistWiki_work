# 観察ページ ch00108__2-87　サイバネティクスとオカルティズムの幸福なマリアージュ③.md

### キロン
- 何であるか: 聖騎士の姿をした敵対者。黒馬に騎乗し、五種の神滅具を操る。空間操作能力と瞬間移動・超回復を持つ。
- 関係: アキラ（俺）と戦闘している。コルセスカとの戦闘で破壊されたはずの呪具を使用している。
- 引用: 「キロンの目の前で無数の文字列を立体投影していく。」 / 「キロンは遙か上空で滞空し、こちらへと突撃の態勢に入っていた。」

### アキラ（俺）
- 何であるか: 主人公。右腕に停滞の呪力と鏡による幻肢攻撃能力を持ち、左手にウィッチオーダーを装備している。
- 関係: キロンと戦闘している。トリシューラからウィッチオーダーを受け継いでいる。
- 引用: 「俺は同じ地点から同じ地点へと跳躍していた。」 / 「事実なのだが、真面目な回答とは受け止められなかったらしい。」

### トルクルトアの神託機械
- 何であるか: キロンが召喚した光り輝く石版。文字列を立体投影し、攻撃や防御の補助を行う。
- 関係: キロンの所持品。鏡の世界の幻影の腕に対して接触し、動きを押し止める能力を持つ。
- 引用: 「虚空から出現した光り輝く石版が、キロンの目の前で無数の文字列を立体投影していく。」 / 「展開された文字列が鏡の世界の幻影の腕に対して接触すると、ワイヤーのように巻き付いてその動きを押し止めたのである。」

### 五種の神滅具
- 何であるか: キロンが使用する漆黒の槍、古びた盾、白い弓、黒馬、石版のセット。完全な状態で集結する。
- 関係: キロンの装備品。コルセスカとの戦闘で破壊されたはずだが、修復または自動修復機能により再出現している。
- 引用: 「漆黒の槍、古びた盾が出現して、下方から迫り上がってくる巨大なシルエットは見覚えのある黒馬。」 / 「五種の神滅具は完全な状態で持ち主の下に集結する。」

### ちびシューラ
- 何であるか: アキラの味方（推測: 召喚獣やサポートAIなど）。アラートを出す機能を持つ。
- 関係: キロンの消える直前にアキラへアラートを出したが、回避は失敗した。
- 引用: 「ちびシューラが直前に発していたアラートによって回避、しようとするが失敗。」

### 停滞の呪力
- 何であるか: アキラの右腕から放たれる防御能力。運動エネルギーを零に近づける絶対防御。
- 関係: アキラの右腕の機能。キロンの突撃に対して使用された。
- 引用: 「右腕を突き出して膨大な速度と質量、それによって生み出される運動エネルギーを零に近づけていく。停滞の呪力による絶対防御。」

### 多面鏡
- 何であるか: アキラの右腕周囲に展開される氷の破片群。昆虫の複眼や亀の甲羅のような形状をしている。
- 関係: アキラの武器。仮想の幻肢を映し出し、非現実の世界から攻撃を仕掛ける。
- 引用: 「右腕の周囲に多面鏡を展開。昆虫の複眼、あるいは亀の甲羅めいた氷の破片群が仮想の幻肢を映し出し」

### 攻性防壁【氷】
- 何であるか: コルセスカが構築した防御術式。脳を焼き切る性質を持つ。
- 関係: アキラがキロンの脳を狙う際に参照する技術。コルセスカの遺産。
- 引用: 「コルセスカの構築した攻性防壁【氷】によって脳を焼き切ることすら不可能ではないのだが」

### 射影聖遺物（アトリビュート）・第五番――神の万年筆を拾った少年
- 何であるか: キロンが使用する神働術の名前。過去の聖人のエピソードを模倣し、自己を強化する。
- 関係: キロンの攻撃手段。無数の輝く文字列を複雑に絡み合わせて襲いかかる。
- 引用: 「射影聖遺物（アトリビュート）・第五番――神の万年筆を拾った少年」 / 「言葉と同時に、無数の輝く文字列が複雑に絡み合い、無数に枝分かれしてこちらに襲いかかる。」

### 【松明の騎士団】
- 何であるか: キロンが所属する組織（推測）。膨大な歴史と伝統を持つ。
- 関係: キロンの神働術の力の源。その重みが呪力の強度となる。
- 引用: 「【松明の騎士団】が誇る膨大な歴史と伝統、その重みがそのまま呪力の強度となって襲いかかる。」

### 射影三昧耶形（アトリビュート）・十四番
- 何であるか: アキラが使用する左手の能力の名前。ヴァレリアンヌをエミュレートする形態。
- 関係: アキラのウィッチオーダーの機能の一つ。空間制御技術「縮地」を発動させる。
- 引用: 「射影三昧耶形（アトリビュート）・十四番」 / 「改型十四番・【縮地】」

### ヴァレリアンヌ
- 何であるか: 【星見の塔】随一の扉職人（ハイパーリンカー）。緑色の短い髪と巨大な斧を持つ背の低い少女。
- 関係: アキラがエミュレートする対象。空間制御技術「扉」の叡智を統べる。
- 引用: 「緑色の短い髪と、身の丈よりも巨大な斧が特徴的な背の低い少女。」 / 「【星見の塔】随一の扉職人（ハイパーリンカー）ヴァレリアンヌ。」

### 仏眼仏母（アーザノエル）
- 何であるか: アキラが招集する魔女の騎士団の名前の源。左手「ウィッチオーダー」の考案者に関わる存在。
- 関係: アキラが呪力を発動させる際に名を呼ぶ対象。「ここに魔女の騎士団を招集する」と宣言する。
- 引用: 「仏眼仏母（アーザノエル）の名に於いて、ここに魔女の騎士団を招集する」

### ウィッチオーダー
- 何であるか: アキラの左手の義肢。キュトスの七十一姉妹全ての能力を個別に参照し発動させる。
- 関係: アキラの装備品。トリシューラが再現したもので、第五階層の物質を材料として再構成される。
- 引用: 「この左手の名は、アーザノエルの御手【ウィッチオーダー】。」 / 「キュトスの七十一姉妹全ての能力を個別に参照し、それに応じた能力を発動させるというものである。」

### キュトス
- 何であるか: アキラの左手（ウィッチオーダー）が参照する魔女たちの総称。九姉の頂点に立つ存在がいる。
- 関係: ウィッチオーダーの設計思想の源。七十一姉妹が存在する。
- 引用: 「【星見の塔】の第九位、キュトスの姉妹の頂点に立つ九姉、その最後の一人が考案したこの義肢」

### トリシューラ
- 何であるか: アキラの左手（ウィッチオーダー）を再現した魔女。アンドロイドの魔女。
- 関係: アキラにウィッチオーダーを託した人物。第五階層に干渉し、物質を左手の材料に変換する技量を持つ。
- 引用: 「その薫陶を受けたトリシューラが自力で再現したこの左手は」 / 「戦いの前にトリシューラはこう言っていた。」

### 第五階層
- 何であるか: アキラとキロンが戦闘している場所。住まう者に物質の創造能力（世界槍）を与える。
- 関係: 戦闘の舞台。ウィッチオーダーの再構成に使用される材料源。壁が崩壊しクレーター状になっている。
- 引用: 「第五階層に住まう者に例外なく与えられる、共通のリソース。」 / 「衝撃と轟音が、階層全体を揺るがした。」

### 世界槍
- 何であるか: 第五階層の小世界を掌握し、改変する能力。物質の創造能力の正確な定義。
- 関係: トリシューラがウィッチオーダーの材料を得るために使用した権限。
- 引用: 「物質の創造能力――正確には、世界槍という小世界を掌握し、改変する能力である。」

### 縮地
- 何であるか: サイバーカラテに存在する技法であり、ウィッチオーダーによって再現された空間制御能力。距離を短縮して攻撃を命中
