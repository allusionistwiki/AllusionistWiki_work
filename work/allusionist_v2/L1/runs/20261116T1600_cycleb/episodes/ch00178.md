# 観察ページ ch00178__3-56　パレルノ山六千人殺し.md

### リーナ
- 何であるか: 浮遊する端末から書籍テクスチャを立体投影し、幻覚呪術によって『手触り』や紙の質感を再現して読書を楽しんでいる人物。
- 関係: 「私」に質問され、戦場小説・迷宮小説について語る。ペイルに声をかけられそうになる。「空圧」という能力（または呪術）を持つと示唆される。
- 引用: 「浮遊する端末から書籍テクスチャを立体投影しているリーナに問いかける。」 / 「私の槌矛が奴の顔面にめり込み、リーナの【空圧】が空高く巨体を舞い上げた。」

### 戦場小説／迷宮小説
- 何であるか: その内容よりも社会的な利用形態（迷宮待機中や帰還途中の暇つぶし）に重きをおいて定義される小説ジャンル。駅小説に起源を持つとも言われる。
- 関係: リーナが読んでいた作品群。「私」がその性質について解説する。
- 引用: 「彼女が読んでいたのは、戦場小説あるいは迷宮小説と呼ばれる、その内容よりも社会的な利用形態に重きをおいて定義されるジャンルの小説である。」

### プリエステラ
- 何であるか: ティリビナの民のまとめ役であり、今回の護送隊の一員。ミルーニャとの和解を民衆に説明した人物。
- 関係: 「私」やメイファーラに対して一定の距離感を保ちつつも仲介者としての役割を果たす。隊列の後尾にいる。
- 引用: 「間に合わせで貸与されている呪動装甲の中は少し狭いような感じがする。」（※文脈上、プリエステラとの会話の流れ） / 「見覚えのある、筋骨隆々とした体躯を晒した変態――もとい巨漢。そして黒い肌に祭服という静かな立ち姿。修道騎士ペイルと、黒檀の民の医療修道士イルスがそこにいたのだ。」（※直前の段落でプリエステラがミルーニャへの説明をしたことが記述されている）

### ティリビナの民
- 何であるか: パレルノ山の集落に住む人々。今回の護送対象であり、その一部は地獄や第五階層へ向かい、残りは保護される予定。
- 関係: ミルーニャに懐いている子供たちがいる。ペイルの挑発的な言動によりミルーニャへの敵意が緩和された。
- 引用: 「振り返ると、整列したティリビナの民たちの姿。」 / 「そのミルーニャは、現在列の後ろで小さな子供たちに囲まれている。」

### ミルーニャ
- 何であるか: 以前「私」を捕獲しようとしたペリグランティア製薬の使い魔。現在は和解し、ティリビナの民に懐かれている。呪具を用意して運搬を楽にした。
- 関係: ペイルに手を引かれ挑発される。「私」が守ろうとした対象。カタルマリーナ（ハルベルトの師）との取引の結果として解放された可能性が高い。
- 引用: 「ミルーニャちゃんのお陰で色々と運搬が楽になったしね。」 / 「ペイルが無造作に前に出た。何故かミルーニャの手を無理矢理引っ張ってだ。」

### ペイル
- 何であるか: 修道騎士。筋骨隆々とした巨漢。「松明の騎士団」の一員。露出狂じみた振る舞いをする。
- 関係: ミルーニャに強引に迫り、挑発的な言動で民衆の敵意を自分に向けさせた。「私」の槌矛とリーナの【空圧】で吹き飛ばされる。ハルベルトとナトが人員を回した結果として参加している。
- 引用: 「修道騎士ペイルと、黒檀の民の医療修道士イルスがそこにいたのだ。」 / 「おう、テメーの所為で全治一晩の大怪我しちまったぜ。詫びに一発ヤらせろや」

### イルス
- 何であるか: 黒檀の民の医療修道士。修道騎士ペイルと共に参加している。静かな立ち姿。
- 関係: ペイルと並んで隊列の後尾にいる。「私」やメイファーラに対して嫌悪感を示さず、プリエステラを間に置いて距離を保つ。
- 引用: 「黒い肌に祭服という静かな立ち姿。」 / 「以前プリエステラを助けた一件が効いたのだろうか、イルスを始めとした修道騎士――正体を明かした私やメイファーラに対しても、そこまで嫌悪感を示される事は無かった。」

### サリア
- 何であるか: 探索者。今回の護送の先導者。軽装で二振りの短剣を持つ。栗色の髪が一房だけ編み込まれている美貌の持ち主。
- 関係: 隊列の先頭に立ち、正確な地図を所持している。「【白焔】」との戦闘経験についてコルセスカに言及する。「【死の囀り】」への陽動役を引き受ける。
- 引用: 「今回の護送において先導者となる探索者サリアだった。」 / 「『隅から隅まで調べ尽くさないとクリアした気になりません』とか…訳のわからないことを言われて結局地図が完成しただけの無駄足だったけど」

### メイファーラ
- 何であるか: 「私」と共に行動する人物。千里眼を持つ。「松明の騎士団」の一員（呪動装甲の紋章から光を放出）。
- 関係: サリアと共に隊列の先頭に立つ。「私」に「アズ、行こう」と声をかける。坑道内の視界確保に貢献する。
- 引用: 「彼女は小さく頷いて、メイファーラと共に列の先頭に立つ。」 / 「薄暗い道を私とメイファーラの呪動装甲が照らす。」

### ハルベルト
- 何であるか: 「私」の同行者。智神の盾に所属していた過去を持つ。呪文の派閥（カタルマリーナ派）に所属する魔女。
- 関係: 「私」を「アズ」と呼ぶ。師である【死の囀り】カタルマリーナへの複雑な感情（敬愛と恐怖）を抱えている。ペリグランティア製薬との取引について解説する。
- 引用: 「『アズ、行こう』 隣のハルベルトに頷いて、私たちは出発する。」 / 「【白焔】ビークレットがコルセスカの師であるように、【死の囀り】カタルマリーナもまたハルベルトの師であるという。」

### 【私】（アズ）
- 何であるか: 物語の語り手。肉体のサイズを変動させる能力を持つ。「槌矛」を所持する。ペリグランティア製薬に追われていた身。
- 関係: リーナ、ハルベルト、メイファーラらと共に行動する。ミルーニャを守ろうとした過去がある。カタルマリーナに感謝の念を抱いている。
- 引用: 「私が肉体のサイズを変動させれば最適化されるのだが、『私』を歪めるようで抵抗感があるのだ。」 / 「私は、カタルマリーナという人に感謝しなければならない理由がある。」

### ラーゼフ
- 何であるか: 新しい甲冑（呪動装甲）を用意できる人物。ペイルとハルベルトに人員を回した関係者。
- 関係: 「私」の新しい装備について言及される。ペイルとイルスの参加を可能にした背景にいる。
- 引用: 「ラーゼフはあと一週間もあればまた新しい甲冑を用意できると言っていた。」 / 「何でもラーゼフとハルベルトが動かせる人員を回してくれたらしい」

### ナト
- 何であるか: 今回の護送に参加していない人物。治療や試験運転で来られないとのこと。
- 関係: 本来参加するはずだったメンバーの一人。
- 引用: 「ちなみにナトは治療とか試験運転とかで来られないとのこと。」

### コルセスカ
- 何であるか: 「冬の魔女」。星見の塔出身。サリアの師匠（あるいは先輩格）。「【白焔】」を師とする。
- 関係: サリアが過去に「コア」として一緒に行動していた相手。時間操作系の呪術の適性を持つとされる。
- 引用: 「ひょっとして、コルセスカさんのお話でしょうか？」 / 「冬の魔女というイメージからは遠くかけ離れている。悪魔の九姉に直接師事していたという事そのものには納得がいくのだけれど。」

### 【白焔】ビークレット
- 何であるか: キュトスの七十一姉妹のうち第八位。「悪魔の九姉」の一員。コルセスカの師匠。パレルノ山を滅ぼす災厄の記憶を持つ存在（残響）。
