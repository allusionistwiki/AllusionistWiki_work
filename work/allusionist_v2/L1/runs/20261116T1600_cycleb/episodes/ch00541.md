# 観察ページ ch00541__5-42　ユディーア対チリアット①.md

### チリアット
- 何であるか: マレブランケ構成員のひとりであり、牙猪（バビルサ）氏族の猪人（ブルータ）。魔将ダエモデクから逃亡し、トリシューラの配下としてガロアンディアン勢力に協力している。
- 関係: 名無しの王を守る使命を持つ。アテンプレク・ディスケイムと同じ博物城出身であり、ディスケイム家の血統作品（アート）。キニス・ペラティアの元指導教官であるアテンプレク先生と同一人物と思われる。
- 引用: 「チリアットはマレブランケ構成員のひとりである。」 / 「アテンプレク・ディスケイム。マレブランケ構成員のひとりチリアットは、キニス・ペラティアと同じ博物城の出身であり、ディスケイム家の血統作品（アート）である。」

### 牙猪（バビルサ）
- 何であるか: チリアットが属する氏族。己に向かって弧を描く独特の牙を持つ。
- 関係: 猪人（ブルータ）氏族の少数種。始祖は戦乙女ブルーティであり、紀神シャルマキヒュの眷属として天眼の民の加護系統を持つ。
- 引用: 「己に向かって弧を描く独特の牙を持った牙猪（バビルサ）氏族の猪人（ブルータ）だ。」 / 「牙猪（バビルサ）は、猪人（ブルータ）氏族の少数種である。」

### 魔将ダエモデク
- 何であるか: チリアットが逃亡してきた相手であり、黒き亜竜。
- 関係: チリアットの右腕の義肢（ウィッチオーダー十六番・ディシルキュトス）は、回収された彼の細胞を利用した寄生異獣で作られている。
- 引用: 「とある理由から魔将ダエモデクの軍勢から逃亡していた彼は」 / 「回収された魔将ダエモデクの細胞を利用した寄生異獣。」

### 名無しの王
- 何であるか: チリアットが守り抜かねばならない存在。『白き亜竜の成れの果て』。
- 関係: チリアットの背後にある病院に保護されている無辜の民と共に、チリアットの戦意の源泉となっている。
- 引用: 「特に『白き亜竜の成れの果て』である名無しの王を守るための動機を強く持っていなくてはならないはずだ。」 / 「背後に存在する病院には無辜の民、そして守り抜かねばならない名無しの王。」

### ユディーア（偽ユディーア）
- 何であるか: チリアットと対峙した女。キノコが生えた人形のような身体を持つ自動人形（使い魔）。
- 関係: レナリア・V・オルガナによって制御されている。「ユディーア」という宣名価値を持つが、本物の勇士ではない。最終的に破壊され、銀貨として回収される。
- 引用: 「一度きりの宣名は『ユディーア』だが、空虚な響きから張りぼてであることは明白。」 / 「たったひとつの『ユディーア』という宣名価値が銀貨となってエレクトラの手に収まる。」

### 三眼瞬知
- 何であるか: 天眼の民が用いる奥義。時を止め、神速を得る術理。
- 関係: チリアットは死への恐怖から変質した独自の加速ロジック（臨死加速）で発動する。エレクトラも使用し、レナリアとの鬩ぎ合いの中で世界の色が変化する現象を引き起こす。
- 引用: 「天眼の民が用いる奥義、三眼瞬知。時を止め、神速を得るという恐るべきまじないである。」 / 「個々の加速ロジックに由来する世界色の違い。」

### 紀神シャルマキヒュ
- 何であるか: 猪人の始祖ブルーティが血を取り込んだ神であり、チリアットの加護系統の源。
- 関係: チリアットの呪術基盤（簡易浄界）は「シャルマキヒュの凍視」に基づいているが、彼はこれを死と冥府に連なる外法として歪めて使用している。
- 引用: 「紀神シャルマキヒュの眷属。すなわち彼の加護系統は天眼の民である。」 / 「簡易浄界あるいは『シャルマキヒュの凍視』の呪術基盤によって制御されるべき静止時空の奥義は」

### 紀人ティーアードゥ
- 何であるか: 罰則を司る新しき神。チリアットの眷属の神。
- 関係: チリアットとの誓約により、寿命消費（供儀）による呪術強化の精度を高めている。転生成功時は権威を失う。
- 引用: 「紀人ティーアードゥは罰則を司る新しき神だ。」 / 「紀人ティーアードゥとの誓約によって呪術の精度を高めているため、記憶の改竄や天寿値の忘却は無意味。」

### 天寿値
- 何であるか: チリアットが設定した寿命年齢の数値。使用ごとに消費される。
- 関係: 現在72歳（42歳のチリアットに対して30年分の残量）。回避行動により29歳へ減少し、一か月ほど圧縮された生命を消費したと認識されている。
- 引用: 「自らの天寿を200巡節（100年分）と仮定し、使用のたびに寿命が短くなっていく。」 / 「現在、チリアットの天寿値は72歳。42歳であるチリアットに残された天寿値は30歳ぶんとなる。」

### ウィッチオーダー十六番・ディシルキュトス
- 何であるか: チリアットの右腕にある黒鉄と融け合うような黒鱗の義肢（寄生異獣）。
- 関係: 塔の姉妹ディシルキュトス（ババロアの魔女）を参照して『創造（クラフト）』された巨大な鉤爪付き装甲。腐食の『吐息』を内包する。
- 引用: 「ウィッチオーダー十六番・ディシルキュトス！」 / 「参照するのは塔の姉妹ディシルキュトス。『ババロアの魔女』という異名で知られるガロアンディアンの庇護者。」

### レナリア・V・オルガナ
- 何であるか: 銀髪ツインテール、漆黒のワンピースを着た女。盗賊王ゼドや暗殺者アダスの別人格とされる紀人の暗殺者。
- 関係: 偽ユディーアを糸で操作し、チリアットを捕縛する目的で介入した。エレクトラ（キニス）によって瞬殺され、価値剥落する。
- 引用: 「その別人格とされている女がレナリア・V・オルガナ。思惑の計り知れない紀人の暗殺者だ。」 / 「そして、呆気なくレナリアは敗北した。瞬殺。即死、からの価値剥落。」

### エレクトラ
- 何であるか: レナリアと対峙し、偽ユディーアを破壊した少女。片角を想起させる髪房を持つ。
- 関係: キニス・ペラティアの別人格または現在の姿。「本物」の勇士として登場する。メートリアンと同居している。
- 引用: 「現れたのは一人の少女だった。すらりと伸びた四肢、片角を想起させる髪房、眠たげな垂れ目。」 / 「状況は悪い。エレクトラは即座に三眼瞬知を起動した。」

### キニス・ペラティア
- 何であるか: エレクトラの本来の名前（または過去の名）。博物城出身の亜竜人。
- 関係: チリアット（アテンプレク先生）の元生徒。「広く浅い三眼瞬知」を得意とし、歴代の勇士ユディーアの記録を学ぶことで技を磨いた。
- 引用: 「もしや、キニス様。いや、ユディーア様ですかな？」 / 「かつての指導教官であった猪人（アテンプレク）はこう言ってくれた。」

### アテンプレク・ディスケイム
- 何であるか: キニスの元指導教官であり、チリアットの別名（または同一人物）。
- 関係: マレブランケ構成員。キニスに「過去の記録を順番に辿り、その全てを丁寧に学ぶ」ことを勧めた穏やかなおじさん先生。
- 引用: 「アテンプレク先生？」 / 「マレブランケ構成員のひとりチリアットは、キニス・ペラティアと同じ博物城の出身であり、ディスケイム家の血統作品（アート）である。」
