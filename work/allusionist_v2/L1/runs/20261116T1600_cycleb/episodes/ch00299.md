# 観察ページ ch00299__4-68　死人の森の断章3　コキュートス／ROUND3.md

### 第三ラウンド
- 何であるか: 物語の進行段階を示す用語。世界が変貌し、炎上する地獄のような背景となる場面を指す。
- 関係: 禿頭の女力士（ゾーイ）との戦闘が始まる契機となる。
- 引用: 「第三ラウンド。世界が変貌する。炎上する地獄のような背景。」

### 禿頭の女力士 / ゾーイ
- 何であるか: 対戦相手として現れた力士。頭部に刻まれた溝が顔面に広がり隈取り（ペイント）のようになる。昆虫の外骨格を思わせる硬化した鎧状の身体を持つ。
- 関係: コルセスカ（アキラ）と戦闘する。「YOKOZUNA」と呼ばれる存在でもある。
- 引用: 「転移して現れた禿頭の女力士の表情が、これまでとは変わっていた。」 / 「雷光が閃き、ゾーイの巨体が膨張する。」

### YOKOZUNA
- 何であるか: 力士（ゾーイ）を指す称号。誇りある存在であり、二敗したことで不退転の覚悟で向かってくる。
- 関係: ゾーイの呼称・側面。
- 引用: 「こちらが六王の力を借りていたとはいえ、誇りあるYOKOZUNAが二敗したのだ。」

### カブキスタイル / 羅刹の如き形相
- 何であるか: 東洋系力士に多いとされるスタイル。溝が顔面に広がり隈取り（ペイント）のようになった状態を指す。
- 関係: ゾーイの外見変化の特徴。
- 引用: 「東洋系力士に多いカブキスタイル。羅刹の如き形相となって、出し抜けに四股を踏む。」

### 出力――六十パーセント
- 何であるか: ゾーイが身体能力や防御力を高めるために宣言する数値。脂肪が硬化した鎧となる変質を引き起こすトリガーとなる。
- 関係: ゾーイの戦闘準備を示す台詞。
- 引用: 「「出力――六十パーセント」」

### 機巧廻し / 噴射孔 / ジェット
- 何であるか: ゾーイの背後にある噴射装置。噴流（ジェット）を放つことで空中殺法や移動を実現する。
- 関係: ゾーイが装備している技術的な部位。「華」と呼ばれる空中殺法の源。
- 引用: 「機巧廻しが背後の噴射孔から噴流（ジェット）を放つ。」 / 「廻しからのジェット噴射で迫り来る独特の型は、力士の華とも呼ばれる空中殺法だ。」

### 発気よい！
- 何であるか: ゾーイが突撃する際に叫ぶ掛け声。
- 関係: ゾーイの攻撃開始を示す台詞。
- 引用: 「「発気よい！」」 / 「叫びと共に突撃する力士を真正直に打撃で迎え撃つのは愚策だ。」

### 手刀 / クレイの力
- 何であるか: コルセスカ（アキラ）が使用する攻撃手段。左腕に一時的に宿るクレイの力により、生身の左手が刃のような形になる。
- 関係: アキラの武器。ゾーイの手刀と鍔迫り合いを行う。
- 引用: 「手を真っ直ぐに伸ばした刃を思わせる形――手刀。左腕に一時的に宿っているクレイの力が打撃を斬撃へと変化させる。」

### チョップ / スモーレスラーの基本技能
- 何であるか: ゾーイが使用する攻撃手段の一つ。手掌の型（突っ張り、張り手）だけでなくチョップも用いる。
- 関係: ゾーイの戦闘スタイルの一部。「刃を刃で受けるのは愚策」と判断される要因となる。
- 引用: 「チョップもまた、スモーレスラーの基本技能である。」

### ケイトによる呪文強化
- 何であるか: アキラの手刀に施された強化。圧倒的な迫真性を伴い、ゾーイとの鍔迫り合いを演じる。
- 関係: アキラの攻撃力を高める要素。
- 引用: 「ケイトによる呪文強化が施された手刀は、圧倒的な迫真性を伴ってこちらの剣と鍔迫り合いを演じていた。」

### 短剣 / 大剣
- 何であるか: 演劇空間（演技）において、互いの手が刃として認識されている状態の比喩。アキラの手が短剣、ゾーイの手が大剣に見えている。
- 関係: アキラとゾーイの攻撃力の格差を表現するメタファー。「刃毀れ」や「砕け散る」というリスクを示す。
- 引用: 「こちらの手刀が鋭い短剣ならば、あちらの手刀は無骨な大剣だ。」 / 「私たちには、演劇空間において両者が短剣と大剣で切り結んでいる光景が見えていた。」

### 星見の塔
- 何であるか: コルセスカ（語り手）が幼少期から篭もっていた場所。ゲームをプレイしてきた環境。
- 関係: 語り手の生い立ちや、ゲームパッドへの愛着の背景にある場所。
- 引用: 「私は幼少期から星見の塔に篭もって様々なゲームをプレイしてきた。」

### ゲームパッド / 改造ゲームパッド
- 何であるか: コルセスカが使用する入力装置。トリシューラから贈られたもの。人間工学に基づき、ボタン増設やマクロキー多機能割り当てが可能。白と銀、青のカラーリング。
- 関係: トリシューラの贈り物。コルセスカが「禁を破る」ために使用し始める。サイバーカラテ道場と連携して最適化される。
- 引用: 「そんな私に、改造ゲームパッドを贈ってくれたのがトリシューラだった。」 / 「両手にぴったりと吸い付くような流線型のゲームパッド。カラーリングは私の好きな白と銀、そして青。」

### トリシューラ / ちびシューラ
- 何であるか: コルセスカの妹（末妹選定参加者）。コルセスカに改造ゲームパッドを贈った人物。アキラの傍に浮かぶ小さな姿（ちびシューラ）として現れる。索敵網や攻撃パターン解析を行う。
- 関係: コルセスカの家族（妹）。戦闘支援AIのような役割を果たす。「セスカの方が妹だよ」という発言からコルセスカとの関係性が示唆される。
- 引用: 「アキラのすぐ傍に浮かぶちびシューラが、少しだけしょげているのが見えた。」 / 「流石は私の妹です、と心の中で語りかけた。」

### サイバーカラテ道場
- 何であるか: 敵力士の攻撃パターン解析や最適化された動きを提供するシステム・場所。改造ゲームパッドと連携してアキラの動きを加速させる。
- 関係: コルセスカ（アキラ）の戦闘支援環境。ちびシューラと共同で解析を行う。
- 引用: 「更に重ねて、ちびシューラとサイバーカラテ道場が敵力士の攻撃パターンの解析を終了。」

### カシュラム王オルヴァ / オルヴァ
- 何であるか: アキラに降りてくる役（存在）。託宣によって未来を予知する大予言者にして大賢者。カシュラムの王。
- 関係: アキラの一時的な憑依対象。「ノーグの血脈」を持つ。戦闘中にアキラの瞳が十字の紋様を映すことで出現し、最終的に消失して断頭台で死ぬ運命にある。
- 引用: 「瞳が十字の紋様を映し出し、カシュラム王オルヴァの役が一時的に降りてくる。」 / 「本来の時間流で、カシュラムの王は断頭台にかけられて死んでいった。」

### ノーグの血脈
- 何であるか: オルヴァが持つ血統。ちびシューラの予測精度を上昇させる効果を持つ。
- 関係: オルヴァの属性・側面。戦闘支援能力の源の一つ。
- 引用: 「大いなるノーグの血脈がちびシューラの予測精度を上昇させ」

### 紫槍歯虎 / 猛獣
- 何であるか: カシュラムに生息する猛獣。アキラが肉体言語魔術を発動する際に模倣する対象（両手を指を牙に見立てた獣の顎）。
- 関係: オルヴァの力を借りて放たれる必殺拳のモデル。
