# 観察ページ ch00196__3-71　言語魔術師の弟子（後編）②.md

### フィリス
- 何であるか: 魔将であり、左手から呪文を紡いで万物を無かったことにする存在。後に「言理の妖精」と呼ばれる小さな存在として矮小化され、言葉の解釈をひっくり返す悪戯好きの妖精として使役される。
- 関係: 「第一魔将」「はじまりの魔将」の側面を持つ。「澄明（わたし）」の中に閉じ込められ、後に「葉っぱの伝言板」で飼われる存在となる。
- 引用: 「フィリスの前ではあらゆる力が無意味と化す。」 / 「私はフィリスを小さな妖精として矮小化させ、言葉の狭間に住まわせて使役したり」

### 澄明（わたし）／アズーリア
- 何であるか: 物語の語り手であり、かつて「絶対者」として頂点に立っていたが、現在は色づいた世界で弱々しい存在として仲間と競い合っている。フィリスを体内に抱えている。
- 関係: 「ヴァージリア」から「アズーリア」と呼ばれる。「真黒（ヴァージリア）」の対戦相手。「澄明」は称号、「アズーリア」は名前。
- 引用: 「色づいた世界では誰もが強くて、その中の一つでしかないアズールはひどく弱々しい存在でしかない。」 / 「『アズーリア』 『ハルベルト』 二つの存在はお互いによって認められて」

### ヴァージリア／真黒（ヴァージリア）
- 何であるか: 聴力を失っている少女。フィリスの呪文により絶望に染まりかけたが、「澄明（わたし）」による書き換えられた言葉で希望を取り戻し、聴覚を得る。「ハルベルト」という名前を持つ。
- 関係: 「澄明（わたし）」から「ヴァージリア」と呼ばれる。「真黒」は称号。「末妹」になることを願っている。
- 引用: 「左右非対称の両耳が淡い光に包まれていく。 はっと黒玉の目が見開かれ、ヴァージリアはそっと両耳に手を当てる。」 / 「『アズーリア』 『ハルベルト』 二つの存在はお互いによって認められて」

### メイファーラ
- 何であるか: 十四歳の少女。蜥蜴のような変異した肉体を持つ（鱗を浮かび上がらせる）。ヴァージリアを守ろうとして盾となり、倒れる。手袋を着用していない状態で登場する。
- 関係: 「ヴァージリア」を抱えて逃走する。「辞書や物語を片手に普通の言葉を与えようとする」。
- 引用: 「メイファーラはヴァージリアを突き飛ばして、自ら盾となり――そして、全身から鱗を浮かび上がらせ、蜥蜴のように変異した肉体がゆっくりと倒れていった。」 / 「時折メイファーラが辞書や物語を片手に普通の言葉を与えようとする」

### クリア先生
- 何であるか: 黒百合宮に常在する存在。お菓子の群れを生み出して障壁を張る。フィリスの呪文により「白黒の小ウサギ」に変えられ、その姿を気に入ってそのまま振る舞う。
- 関係: 「澄明（わたし）」の師匠の一人（放任主義）。子供たちにお菓子を配る。「使徒様」と呼ばれる存在に包まれる描写がある（※推測: セリアック＝ニアへの呼びかけと混同の可能性、原文では「使徒様の仰る通りだわ」とセリアック＝ニアがクリア先生？の発言を受けている文脈だが、直前にクリア先生がウサギ化している。原文の「使徒様」はセリアック＝ニアに対する呼称として登場する）。
- 引用: 「無力な白黒の小ウサギに変えてしまう。」 / 「小さな白黒兎に変えられていたクリア先生は何故かその姿が気に入ったみたいで、そのまま手を叩いてお菓子を生み出してはみんなに配っていく。」

### ミブレルお姉様
- 何であるか: 雲の身体を持つ存在。時間稼ぎのために飛び上がり、フィリスの呪文で千切れ飛んで空の雲の一部となる。事後処理や子供たちの保護を行う。
- 関係: 「黒百合の子供たち」の上から降ってくる。「澄明（わたし）」を捕まえてお説教をする。
- 引用: 「時間稼ぎにと飛び上がったミブレルお姉様がその身体を拡散し」 / 「雲になっていたミブレルお姉様が降ってくる。」

### セリアック＝ニア／真黄（セリアック＝ニア）
- 何であるか: 宝石の彫像にされるなど被害を受けるが、後に涙を見せる。「使徒様」と呼ばれる存在に包まれる。実力を伸ばし一位争いに食らいつく。
- 関係: 「リールエルバ」の弟子（※原文では「弟子であったリールエルバはうつむき、セリアック＝ニアはその時はじめて私たちの目の前で涙を見せた」とあり、リールエルバが弟子であることが示唆される）。称号は「真黄」。
- 引用: 「セリアック＝ニアは宝石の彫像に」 / 「特に直接の弟子であったリールエルバとセリアック＝ニアは目に見えて実力を伸ばし」

### リールエルバ／真緑（リールエルバ）
- 何であるか: アストラルの手足が細くやせ細り壊死して気を失う。うつむき、涙を見せる。「澄明（わたし）」の直接の弟子ではないが、実力を伸ばす。時制を滅茶苦茶にする言葉遊びを行う。
- 関係: 「セリアック＝ニア」と姉妹のような力（「姉妹の力」）で戦う。称号は「真緑」。
- 引用: 「リールエルバはアストラルの手足が細くやせ細りそのまま壊死して気を失う。」 / 「真緑（グリーン）の深海魚と真黄（イエロー）の翼猫が姉妹の力を合わせて」

### ディスペータお姉様
- 何であるか: 過去に送られた存在。事件で唯一の被害者となり、元に戻す方法がわからず黒百合宮からいなくなる。
- 関係: 「澄明（わたし）」が「きっとあのディスペータお姉様なら...必ずまた会える」と慰める対象。「黒百合の子供たちの残虐さには歯止めがかからなくなっていた」原因の一人。
- 引用: 「過去に送られたディスペータお姉様だけは元に戻す方法がわからなくて、その事件で唯一の被害者となってしまった。」 / 「ディスペータお姉様がいなくなったことで、黒百合の子供たちの残虐さには歯止めがかからなくなっていた。」

### リーナ／明藍（リーナ）
- 何であるか: 血の色の鎖で雁字搦めに縛られて意識を失う。後に「澄明（わたし）」と一緒に空中散歩を楽しみ、新語や略語を生み出す言葉遊びに参加する。称号は「明藍」。
- 関係: 「澄明（わたし）」と一緒にはしゃぐ。「真黒（ヴァージリア）」に撃破される（雲）。
- 引用: 「リーナが体内から飛び出した血の色の鎖で雁字搦めに縛られて意識を失い」 / 「厳重な警戒網の目を盗みながらリーナと一緒に空中散歩を楽しんで」

### プリエステラ
- 何であるか: 周囲から伸びてきた草木に飲み込まれて同化する。メイファーラの仲裁に入る。
- 関係: 「ヴァージリア」と「メートリアン」の喧嘩を仲裁する。
- 引用: 「プリエステラが周囲から伸びてきた草木に飲み込まれて同化していき」 / 「メイファーラとプリエステラが仲裁に入る所までいつも通りの流れ。」

### メートリアン／真白（メートリアン）
- 何であるか: 膨張しながら蠢くだけの真っ白な肉塊となる。後に「三本足のカラス」として戦う。「ヴァージリア」から因縁をつけられ喧嘩を始める。称号は「真白」。
- 関係: 「澄明（わたし）」に撃破される。「ヴァージリア」と喧嘩する。
- 引用: 「メートリアンが膨張しながら蠢くだけの真っ白な肉塊となり」 / 「真白（メートリアン）の三本足のカラスと明藍（リーナ）の雲とをそれぞれ撃破した真黒（ヴァージリア）」

### 黒百合宮
- 何であるか: 子供たちが生活し、勉強やお茶会を行う場所。玄関があり、柱廊や噴水、螺旋階段がある。フィリスの呪文で一部がお菓子に変えられたり改築されたりする。
- 関係: 「クリア先生」が常在する場所。「澄明（わたし）」と「ヴァージリア」が歌い始める場所。
