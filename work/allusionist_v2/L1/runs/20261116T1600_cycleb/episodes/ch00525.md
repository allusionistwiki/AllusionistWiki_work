- 関係: ジュティアとミナの狙い撃ち対象（「パーンを狩る方が確実だろ」）。ジュティアの介入により足を引かれるが、巨人ダウザールにとっては羽虫のような存在である。
- 引用: 一斉に加速する中で、頭一つ抜け出たのはやはりパーン。 / 小細工を弄してまで必死に巨人の足を引こうとしていたパーンは、小さな炎天使を振り払おうとして失敗していた。

- 引用: ダウザールは一瞥した上で完全に無視。 / 『強引な介入だけど許してくれよ、ダウザール。少しは友達っぽいことがしてみたくてね』

- 関係: ジュティア（ハッピー）とミナ（ラメント）が使用し、情動を射出する異能の兵器として猫科魔獣を無力化する。権能を預けられた器。
- 引用: 「ハッピー、ぶちかませ」 / 「ラメント、歌って」 / 喜銃と愴銃。女神が作り出したオーパーツにして情動を射出する異能の兵器。

### アヴロノ
- 何であるか: 灰色帽子の召喚士（北方辺境の浮遊戦車に匹敵する航空戦力）。ロードデンドロンが召喚した存在。
- 関係: ロードデンドロンの自衛手段として現れ、ジュティアとミナの魔弾を防御する。後にジュティアの瞳と一体化して「第八魔弾」を放つ射撃手となる。
- 引用: 「召喚（コール）！　美しき九祖、土のアヴロノ、穏やかなるアドガレンスよ。この身に城砦の守りを与えたまえ！」 / 銃口と一体化したアヴロノの瞳が、爛々と輝く。

- 引用: 「感涙に咽び泣け、『第八魔弾』」 / 次の六発をまとめてひとつに。七つ目の眼光が世界を照らす光を呑み込んで、闇が虚空を満たしていく。

- 引用: 出現したのは一見して未熟とわかる不完全な浄界だった。 / 明らかな実力不足。実戦での無茶がもたらした当然の結果に見えた。

### アルコーン
- 何であるか: 神としての完全な機能を兼ね備えた悪しき造物主。神を僭称する存在。
- 関係: アエルガ＝ミクニーとピュクティエトの両方であり、同時にどちらでもない「何か」。ジュティアとミナの背後に現れる。
- 引用: あろうことか神を僭称し、その権能すら偽装して恥じない悪魔のごとき存在。 / その上で、神としての完全な機能を兼ね備えた悪しき造物主（アルコーン）。

### ロードデンドロン
- 何であるか: レース参加者の一人。召喚士。
- 関係: ジュティアとミナの魔弾攻撃に対し、アヴロノを召喚して防御する。反応できなかったレーサーの一人として悲鳴を上げる側面もあるが、即座に対処した側面も描かれる。
- 引用: ロードデンドロンは対抗するように拳銃を取り出し、召喚による自衛を試みた。 / 至る所で悲鳴が上がる。全く反応できなかったレーサーたちやリーナ、ロードデンドロンたちに呪術攻撃が直撃。

### リーナ

- 関係: ジュティアとミナの浄界が半球型で閉じられていないことを「典型的な浄界修行者によくある失敗」として驚愕し悲鳴を上げる。魔弾攻撃の被害者でもある
