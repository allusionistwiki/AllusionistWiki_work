# 観察ページ ch00538__5-39　アルト・イヴニルと五人の騎士②-2.md

### ノゴルオゴルオ
- 何であるか: 隻頭の岩肌種（トロル）であり、ディスケイム家を統括する十二長老の一角。第五階層を巡る争いの中心で暗躍する三人の超越者のひとり。
- 関係: ティシリア・ハーゼム・メイザッハと対峙し、互いに警戒している。ガルラ・クオールを踏みつけている。アルテミシアに呼びかけを行う。
- 引用: 「隻頭の岩肌種は、『塗壁』を名乗る危険な言語支配者の転生体だ。」 / 「ノゴルオゴルオはにんまりと笑い、足裏のガルラをぐりぐりといたぶる。」

### ティシリア・ハーゼム・メイザッハ
- 何であるか: 甲冑を着た亜竜人の女。アゥルメイアの遠い子孫であり、ディスケイムの分家から長老の後継者として見出された傑物。「エィルの魔女」と呼ばれる。精神支配の達人。
- 関係: ノゴルオゴルオに対して支援活動を行っているが、権力闘争において危険視されている。キニスちゃんの母親（アゥルメイア）と内縁関係にある。
- 引用: 「対峙する甲冑の女は柔らかい態度を崩さないまま、優雅に細剣を鞘に収める。」 / 「『エィルの魔女』ティシリア・ハーゼム・メイザッハ」

### アゥルメイア
- 何であるか: 博物城の主であり、ディスケイムの長老。ノゴルオゴルオと同格。ティシリアの遠い祖先（お義母さま）。
- 関係: ティシリアを送り出した人物。キニスちゃんの母親でもある（推測: 「恋人（パートナー）の娘」という記述から）。
- 引用: 「博物城の主アゥルメイアはノゴルオゴルオと同格の長老である。」 / 「お義母さまをはじめとした長老の皆様も」

### 博物城
- 何であるか: ディスケイムの次代を担う者たちを作り出すための揺り籠。キュレーターが管理する場所。
- 関係: ティシリアやアルバダオバなど、多くの登場人物の出身地または拠点。ディスケイム最大の成果（階層の操作）に関与している。
- 引用: 「博物城を管理するキュレーター。」 / 「博物城とは、ディスケイムの次代を担う者たちを作り出すための揺り籠でもある。」

### キュレーター
- 何であるか: 博物城を管理する精鋭の十人。ティシリアを含む次世代の俊英たち。
- 関係: ティシリアの指揮下で行動している。ノゴルオゴルオの陣営に増援として加わった。
- 引用: 「この場にいるティシリアが博物城の長老アゥルメイアの後継者なら、他の九人は別の長老の側近や護衛、後継者候補と目される次世代の俊英たちであった。」

### ガルラ・クオール
- 何であるか: 人形姫。現在は屍同然の状態であり、足裏でノゴルオゴルオにいたぶられている。古代祭政期の球神ドルネスタンルフの言葉を代弁していた筆頭神官が正体。
- 関係: ノゴルオゴルオと古い顔見知り（昔馴染み）。ラクルラールの人形として存在している。レッテ（アルト・イヴニル）に可能性を託した。
- 引用: 「ガルラ・クオールは屍同然だ。」 / 「球神ドルネスタンルフの言葉を代弁していたクオール家の筆頭神官がガルラの正体だ。」

### アルバダオバ
- 何であるか: 老騎士。「裏切りの騎士」と呼ばれるが、忠誠を誓っているのはディスケイム家でありアルト王ではない。
- 関係: ティシリアや博物城のキュレーターたちを歓待する館（じいの体内）へ案内する。キニスちゃんの亜竜王覚醒を手伝う約束をする。
- 引用: 「この場の戦端を開いた裏切りの騎士、アルバダオバだった。」 / 「アゥルメイアお嬢様のご息女の願いとあらば、この身にかえても成し遂げてごらんにいれましょう。」

### クドラカーン
- 何であるか: ティシリアが「さん」付けで呼ぶ存在。世界を持ち上げるほどの比類なき腕力を持つ。
- 関係: ティシリアの指示により、第六階層を持ち上げて第五階層に押し付ける作業を行っている。音声通話で連絡を取っている。
- 引用: 「クドラカーンさん。……ちょっと世界を持ち上げてもらえます？」 / 「たったひとりの、比類なき腕力によって。」

### 第六階層
- 何であるか: 地底の階層。大地の呪力が満ちる死者の棲家であり、冥府にも通じる彼岸の世界。
- 関係: クドラカーンによって持ち上げられ、第五階層と融合しようとしている。ガロアンディアンの地下冥府と重なり合う。
- 引用: 「第六階層は世界槍を満たす次元の泡を通過し、その境界面を侵食して第五階層とひとつになろうとしていた。」 / 「ここは地底。大地の呪力が満ちる死者の棲家。」

### 第五階層
- 何であるか: ノゴルオゴルオらが争いの中心としている階層。第六階層と融合しようとしている。
- 関係: 選定レース（空使い選定レース）が行われる舞台の一部でもある（推測: 「クロウサーどもの庭」との対比から）。
- 引用: 「第五階層を巡る争いの中心で暗躍する三人の超越者」 / 「第六階層は、いま強引に持ち上げられて第五階層に押し付けられているのだ。」

### キニスちゃん
- 何であるか: ティシリアが「顔を見たくて」と言う少女。亜竜王として覚醒する可能性がある。ノゴルオゴルオの保護下にある（一任されている）。
- 関係: ティシリアにとって「恋人（パートナー）の娘」。ティシリアは彼女に嫌われている自覚がある。アルバダオバが将来手伝う対象。
- 引用: 「キニスちゃんの扱いはそちらに一任していますけど」 / 「亜竜王として覚醒したら手伝ってあげてくださいね？」

### レッテ（アルト・イヴニル）
- 何であるか: ガルラ・クオールが可能性を託した存在。ガルラの言葉では「彼」と呼ばれる。
- 関係: ガルラは背後から王を操ることを否定し、レッテに託すことを選んだ。
- 引用: 「僕はレッテに、アルト・イヴニルに彼という可能性を託した。」

### ドルネスタンルフ
- 何であるか: 球神。ガルラ・クオール（筆頭神官）が言葉を代弁していた存在。
- 関係: ガルラの正体に関わる神格。ノゴルオゴルオは「ドルスタームの神殿」での思い出を語っている（推測: ドルネスタンルフと関連する場所）。
- 引用: 「球神ドルネスタンルフの言葉を代弁していたクオール家の筆頭神官がガルラの正体だ。」 / 「ドルスタームの神殿で力を合わせて土をこねくり回したあの思い出」

### クロウサー
- 何であるか: 選定レース（空使い選定レース）の来訪者たち。「クロウサーどもの庭」と呼ばれる舞台に関与する。
- 関係: ノゴルオゴルオらが狙う「空の竜母の青い融血」を総取りしようとしている相手。
- 引用: 「選定レースはクロウサーどもの庭だ、簡単に介入はできねえ。」 / 「奴らが総取りを狙う、空の竜母の青い融血。」

### 塗壁
- 何であるか: ノゴルオゴルオが名乗る称号。危険な言語支配者の転生体であることを示す。
- 関係: ノゴルオゴルオの属性・側面。
- 引用: 「隻頭の岩肌種は、『塗壁』を名乗る危険な言語支配者の転生体だ。」

### ディスケイム家
- 何であるか: 十二長老が統括する家系。ノゴルオゴルオ、アゥルメイア、ティシリア（分家）などが所属する。
- 関係: 内部で権力闘争が行われている。博物城を拠点とする血族意識を持つ。
- 引用: 「ディスケイム家を統括する十二長老の一角。」 / 「ディスケイムの分家という血筋の劣位をものともせずに頭角を現し」
