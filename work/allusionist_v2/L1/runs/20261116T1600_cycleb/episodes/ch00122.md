# 観察ページ ch00122__3-3　もうひとつの左手②.md

### ラーゼフ
- 何であるか: アズーリアに呪術理論やフィリスの性質について解説する人物。研究棟にいる。アズーリアの師匠的存在として振る舞い、装備品を返却し、部下を紹介する。
- 関係: アズーリアの指導者・保護者。【騎士団】の再編人事に決定権を持つ一人。「私」と呼ばれる。
- 引用: 「ラーゼフの口調に熱が籠もり出す。」 / 「総団長どのと私、それから君の希望も加味することになっている。」

### アズーリア
- 何であるか: 主人公（語り手）。左手に寄生異獣フィリスを宿す修道騎士。魔将エスフェイルを倒した功績により序列が上昇した。
- 関係: フィリスの宿主。ラーゼフの弟子・保護対象。【騎士団】の英雄として持ち上げられている。妹を取り戻すことが目的。
- 引用: 「君という存在だけ見ても、君自身が認識しているアズーリア」 / 「修道騎士の誓願を立てた時――異獣憑きになると決意した瞬間から、私はこの左手と運命を共にすると決めたのだ。」

### フィリス（呪祖フィリス）
- 何であるか: アズーリアの左手に宿る寄生異獣。通常の寄生異獣とは異なり、世界そのものや構造、視座を浸食する。「引喩（アリュージョン）」というメタテクスト操作系呪術に分類される現象を引き起こす。
- 関係: アズーリアの左手に宿る。世界そのものを浸食する存在。論証不能な記述を含む呪文の可能性が示唆されている。
- 引用: 「フィリスは世界そのものに対して浸食を行う寄生異獣だ」 / 「それが【呪祖フィリス】だ。」

### 引喩（アリュージョン）
- 何であるか: メタテクスト操作系呪術の用語。語らずとも雄弁に物を語り、言葉の狭間を伝う呪文。任意のテクストを想起させ、間テクスト性を生む。
- 関係: フィリスが用いる技術・概念。神働術もこの枠組みで分類される。
- 引用: 「信仰基盤という高次存在の索引を参照して神の奇跡を再現する神働術も、呪術の枠組みで言えば引喩（アリュージョン）というメタテクスト操作系呪術に分類される」

### 間テクスト性
- 何であるか: 言及されたテクストと想起されたテクストの間に働く相互作用。ミームの概念にも近く、呪術の根幹を成す力。
- 関係: 引喩によって生じる現象。アストラル界（地下茎型の世界観群）の正体に関わる。
- 引用: 「今まさに私が言及している引喩についてのテクストと、君が思い描いた引喩についてのテクストとの間に働く何かしらの相互作用が間テクスト性と呼ばれるものだ。」

### アストラル界
- 何であるか: 多層的に広がる地下茎（リゾーム）型の世界観群。人の数だけ存在する視座・視野が相互に影響を及ぼし合う場所。
- 関係: フィリスが浸食している「世界の中にある君というメタテクスト」が存在する場。アズーリアが遊びに出かける場所。談話室のメンバーがいる。
- 引用: 「そうやって多層的に広がる地下茎（リゾーム）型の世界観群が、君がよく遊びに出かけているアストラル界の正体だ」

### 紀元槍神話
- 何であるか: 天地を貫く複数の世界槍は原初ただ一つの巨大な槍であり、全ての存在はそこに由来するという俗説。大神院では歴とした神学論争の係争中案件。
- 関係: フィリスが単一の対象にだけ影響を及ぼしているという仮説（根本原理による記述）を支える根拠。侵略の大義名分としても使われている。
- 引用: 「紀元槍神話だな。天地を貫く複数の世界槍は、原初ただ一つの巨大な槍であり、全ての存在はそこに由来する。」

### 魔導書
- 何であるか: ラーゼフがアズーリアに返却した黒表紙の書物。第五階層で託されたもの。古い時代に書かれ、暗号の鍵が不明。潜在呪力は相当なものだが難物。
- 関係: アズーリアの装備として登録された。エスフェイルとの戦いで使用されたとされるが、完全な掌握はできていない。
- 引用: 「そう言ってラーゼフが渡してきたのは、見覚えのある黒表紙の書物と槌矛だ。第五階層で託された魔導書と」

### 呪術杖（槌矛）
- 何であるか: ラーゼフ謹製の呪術杖にして打撃武器。ラーゼフがアズーリアに返却した。牽引帯の数を減らし持続時間を伸ばす調整が施されている。
- 関係: アズーリアの装備として登録された。ラーゼフが作成・調整した。
- 引用: 「ラーゼフ謹製の呪術杖にして打撃武器。」 / 「それと、杖のほうは牽引帯の数を減らして持続時間を伸ばす調整をしておいた。」

### 神働術
- 何であるか: 信仰基盤という高次存在の索引を参照して神の奇跡を再現する術。槍神の御業で説明しようとする性質を持つ。
- 関係: 呪術と対比される概念。抽象的な物事を扱う術では呪術体系に分がある。大神院の訓練過程に含まれるがアズーリアには合わないと言われている。
- 引用: 「信仰基盤という高次存在の索引を参照して神の奇跡を再現する神働術も」 / 「大神院の通り一遍な訓練過程で神働術を学んでも、君には合わないだろう。」
