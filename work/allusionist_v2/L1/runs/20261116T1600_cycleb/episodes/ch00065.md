# 観察ページ ch00065__2-44　春の魔女④.md

### レオ
- 何であるか: アキラに連れられ、言葉が理解できず困惑している少年。頭頂部に猫耳を持ち、感覚が鋭敏で他人の感情や声の響き（寒さ・冷たさ）を察知できる。純粋な心根を持つがゆえに、弱者への同情と正義感からアキラを責める発言をする。
- 関係: アキラに袖を引く。松明の騎士団の慈善活動を見て「上の人たちだけしか助けない」と指摘する。ティリビナ人（枯れ木族）の迫害を見つめる。
- 引用: 「おずおずと、レオがこちらの服の袖を引いてくる。」 / 「アキラさんが付けてるみたいな腕は、みなさんに差し上げられないんですか？」

### アキラ
- 何であるか: 主人公（俺）。右腕に電子制御義肢を持ち、左腕は欠損している。半年間この世界で生き残っている。レオを保護・案内しているが、自身の恵まれた状況への罪悪感から自虐的な思考に陥る。
- 関係: レオに連れられ貧困区画へ向かう。ちびシューラ（トリシューラ）と契約し、幻肢接続型の呪術制御義肢の提供を約束される。松明の騎士団とは敵対関係にある。
- 引用: 「俺はレオを連れて、市街の中心区域から外れた道へ逸れていく。」 / 「俺の右腕は、この世界には本来あってはならないものだ。」

### ちびシューラ
- 何であるか: アキラの脳内に埋め込まれ、データ採取と干渉を行う存在。二頭身のデフォルメ体として視界に現れる。棒付きキャンディーを教鞭のように振り、アキラの自虐的思考（全人類皆殺し的な平等論）を「邪悪な魔女っぽい」と諫める。
- 関係: アキラの右腕（電子制御義肢）を解析し、幻肢と接続する「呪術制御義肢」の設計思想を持つ。第五階層の物体創造能力を義肢素材に転用するアイデアを出す。トリシューラの側面または分身と思われる。
- 引用: 「舌に甘みが広がって、棒付きのキャンディーが突き出されていることに気付く。ちびシューラが呆れと怒りを半分ずつ表現しながら、此方を睨み付けていた。」 / 「ちびシューラが表示させたカーソルが、俺の右腕にフォーカスする。」

### トリシューラ
- 何であるか: ちびシューラの本体または上位存在。アキラに協力の見返りとして左腕（義肢）を与える約束をしている。第六階層でアキラを試験し、身体内部を弄くり回してデータを取得した過去を持つ。
- 関係: ちびシューラを通じてアキラと契約しようとする。「サイバネティクスとオカルティズムのハイブリッド」な一点物の義肢を提供する主体。
- 引用: 「トリシューラは義肢を作成可能になる。」 / 「シューラと正式な契約を交わせば、特別に提供してあげるよ。」

### 松明の騎士団
- 何であるか: 地上の大勢力であり、宗教組織（大神院）の連合体。甲冑姿の者と白く清潔な服装をした者で構成される。病院修道会としての側面を持ち、慈善活動やセーフティネットの役割を果たす部門があるが、救済対象を選別する。
- 関係: アキラとは敵対関係（一歩階層の外に出れば殺し合う）。第五階層の中立地帯で施しを行っているが、「上の人たち」を優先し「下の人たち」には手を出さない傾向がある。
- 引用: 「そこで人々に施しをしているのは、【松明の騎士団】と呼ばれる地上の大勢力だった。」 / 「松明の騎士団は宗教組織であり、神の名の下に人々に慈悲を与え、救おうとする。ただし救いを与える対象は選別される。」

### ティリビナ人
- 何であるか: 表皮が枯れ木のように見え、頭部から枝葉や花が生える樹木を想起させる種族。「枯れ木族」と呼ばれると差別になる。過酷な環境適応の結果であり、家を造る習慣がなく野宿可能。第五階層に急増し独自のコミュニティを形成している。
- 関係: かつては「上」に住んでいたが追放され、「下」でも迫害されるという歴史を持つ。レオが見つめる対象。建造物創造能力を売り払ったため社会から疎外されている。
- 引用: 「彼らのような種族を、ティリビナ人というらしい。」 / 「昔は上に住んでたっていう歴史もあって、上と下の両方から迫害されている種族だね。」

### 第五階層
- 何であるか: 物語の舞台となる区画の一つ。浮浪者や貧困層、迷宮探索に失敗した者が集う「ゲットー的な隔離区画」がある。多様な種族（昆虫系、植物系、矮小複眼人など）が混在する。
- 関係: アキラとレオが移動する場所。「公社」に許可された物乞いや街娼の声が響く。第五階層限定の物体創造能力が存在し、それが義肢素材として利用可能であることが判明する。
- 引用: 「辿り着いたのは浮浪者などの貧困層が集う区画だった。」 / 「第五階層限定の物体創造能力は義肢の素材にできる、という。」

### 右腕（電子制御義肢）
- 何であるか: アキラが持つ義肢。感情を制御して戦闘を補助する脳内機器と連動している。この世界には本来あってはならない技術であり、不正によって持ち込まれた「異物」とされる。
- 関係: レオが「みなさんに差し上げられないんですか？」と問う対象。アキラの罪悪感の源泉。ちびシューラが解析し、幻肢接続型の義肢設計の参考データとして使用された。
- 引用: 「俺の右腕は、この世界には本来あってはならないものだ。」 / 「レオが純粋な優しさからその言葉を発したのはわかっている。それでも俺には、その言葉が右腕を引き千切って差し出せという要求に聞こえた。」

### 幻肢
- 何であるか: 失ったはずの腕を脳がまだあるように錯覚する現象（誤作動）。ちびシューラが用意する義肢は、この幻肢と接続することで動作させる仕組みを持つ。
- 関係: アキラの右腕があることで脳が騙されることに慣れているため、左腕への適用成功が見込まれる。「幻影っていう呪術的な存在を捉えて物質と繋げる」という理屈で機能する。
- 引用: 「幻肢ってあるよね。失ったはずの腕を、脳がまだあるように錯覚してしまう、幻の腕。」 / 「メインとなるシステムは、あくまでも幻影っていう呪術的な存在を捉えて物質と繋げるっていう理屈だから」

### 公社
- 何であるか: 第五階層の貧困区画において、物乞いや街娼の活動を許可している組織または権限。
- 関係: 第五階層の治安や社会構造の一部を形成している。
- 引用: 「『公社』に許可された物乞いや街娼たちの声が響き渡り」

### 探索者協会
- 何であるか: 迷宮探索者を支援する組織の一つ。保険加入などのセーフティネットを提供するが、資金がない者は加入できず再挑戦の機会を得られない。
- 関係: アキラが言及する社会制度の一部。「松明の騎士団」と並ぶ組織として挙げられている。
- 引用: 「そもそも松明の騎士団や探索者協会といった組織に入れない者」

### 大神院
- 何であるか: 松明の騎士団を構成する宗教組織の一つ（教圏を広げる主体）。
- 関係: 松明の騎士団の歴史的背景に関わる。地上に多くの種族が暮らしていた時代から、教圏拡大により異獣たちを追放した歴史を持つとされる。
- 引用: 「大神院――松明の騎士団がその教圏を広げる前までは、地上には沢山の種族が暮らしていたの」

### 第六階層
- 何であるか: トリシューラ（ちびシューラ）がアキラを試験し、身体内部を調査した場所。
- 関係: アキラのデータ取得と義肢技術開発のための実験場として機能した。
- 引用: 「だからシューラは第六階層でアキラくんを試して、それから身体の中を弄くり回して隅々まで見させてもらったの」
