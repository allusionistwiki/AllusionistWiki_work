# 観察ページ ch00349__4-118　騒乱②.md

### アレッテ
- 何であるか: 紅紫の髪を持つ魔女。左手でルバーブを拘束し、右手で斬撃、視線でドルンを石化させ、髪を変形させてゴガベズを噛み砕くなど多面的な戦闘能力を持つ。使い魔系呪術師であり、「ワルシューラ」や「ちびシューラ」といった存在を操る。
- 関係: ルバーブの敵対者。カルメーキフ、ドルン、ゴガベズの殺害者。「グレイシス」（髪の中の怪物）の使役者。「ちびシューラ」「ワルシューラ」の背後にいる人物（推測）。ラクルラールに「レッテ」と呼ばれる。
- 引用: 「アレッテの左手は私の足を封じたことで動きが止まっている。」 / 「こら、駄目よグレイシス。ぺってしなさい、ぺって。」

### ルバーブ
- 何であるか: 語り手であり、陛下（我が主）の筆頭侍従武官。大地の民の戦士として呪力を得るが、アレッテの髪による拘束を受け、後に球神ドルネスタンルフの呪いによって狂乱し突撃する。
- 関係: アレッテに足を拘束される。「陛下」を守護する立場。カルメーキフ、ドルン、ゴガベズの指揮官（推測）。ラクルラールに「瓦落多（ガラクタ）」と呼ばれる人物の一人（推測）。
- 引用: 「我が主が鋭く反応した。」 / 「気付けば私は突撃を開始していた。」

### 陛下
- 何であるか: ルバーブの主。機械野郎どもから守られるべき存在。ラフディの民の意思によって「陛下を守る」という決意に押し流され、ルバーブを失う。
- 関係: ルバーブの主。「トリシューラ」の声が虚しく響く対象（推測）。ラクルラールが干渉する下界の存在。
- 引用: 「陛下が思わず一歩退くが、魔女はそちらには目もくれず競技場の方へと向かって行った。」 / 「陛下を機械野郎どもからお守りしろ！」

### カルメーキフ
- 何であるか: ラフディの精鋭戦士の一人。丸盾と球形の呪術障壁で身を守りアレッテに襲いかかるが、アレッテの右五指から伸びる「線の嵐」によって防御を断ち切られ殺害される。
- 関係: ルバーブの部下。アレッテに殺害される。
- 引用: 「戦士の一人、カルメーキフが右側から襲いかかった。」 / 「カルメーキフの堅固な守りをいとも容易く断ち切ったのだ。」

### ドルン
- 何であるか: ラフディの精鋭戦士の一人。獣のように四つ脚で駆けアレッテに襲いかかるが、アレッテの視線（竜爪眼）によって石化し砕け散る。
- 関係: ルバーブの部下。アレッテに殺害される。
- 引用: 「その隙にドルンが獣のように四つ脚で駆け」 / 「呪いの視線によって石化したドルンが砕け散った。」

### ゴガベズ
- 何であるか: ラフディの精鋭戦士の一人。斧を担いでアレッテを攻め立てるが、アレッテの髪が変貌した紅紫の大蛇に噛み砕かれる。
- 関係: ルバーブの部下。アレッテに殺害される。
- 引用: 「ゴガベズが斧を担いでアレッテを攻め立てる。」 / 「ゴガベズは噛み砕かれていた。」

### グレイシス
- 何であるか: アレッテの髪の中に宿る得体の知れない怪物（大蛇のような形）。アレッテに「愛玩動物」のように躾けられ、敵を屠る。
- 関係: アレッテの使い魔または髪の一部。「竜爪眼」と並ぶアレッテの戦闘手段の一つ。
- 引用: 「こら、駄目よグレイシス。ぺってしなさい、ぺって。」 / 「それが蠢き、大蛇のような形に変貌して敵対者を屠ったのである。」

### ちびシューラ
- 何であるか: サイバーカラテを司る小さな妖精。「国土交通シューラ」を名乗り、悪意に満ちた笑顔で競技場を棺桶に改築し、再生者を減らす計画（インテグレイト）を発表する。
- 関係: アレッテの操る存在（推測）。「ワルシューラ」と呼ばれる偽物としてトリシューラに糾弾される。
- 引用: 「サイバーカラテを司る小さな妖精、『ちびシューラ』だ。」 / 「国土交通シューラがみんなにお知らせだよ－！」

### ワルシューラ
- 何であるか: トリシューラの偽物とされる存在。「ちびシューラ」の別名またはその正体。使い魔系呪術【騒乱（メイヘム）】を詠唱し世界を揺るがす。
- 関係: トリシューラの偽物。「ちびシューラ」と同一視される。アレッテの計画の実行者（推測）。
- 引用: 「そいつはワルシューラ！　私の偽物だよ！」 / 「『ワルシューラ』なる偽物は、悪意に満ちた呪文を詠唱する。」

### トリシューラ
- 何であるか: 機械的な女王。競技場の混乱の中で「ワルシューラ」は自分の偽物だと叫ぶが、その声は虚しく響く。アレッテの声によって妨害される。
- 関係: 「ちびシューラ」「ワルシューラ」と対立する存在。「陛下」を守護すべき対象（推測）。ラクルラールに「愚かなトリシューラよ」と呼ばれる。
- 引用: 「どこかからトリシューラの拡声器越しの叫びが聞こえてきた。」 / 「呪術によって拡大された声が、遮ろうとするトリシューラの声を妨害しながら全ての者に届いた。」

### 球神ドルネスタンルフ
- 何であるか: 競技場（儀式場）を支配する神。半球状の天蓋や壁を形成し、閉じ込められた人々を「血を神に捧げるための祭壇」で挽き潰そうとする。ルバーブら大地の民に呪力を与え狂乱させる。
- 関係: アレッテが儀式を行う対象。「ドルネスタンルフの呪い」によって再生者も魂まで塵にされる可能性がある。
- 引用: 「強大なドルネスタンルフの呪いに耐えられる者はそう多くはない。」 / 「球神ドルネスタンルフが歓喜しているのだ。」

### 塔
- 何であるか: 競技場の天井から落下し、閉ざされた球を貫く巨大な柱。アレッテが浮遊する場所であり、「世界を貫く塔」と呼ばれる。
- 関係: アレッテの居場所。「油断ね。長大なもので貫かれるのが世界というものなのに」という台詞の対象。
- 引用: 「直後、真上から巨大な柱が落下してきたのだ。」 / 「牢獄の中に響く、アレッテの声。世界を貫く塔を背後に、紅紫の魔女が浮遊している。」

### ラクルラール
