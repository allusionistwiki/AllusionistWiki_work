# 観察ページ ch00529__5-34　義憤について③.md

### 球神の吐息
- 何であるか: 神話に語られる妖精滅殺の大呪術であり、防御不可能な重圧を放射する。
- 関係: ルバーブがミナに対して使用した技。
- 引用: 「『球神の吐息』よ」 / 神話に語られる妖精滅殺の大呪術。防御不可能の重圧が巨漢の口から放射され、前に出たミナの全身が空中で圧壊。

### ミナ
- 何であるか: 燐血の民であり、炎天使の化身を持つ探索者。清楚なブラウスと背中空きニットワンピースを着用している。
- 関係: ルバーブと戦闘し、最終的に死亡する。ジュティアの相棒。パーンやダウザールを標的とする。
- 引用: 清楚なブラウスと背中空きニットワンピースという妙な出で立ちをした燐血の民は、炎の中で獰猛に笑う。 / あまりにもあっけないミナの絶命。

### ルバーブ
- 何であるか: 古代ラフディの王マラードの右腕であり、大地の民が誇る英雄（猛将）。巨漢。
- 関係: ミナと戦闘する。球神ドルネスタンルフの啓示を受け、あえて死を選ぶことでミナを道連れにする。
- 引用: ここにいるのは古代ラフディに君臨した美しき王マラードの右腕。 / ルバーブは判断ミスによって死んだのではない。神による傀儡化をかわしつつ敵を仕留めるために死を選んだのである。

### ジュティア
- 何であるか: アヴロノの女であり、ミナの相棒。機甲箒で離脱するが、ミナの死により精神が崩壊し浄界が暴走する。
- 関係: ミナを庇う。ハグレスに操られ、パーンを追跡させられる。リーナによって精神を平静に取り戻される。
- 引用: 相棒に庇われたジュティアが機甲箒で離脱していく / ミナの死によって半狂乱となったジュティアは既に正常な精神状態を維持できていない。

### ハグレス
- 何であるか: 球神ドルネスタンルフの姿（かりそめ）を借りてミナを操っていた存在。邪視者。
- 関係: ミナとジュティアを手駒として使役していたが、両者を失い激昂する。ダウザールやパーンに敵意を持つ。
- 引用: ハグレスの罵声が使い魔を叱責する。 / 手駒を失ったばかりか、球神という貴重な化身まで奪われたハグレスは激昂してジュティアに操り糸を伸ばす。

### 貪る炎
- 何であるか: ミナが槍に纏わせる炎による生命吸収（ライフゲイン）効果を持つ呪術基盤。
- 関係: ミナの攻撃と治癒を両立させるが、対象特化型であり防御無視の強制力を持つ。
- 引用: 発動したのは『貪る炎』による生命吸収（ライフゲイン）効果。 / ルバーブの防御や回避を問答無用で無視する強制力は、対象特化型の呪術に特有の挙動。

### 童貞殺し
- 何であるか: ミナの槍に込められた魅了（チャーム）による生命力略奪の本質。
- 関係: 対象が「童貞」であることを条件として威力を増大させる。ミナはこれをパーンに対して使用しようとした。
- 引用: ミナの槍に込められた『童貞殺し』の本質は魅了（チャーム）による生命力の略奪である。 / 「少年（ショタ）化してるってことは～、ほぼ確実に『童貞化』してるってこと！」

### 球神ドルネスタンルフ
- 何であるか: 時と空を統べる神であり、宇宙を象る原初的形態（完全なる球体）。
- 関係: ルバーブに啓示をもたらす。ハグレスが借りていた姿でもある。ルバーブの破戒によりその姿が奪われる。
- 引用: 球神ドルネスタンルフが、啓示をもたらしてるのだ。 / その魂から伝播した呪詛が操っていた神にまで及び、球神というかりそめの姿が髪の毛によってがんじがらめにされていく。

### 破戒
- 何であるか: ルバーブが眷属種を規定する加護と祝福を放棄し、冥府への帰属表明を実行する行為。
- 関係: 二重眷属種（再生者）であるルバーブのみが可能。球神の傀儡化を回避するための手段。
- 引用: 破戒。その場で眷属種を規定する加護と祝福を放棄。 / 紀神の祝福を拒絶するという掟破りの蛮行だった。

### 炎天使
- 何であるか: ミナの化身であり、蝋燭の火を激しく燃え上がらせる存在。天寿（寿命）を消費して加護を与える。
- 関係: パーンとダウザールの肩に付着し、速度を与えると同時に寿命を焼き尽くす。ミナ死後も継続する。
- 引用: 術者の死後も継続し続けていた炎天使が加護をもたらす。 / ミナの化身は聖典に記された一回性の奇跡、天使現象を再現するものだ。

### パーン
- 何であるか: 六王級の呪詛使いであり、変質した存在（少年化・童貞化）。
- 関係: ミナに狙われるが、ルバーブの死後の怨念（髪の毛）によってミナを殺害する。ダウザールと競走する。
- 引用: パーンは、その真横を何事もなかったかのように通り過ぎて行った。 / ルバーブは判断ミスによって死んだのではない。神による傀儡化をかわしつつ敵を仕留めるために死を選んだのである。

### ダウザール
- 何であるか: レースの先頭を走る老人。長命者（転生者）。
- 関係: パーンに追い抜かれるが、ミナの炎天使の加護を受け寿命を消費させられる。リーナの実力を評価する。
- 引用: 飛散した呪詛の余波を搔い潜ってダウザールがトップに躍り出た。 / 老人は愕然とした表情で己の肩を見ていた。そこには、パーンと同じように小さな炎天使がしがみついている。

### リーナ・ゾラ・クロウサー
- 何であるか: 三角帽子を被った魔女。千切られた大学ノートを魔導書として使用する。
- 関係: ジュティアの暴走する浄界を箒の軌跡で浄化し、ハグレスに怒りを向ける。パーンを追う。
- 引用: リーナ・ゾラ・クロウサーは真っ直ぐに前を見据えながら、確かに天に唾を吐いた。 / 呪文発動のたびに即席の魔導書を作ってるみたい。

### 大学ノート
- 何であるか: リーナが呪文発動ごとに作成する即席の魔導書。
- 関係: 大気と空間認知のモデルを一回ごとに特化させて呪文を組み上げるために使用される。
- 引用: 響く詠唱、千切られた大学ノート。 / 呪文発動のたびに即席の魔導書を作ってるみたい。

### 浄界
- 何であるか: 空間や内面を反映した世界（絶望の世界など）。暴走する現象。
- 関係: ジュティアが暴走させる。リーナが箒によって掃き清める（浄化する）。
- 引用: 猛追する浄界魔弾は捻じれた軌跡を描いてわだかまる闇の世界を広げていた。 / 禍々しい浄界の暴走を、決然たる意思が抑え込む。

### 箒
- 何であるか: 飛翔のための道具であり、聖なる領域を浄化する祭具としての役割を持つ。
- 関係: リーナが使用し、浄界を浄化するための軌跡を描く。ジュティアも機甲箒を使用する。
- 引用: 掃き清める。聖なる領域を浄化する祭具としての箒の役割。 / 地上のみならず天の穢れまでも払うという決意が、その道具に飛翔を求めた。

### 死後の怨念（髪の毛）
- 何であるか: ルバーブが「二度目の死」の際に発動した呪詛。細い長い無数の糸状の毛髪。
- 関係: ミナの喉や手足を縛り上げ、蘇生を阻み殺害する。球神の姿もがんじがらめに拘束
