# 観察ページ ch00079__2-58　転生者殺し④.md

### 眼球（剥き出しの眼球）
- 何であるか: 拳ほどの大きさで、迷宮の隅に浮遊し、超人たちの戦いを監視している物体。第六階層で巨獣カッサリオを召喚した奇怪な目玉と同じもの。
- 関係: 迷宮結界の基点であり、邪視系の使い魔【アブロニクレス】である。コルセスカが凍結させるのは難しいが物理防御が低いため、主人公（俺）が握り潰す対象となる。
- 引用: 「拳ほどの大きさの、剥き出しになった眼球。」 / 「いいですか、あれは邪視系の使い魔【アブロニクレス】といって」

### コルセスカ
- 何であるか: 白い袖無しのワンピースに黒のタイツ、白い長手袋を着た女性。巨大な氷の右目を持つ「冬の魔女」。トリシューラと対をなす存在。
- 関係: 主人公（俺）とは無関係であり、トリシューラとは基本的には敵だが、陰ながら支援している。「振られた」ことを恥ずかしそうに告白する。邪視同士の戦闘でアルテミシアと戦う。
- 引用: 「そして相変わらず感情表現に乏しい表情と、巨大な氷の右目。」 / 「私は既に貴方とは無関係ですし、トリシューラとは基本的には敵ですから」

### トリシューラ
- 何であるか: コルセスカが「アキラと共に歩んでいく準備を整えている」と言及する人物。コルセスカにとって「振られた」相手であり、対をなす存在。
- 関係: コルセスカの敵（基本的には）。主人公（俺）と行動を共にしている。キロンとの戦いにおいて、彼の弓術と神働術が危険であると事前に警告した人物でもある。
- 引用: 「トリシューラはすっかりアキラと共に歩んでいく準備を整えていますし」 / （いい、アキラくん。聖騎士キロンは槍術、棍術、騎乗術と武芸一般に秀でた一流の聖騎士だけれど、本当に危険なのは彼の弓術と神働術）

### アキラ
- 何であるか: 主人公（俺）。感情制御により無感情に近い状態にある。コルセスカから「アキラ」と呼ばれる。
- 関係: コルセスカが支援対象としている人物。トリシューラと共に歩んでいる。【松明の騎士団】を敵視し、キロンを殺すことを躊躇わない。
- 引用: 「安心しろ。今の俺は極めて無感情に近い状態だからコルセスカがどんなことを考えていても何も思わない」 / 「アキラ、君は我々を――【松明の騎士団】を、憎んでいたのか」

### カッサリオ
- 何であるか: 第六階層で眼球（使い魔）によって召喚された巨獣。
- 関係: 現在の迷宮を作り出した存在と同じ個体（使い魔）が呼び出す対象として言及される。
- 引用: 「忘れもしない、第六階層で俺達の前に現れ、巨獣カッサリオを召喚した奇怪な目玉が」

### アブロニクレス
- 何であるか: 邪視系の使い魔。邪視に強い抵抗力を持つが、物理防御能力が低い。
- 関係: 眼球（剥き出しの眼球）の正式名称。コルセスカが凍結させるのは無理だが、主人公が打撃で潰す対象。
- 引用: 「いいですか、あれは邪視系の使い魔【アブロニクレス】といって」

### アルテミシア
- 何であるか: 聖騎士。髪を振り乱して石化現象を操る。左目（右目はコルセスカが巨大な氷の右目を持つため、対比として言及されている文脈から推測されるが、原文では「片目を押さえて」とあり、視認するだけで世界を書き換える能力を持つ）。
- 関係: コルセスカの敵。凍結と石化の領域で戦い、敗北後に自らの脚を石化・破壊して地下へ逃走する。「その奇眼」をコルセスカに焼き付けると宣言する。
- 引用: 「アルテミシアが迎え撃つようにして髪を振り乱せば逆側から石化現象が拡大、浸食していく。」 / 「悪態を吐きながら、片目を押さえてうずくまるアルテミシア。」

### キロン
- 何であるか: 聖騎士。漆黒の槍を持っていたが、少年の頭に触れることで純白の弓に変化させる。【松明の騎士団】に所属する。
- 関係: 主人公（俺）の敵。アズーリアに対して信頼を失っていないと主人公に指摘される。弓術と神働術を用いて主人公を攻撃しようとする。コルセスカが「同属」と呼ぶメクセトの禁呪に関わる武器の擬人化を行う。
- 引用: 「聖騎士キロンが漆黒の槍を手に、何か言いたげにこちらを向いている。」 / 「キロンの手の中で、少年が裸身を光り輝かせている。」

### 【松明の騎士団】
- 何であるか: キロンが所属する組織。主人公（俺）に対して徹底した敵視を行っている。
- 関係: 主人公にとって信用に値しない敵。半年前、エスフェイルを倒し第五階層が放棄された以来、主人公を殺すべき存在とみなしている。
- 引用: 「当然だ。俺と【松明の騎士団】は敵同士。」 / 【松明の騎士団】は信用に値しない。

### アズーリア
- 何であるか: 半年前、主人公を見捨てざるを得ない状況に陥った人物（推測: キロンと同じく地上側の人間）。
- 関係: キロンがアズーリアに対して信頼を失っていないと主人公に言及される対象。主人公にとっての過去の裏切り（見捨てられ）の象徴の一つ。
- 引用: 「まさに半年前、アズーリアがそのようにして俺を見捨てざるをえない状況に陥ったのではなかったか。」

### 少年（三人の少年たち）
- 何であるか: キロンの傍らにいる裸身の少年たち。キロンの弓の変換に関与し、不可視の障壁でキロンを守る。
- 関係: キロンの武器（弓）の擬人化の一部または媒介となる存在。一人は腕と一体化した方形盾を持ち、コルセスカの凍結を防御するが片腕が石化している。
- 引用: 「キロンの手の中で、少年が裸身を光り輝かせている。」 / 「三人の少年たちが立ち塞がる。」

### 迷宮結界
- 何であるか: 眼球（アブロニクレス）を基点として展開されている空間。約八百個の使い魔が分散して改変を行っていた。
- 関係: 主人公が眼球を潰した結果、壁が消え、以前の第五階層（街であった空間）に戻っていく。
- 引用: 「恐らくアレが現在展開されている迷宮結界の基点です。」 / 「俺が眼球を握りつぶした結果なのか、周囲から迷宮の壁が消え始める。」

### 邪視
- 何であるか: 視認するだけで世界を書き換える能力。投射型の石化邪視や凍結の邪視が存在する。
- 関係: コルセスカ（凍結）とアルテミシア（石化）が相対した際の戦闘の性質。「自らへの確信を失った邪視者ほど脆弱」とコルセスカが述べる。
- 引用: 「視認するだけで世界を書き換える能力を持つ両者が相対した時、その戦いは世界の改変合戦の様相を呈する。」 / 「自らへの確信を失った邪視者ほど脆弱な存在もない。」

### 神働術
- 何であるか: 聖騎士が用いる呪術。弓術と並んでキロンにとって本当に危険な力。
- 関係: キロンが弓を持ち出した際に発動しようとしているもの。トリシューラが事前に警告していた。
- 引用: 「本当に危険なのは彼の弓術と神働術」 / 「つまり、キロンが弓を持ち出した時、彼はその最大の力である呪術を発動しようとしているということになる。」

### メクセトの禁呪
- 何であるか: 武器の擬人化に関わる禁呪。コルセスカが「私と同じ」と言及するもの。
- 関係: キロンの弓（少年の変換）とコルセスカの能力（氷の右目など）が連なるものとして言及される。
- 引用: 「武器の擬人化――私と同じ、メクセトの禁呪に連なるもの」
