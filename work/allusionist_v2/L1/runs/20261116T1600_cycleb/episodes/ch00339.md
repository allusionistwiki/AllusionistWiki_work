# 観察ページ ch00339__4-108　ゲームスタート①.md

### 弾道学（バリスティクス）
- 何であるか: サイバネティクスの基礎であり、照準器の調整、空気の流れ計算、着弾観測と誤差修正、運動エネルギーの推定、フィードバックを繰り返す情報処理システム。
- 関係: この世界では投射武器の発達が遅れたため、高位呪術師が独占する技術となっている。トリシューラ（シューラ）がこれを応用して高射砲の対空射撃を行っている。
- 引用: 「弾道学（バリスティクス）はサイバネティクスの基礎だ。」

### ちびシューラ / トリシューラ / シューラ
- 何であるか: 【星見の塔】有数の銃士であり、ガロアンディアンの王。技術力に優れ、弾道予報を応用した高射砲で敵の投石を撃ち落とす。住民の物質創造能力を徴集し、軍事施設を構築している。
- 関係: アキラくんの同盟者。「ちびシューラ」はアキラくんが彼女を呼ぶ際の愛称と思われる。「王の器がシューラには無い」という自覚がある。【北門】と【北階段】の不具合は彼女による意図的な機能停止である。
- 引用: 「ちびシューラは語る。」 / 「トリシューラはこれを敵対する六王の仕業だと断定。」

### ラフディ
- 何であるか: 第五階層の覇権を狙う勢力（大地の民）。大型バリスタや石像兵（ゴーレム）による投石を行う。隣接するガロアンディアンの領域へ進行し宣戦布告した。
- 関係: ガロアンディアンとアルト率いる竜王国の敵対勢力。技術力ではトリシューラに劣る。「杖」適性に優れ弓矢や投石器の扱いに秀でているが、銃士であるシューラには及ばない。
- 引用: 「第五階層の覇権を狙うラフディは真っ先に他勢力に宣戦を布告。」

### 石像兵（ゴーレム）
- 何であるか: ラフディ軍が使用する大地の呪力を纏った巨大な岩石群や戦闘兵器。高射砲による対空射撃で粉砕される。
- 関係: ラフディの主力兵器。アルト率いる竜王国の航空戦力（蒼空騎士団など）によって翻弄・掃討される。
- 引用: 「大型バリスタや石像兵（ゴーレム）による大地の呪力を纏った投石を、弾道予報を応用した高射砲の対空射撃によって撃ち落とす。」

### 第五階層西部 / 南北を分かつ大通り
- 何であるか: ガロアンディアンとラフディが交戦している戦場。ガロアンディアンの砲列が並んでいる場所。
- 関係: トリシューラの陣営がある場所。ラフディの南西区画が完全に占領されている状況下にある。
- 引用: 「第五階層西部、南北を分かつ大通りを前にして、俺とトリシューラの前に砲列が並んでいる。」

### アルト / 竜王国
- 何であるか: ガロアンディアンと共に戦っている友好的な勢力の王。極大呪文を用いて石像兵を粉砕する圧倒的な力を持つ。
- 関係: トリシューラの同盟者。カーティスに「子孫の救援」を約束し、単身スキリシアへ向かった。トリシューラが参照すべき「立派な女王としての在り方」の対比対象として語られる。
- 引用: 「現在俺たちと共に戦っているのはアルト率いる竜王国だけだ。」

### アルマ
- 何であるか: 燐血の民。昨日、操られていた状態から解放された。コルセスカ救出への協力を申し出たが、アルトの極大呪文の直撃を受け倒れ込み、戦える状態ではない。
- 関係: アキラくんの仲間。海中（アストラル界）での戦闘を不得手とするため、コルセスカ救出作戦には参加できない。
- 引用: 「沈んだ表情でこちらに謝罪してきたアルマはコルセスカが囚われている事、トリシューラが置かれている窮状を知り、こちらへの協力を申し出てくれた。」

### コルセスカ
- 何であるか: 囚われている人物。男根城ファルスという建造物に捕らえられている。
- 関係: アキラくんやアルマが救出を望んでいる対象。アストラルの海中にあるため、敵の主力（海の民）にとって有利な戦場にいる。
- 引用: 「コルセスカが囚われている男根城ファルスとかいうふざけた建造物は、アストラルの海中に存在するという。」

### 男根城ファルス
- 何であるか: コルセスカが囚われている建造物。アストラルの海中に存在する。
- 関係: 敵の主力である海の民にとって最大のパフォーマンスを発揮できる戦場。
- 引用: 「コルセスカが囚われている男根城ファルスとかいうふざけた建造物は、アストラルの海中に存在するという。」

### ラクルラール
- 何であるか: 不気味な人形であり、蜘蛛女より上位の存在と推測される敵。こちらの戦力を操る能力を持つ。
- 関係: コルセスカ救出を阻む要因の一つ。攻略の目処が立つまでは救出に向かえない。「王国」の権威の証である【死人の森の断章】を集めることで対抗できる可能性がある。
- 引用: 「敵陣営には不気味なあの人形、恐らくは既に倒した蜘蛛女より上位のラクルラールがいる。」

### 【死人の森の断章】 / 【断章】
- 何であるか: 『王国』の権威の証。集めることでラクルラールに抗える可能性が高まる。
- 関係: ガロアンディアンが当面の目標として収集を進めているアイテム。相手側の王から奪い取ることが問題とされている。
- 引用: 「同じように、『王国』の権威の証である【死人の森の断章】を集めていけばラクルラールに抗える可能性は高い。」

### リールエルバ / 絶対美少女吸血姫神リールエルバ様教団
- 何であるか: 誘拐された人物。聖マローズ教団の内部分裂により発生した狂信的な教団の中心にいる。無事で、戦いの指揮を執り幹部を打ち破っている。
- 関係: カーティスの救援対象（子孫）。半透明の裸身を見せながら戦い、終われば援軍として合流する約束をしている。スキリシアの一地方で紛争に巻き込まれている。
- 引用: 「聖マローズ教団が内部分裂を起こし、マロゾロンド教徒とその中から発生した狂信的な『絶対美少女吸血姫神リールエルバ様教団』に分かれて抗争を開始」

### カーティス
- 何であるか: 群体。アルトの戦力が圧倒的であることを背景に、単身スキリシアへ赴き子孫（リールエルバ）を救援することを決めた。
- 関係: ガロアンディアンの同盟勢力の一つだが、現在は第五階層から離れている。白骨迷宮に設置した【扉】から影の世界へ向かった。
- 引用: 「カーティスはアルトの戦力が圧倒的ということもあって、単身スキリシアへ赴くことを決めた。」

### 【マレブランケ】
- 何であるか: ガロアンディアンの近衛兵、親衛隊。牙猪（チリアット）と銃士（カルカブリーナ）が所属し、前線で活躍している。
- 関係: トリシューラの軍事力の一端を担う。巨大な石像兵と殴り合い引けを取らない牙猪や、高い『杖』適性を持つ銃士が含まれる。
- 引用: 「近衛兵、あるいは親衛隊である【マレブランケ】のメンバーも精力的に働いてくれている。」

### 牙猪（チリアット）
- 何であるか: 【マレブランケ】のメンバー。前線で巨大な石像兵と殴り合い、まったく引けを取らない戦闘力を持つ。
- 関係: ガロアンディアンの親衛隊の一員。トリシューラの軍事力の構成要素。
- 引用: 「前線で巨大な石像兵と殴り合ってまったく引けをとらない牙猪（チリアット）」

### 銃士（カルカブリーナ）
- 何であるか: 【マレブランケ】のメンバー。高い『杖』適性を持つ。
- 関係: トリシューラと同じく「銃士」の肩書きを持つ者たち
