# 観察ページ ch00111__2-90　サイバネティクスとオカルティズムの幸福なマリアージュ⑥.md

### トリシューラ
- 何であるか: アキラのパートナーであり、魔女。アキラに義肢の解説や世界の知識を語る役割を果たす。第六位（予定）と自称するが、コルセスカからは「お姉様」と呼ばれ、個体として最強だと評される。
- 関係: アキラの彼女。コルセスカの姉妹（キュトスの姉妹）。トライデントを不倶戴天の敵として嫌悪している。ちびシューラと同一人物と思われる（推測）。
- 引用: 「満足するまで大人しく耳を傾けるのが俺の彼女に合わせたやり方だった。」 / 「わ、私セスカに勝ったし」

### アキラくん
- 何であるか: 物語の語り手（俺）。異世界からの転生者と思われる。右手で氷鏡や時間減速、左手で反撃を行う戦闘スタイルを持つ。性自認と肉体の性別が一致している人物として描かれている。
- 関係: トリシューラの恋人。コルセスカに守られる存在。キロンと戦っている。トライデントの禁呪【融血呪】の影響下にある。
- 引用: 「この義肢は私の技術とアキラくんの身体性との融合。」 / 「まさに今、俺はトライデントの禁呪【融血呪】の恐ろしさを体感している最中だったからだ。」

### 呪装義肢アーザノエルの御手【ウィッチオーダー】
- 何であるか: トリシューラの技術とアキラの身体性が融合した義肢。手の甲を覆う立体積層曼荼羅が魔法円に変化し、杖の紋章が現れる。陰陽太極の呪装であり、性自認と肉体の性別が異なる人（または異性の目を意識させる状態）に安定した呪力を与える効果を持つ。
- 関係: アキラが装着している。ヘルマプロディートスやアンドロギュヌスの喩えで語られる。左手として機能し、反撃を行う。
- 引用: 「手の甲を覆うように展開される立体積層曼荼羅の姿が変化し、いつかトリシューラの背後に現れた魔法円となる。」 / 「男である俺が使う事で、陰の気と陽の気が合わさり、安定した呪力が得られると説明が続いた。」

### コルセスカ
- 何であるか: トリシューラと共にいる魔女。キュトスの姉妹の一人。ヘルマプロディートスよりアンドロギュヌスが適切だと指摘する。超高速で動いた結果キロンに圧倒され、弱体化呪術による支援が必要とされている。
- 関係: トリシューラの姉妹（推測されるが原文では「私達全員」という文脈から連帯）。アキラの使い魔として守る対象。トライデントを敵視している。
- 引用: 「コルセスカが口を挟んで来た。」 / 「コルセスカは下手に超高速で動いてしまったばかりに、キロンにそれを上回る速度で圧倒されてしまった。」

### キロン
- 何であるか: 人馬（ケンタウロス）の姿をした敵。神滅具と完全な融合を果たし、総合的な呪力が上昇している。クロスボウから白い閃光を放ち、漆黒の槍で攻撃する。真の名や経歴を持つが、殺すことは誰にもできないと推測されている。
- 関係: アキラたちが戦っている相手。神滅具と融合している。鮮血呪による価値操作呪術に関与している（トリシューラから奪ったもの）。
- 引用: 「浮遊する人馬の左手がこちらを照準する。」 / 「神滅具と完全な融合を果たした事で、その総合的な呪力が上昇しているのがはっきりとわかる。」

### トライデント
- 何であるか: 使い魔の魔女。四魔女の一人。「最後の魔女」を目指す候補者だが、他の候補者を全滅させて自分だけが勝利する（個を消滅させ内部に取り込む）ことを宣言している。禁呪【融血呪】を持つ。
- 関係: トリシューラとコルセスカの敵。アキラが対峙する予定の相手。使い魔の魔女であり、事実上の従属や個の生贄を強いる存在。
- 引用: 「トライデントは使い魔の魔女だもの。」 / 「まさに今、俺はトライデントの禁呪【融血呪】の恐ろしさを体感している最中だったからだ。」

### 神滅具
- 何であるか: キロンと融合した存在。これによりキロンの総合的な呪力が飛躍的に上昇し、攻撃が重くなる。
- 関係: キロンの力源の一つ。キロンとの「完全な融合」状態にある。
- 引用: 「神滅具と完全な融合を果たした事で、その総合的な呪力が上昇しているのがはっきりとわかる。」

### 融血呪
- 何であるか: トライデントの禁呪。複数の個体間の結束を強化し、個を生贄にしてより巨大で新しい個に作り替える効果を持つ。アキラに対しては「最悪」な状況（死の危険）をもたらしている。
- 関係: トライデントが使用する能力。キロンの力の一部にも関連している可能性が高い（推測）。アキラが現在受けている攻撃の性質。
- 引用: 「トライデントの禁呪【融血呪】の恐ろしさを体感している最中だったからだ。」 / 「融血呪は複数の個体間の結束を強化する。」

### ちびシューラ
- 何であるか: アキラの戦闘中に通信（念話？）で助言を行う存在。キロンの黒槍が物理攻撃用ではなく呪術攻撃用の【杖】であると分析し、データに基づいた推測を提供する。
- 関係: トリシューラの別名、またはトリシューラの一部（側面）である可能性が高い（推測）。アキラに「アキラくん」と呼びかける。
- 引用: 「ちびシューラもその違和感に気付いたようだった。」 / 「（キロンの真の名、その経歴、シューラから奪った鮮血呪による価値操作呪術、そして神滅具――そこから導き出される推論は一つ。」

### 氷鏡
- 何であるか: アキラが右手で生成する防御手段。クロスボウから放たれた白い閃光を反射するために使用される。
- 関係: アキラの右手の能力によって生成される。キロンの攻撃を防ぐために使われる。
- 引用: 「あらゆるものを焼き尽くす破壊の光を、俺は右手で生成した氷鏡で反射する。」

### 杖（黒槍）
- 何であるか: キロンが使用する漆黒の槍。物理的な防御を無視して貫通するという現象を起こす。ちびシューラの分析では「呪術攻撃用の【杖】」と定義されている。
- 関係: キロンの武器。アキラの左腕を貫通する。穂先から微量の呪力反応がある。
- 引用: 「腕を貫いて、漆黒の槍が喉元に迫る。」 / 「つまりあの槍は物理攻撃用じゃなくて呪術攻撃用の【杖】なんだと思う」

### キュトス
- 何であるか: トリシューラとコルセスカが「元は一なるキュトスから生まれた」とされる起源。両性具有の概念（アンドロギュヌス）の参照点として登場する。
- 関係: トリシューラとコルセスカの姉妹としての起源。ヘルマプロディートスとの対比で語られる。
- 引用: 「私達は元は一なるキュトスから生まれたとされるキュトスの姉妹。」

### ヘルマプロディートス
- 何であるか: ギリシャ神話における両性具有者。トリシューラが義肢の喩えとして使用したが、コルセスカによって「正反対の発想」として否定され、以後口に出すことを禁じられた単語。
- 関係: トリシューラの比喩表現。トライデントの発想（融和・合一）と関連付けられ、トリシューラが嫌悪する対象。
- 引用: 「アキラくんの世界で喩えると、ヘルマプロディートスの疑似再現って所かな」 / 「今後ヘルマプロディートスという単語を一切口に出すことを禁じます。」

### アンドロギュヌス
- 何であるか: コルセスカが提案した概念。両性具有者が別れて男女が生まれたという発想。「男女は元来同じものであった」という視点を含む。
- 関係: ヘルマプロディートスの対比として登場。コルセスカの思考（異質さの無意味化）を示す。
- 引用: 「ヘルマプロディートスよりはアンドロギュヌスの方がより適切に思えますね」

### 第六階層
- 何であるか: アキラが過去
