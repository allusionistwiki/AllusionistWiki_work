# 観察ページ ch00117__2-96　サイバネティクスとオカルティズムの幸福なマリアージュ⑫.md

### アキラくん
- 何であるか: 主人公。キロンとの戦闘後に合体を解除し、屋上に降り立つ。脳が摘出され水槽から遠隔操作されている可能性や、複製された存在である可能性について思考する。「日本人のサイバーカラテ使い」と呼ばれる。
- 関係: トリシューラの協力者（後輩）。コルセスカの保護対象（吸血される側）。ベアトリーチェに「転生者」「忌むべき転生者」として認識されている。
- 引用: 「気がつけば、映像の中で歌姫のステージが終わりを告げているようだった。」 / 「わたくしのあの世界での名はベアトリーチェ。この世界での名はセレクティフィレクティ。この身は二つの魂が融け合った二重転生者。以後お見知りおきを、日本人のサイバーカラテ使い。」

### トリシューラ
- 何であるか: アキラくんと並んで立つ魔女。「鮮血のトリシューラ」と呼ばれる。アキラくんの脳を複製・シミュレートする技術を持つ。自身の中に「ちびシューラ」や「高次のトリシューラ」が存在することを認めている。
- 関係: アキラくんの指導者（先輩）。コルセスカの同僚（相補の魔女）。ベアトリーチェに「鮮血のトリシューラ」として認識されている。キロンを裏から操った手口がトリシューラを思わせると言及される。
- 引用: 「トリシューラと二人並んで向かい合う。」 / 「氷血のコルセスカと鮮血のトリシューラ、そして忌むべき転生者よ」

### コルセスカ
- 何であるか: アキラくんの右手に握られていたが、光に包まれて人の形態を取り戻した魔女。「氷血のコルセスカ」「冬の魔女」と呼ばれる。凍結の邪視を使う。ベアトリーチェとは長年の宿敵同士。
- 関係: アキラくんの保護者（脛を囓って生きていると表現される）。トリシューラの同僚。ベアトリーチェに「相補の魔女」「冬の魔女」として認識されている。
- 引用: 「まだ俺の右手に握られていたコルセスカが白い光に包まれた。」 / 「氷血のコルセスカと鮮血のトリシューラ、そして忌むべき転生者よ」

### キロン
- 何であるか: アキラくんが戦っていた強敵。第五階層で遺体として発見される。正義と己の傷を盾に残虐な行いを正当化していたとベアトリーチェに評される。「我らが筆頭騎士の花嫁」という言葉を残して死んだ。
- 関係: ベアトリーチェによって裏から操られていた手駒。融血呪によって復活させられた過去がある。その遺体から溢れた流体が回収対象となる。
- 引用: 「キロンは強敵だ。」 / 「彼は正義と己の傷を盾に自らの残虐な行いを正当化する恥知らず。」

### ベアトリーチェ / セレクティフィレクティ
- 何であるか: 第五階層に現れた敵。使い魔の転生者（ゼノグラシア）。下方勢力の将（ジェネラル）たちを率いる元帥（マーシャル）。世界槍の迷宮支配者（ダンジョンマスター）。二重転生者。
- 関係: アキラくん、トリシューラ、コルセスカの敵。キロンを利用していた主人。レオ（獅子王）の存在により退去する。「融血のトライデント」に見出された存在。
- 引用: 「わたくしのあの世界での名はベアトリーチェ。この世界での名はセレクティフィレクティ。」 / 「使い魔を使う使い魔』にして、下方勢力の将（ジェネラル）たちを率いる元帥（マーシャル）。世界槍の迷宮支配者（ダンジョンマスター）」

### 八万の眼球アブロニクレス
- 何であるか: ベアトリーチェが使う邪視系使い魔。空中に浮遊する無数の眼球。古代に失われた文明で崇拝されていた神とも、精霊とも言われる。融解現象をもたらす。
- 関係: ベアトリーチェの使い魔。第六階層、第五階層、キロン復活時などに現れた存在と同一視される。「軍勢」と呼ばれるほどの数。
- 引用: 「邪視系使い魔、【八万の眼球アブロニクレス】――古代に失われた文明で崇拝されていた神とも、精霊であるとも言われています」 / 「空中に浮遊する、夥しい数の目、目、目。」

### レオ
- 何であるか: 猫耳を動かしながら第五階層を走り回る小さな姿。記憶喪失の少年。ベアトリーチェが「獅子王」と呼ぶ存在。
- 関係: ベアトリーチェの戦意を消滅させる要因となる存在。「地獄の貴種」「やんごとない身分」であると推測される。ちびシューラがその正体について推測する。
- 引用: 「その視線の先にいたのは、猫耳をぴくぴくと動かしながら第五階層を走り回る、小さな姿。」 / 「そんな馬鹿な。ありえない。獅子王の――あの方がなぜここに？」」

### ちびシューラ
- 何であるか: トリシューラの内部に刻印された存在。仮想視界で縮こまる形で現れる。古代の言語を話す。ベアトリーチェやレオに関する情報をサジェストする。
- 関係: トリシューラの側面（自己の一部）。アキラくんの脳内に刻印されている可能性が言及される。レオの正体について推測を行う。
- 引用: 「仮想視界で縮こまるちびシューラがサジェストした情報には、魔軍元帥の詳細なプロフィールが載っている。」 / 「ちびシューラをアキラくんの中に刻印した時も同じ事があったけど」

### 融血呪
- 何であるか: キロンを復活させた呪術。キロンの遺体から溢れ出た蒼い流体として現れる。ベアトリーチェが回収しようとする転生者の力が含まれている。
- 関係: キロンの復活の手段。ベアトリーチェが「ハルハハールの亡骸」を取り戻すための材料の一部。コルセスカによって凍結・奪取される対象（神滅具を含む）。
- 引用: 「三度目がキロンを融血呪によって復活させた時。」 / 「第五階層に飛散した氷漬けのキロンの遺体、そこから溢れた融血呪の流体が浮上してたゆたっているのだ。」

### 神滅具
- 何であるか: キロンの遺体から溢れた蒼い流体の中に閉じ込められていた五つの物体。輝きと蝶の翅とともに存在していた。
- 関係: ベアトリーチェが回収しようとしていたもの。コルセスカによって「凍れ」と呟かれ、正確に五つだけ凍結させて奪い返された。
- 引用: 「その内側には十数個の輝きと、五つの神滅具、そして蝶の翅が閉じ込められているように見えた。」 / 「コルセスカが小さく「凍れ」と呟いて、正確に五つの神滅具だけを凍結させて奪い返す。」

### 融血のトライデント
- 何であるか: ベアトリーチェが見出された存在（魔女候補）。ベアトリーチェが所属する組織または勢力。
- 関係: ベアトリーチェの所属先。コルセスカは「猫の腰巾着」と呼ばれるが、トライデントに所属しているのはメルトバーズへの忠誠のためだとベアトリーチェは主張する。
- 引用: 「最後の魔女候補の一人、融血のトライデントに見出された『使い魔を使う使い魔』」 / 「わたくしは変わらぬ忠誠と崇敬を大いなるメルトバーズ様に捧げております。トライデントに所属しているのはその為の手段に過ぎない」

### メルトバーズ
- 何であるか: ベアトリーチェが忠誠と崇敬を捧げている存在。「大いなるメルトバーズ様」と呼ばれる。
- 関係: ベアトリーチェの上位者または信仰対象。トライデント所属の理由として言及される。
- 引用: 「わたくしは変わらぬ忠誠と崇敬を大いなるメルトバーズ様に捧げております。」
