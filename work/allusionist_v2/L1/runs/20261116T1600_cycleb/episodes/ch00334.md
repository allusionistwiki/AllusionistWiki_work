# 観察ページ ch00334__4-103　異界転生②.md

### ちびシューラ
- 何であるか: ガロアンディアンの行政・管理を担う存在。経済、農林水産、運輸など多様な分野の「妖精さん」として視覚化されているインターフェース。
- 関係: アキラ（俺）の主であり、コルセスカとも関連する存在。ヴァージルによって呪術的に囚われ、磔にされている状態にある。
- 引用: 「ちびシューラが慌てた様子で手を上下に振る。」 / 「これらのちびシューラは、このガロアンディアンを回していくために必要不可欠なシステムを視覚的に捉えやすくするためのインターフェースだが、呪術的には『人間の代わりに仕事をしてくれる妖精さん』だ。」

### 第五階層
- 何であるか: 物語の舞台となる小世界。天蓋が失われており、転生力が満ちている場所。
- 関係: ガロアンディアンの一部であり、ヴァージルの呪術によって構造そのものが変貌・亀裂が入っている。
- 引用: 「第五階層に満ちる転生力は過去最大級の高まりを見せていた。」 / 「天が歪む。第五階層に亀裂が入り、構造そのものが変貌していた。」

### 六人の王（六王）
- 何であるか: 過去から現代へ旅立ち、この世界で同時転生した6名の王たち。イアテム、クレイ、ヴァージル、サイザクタート、パーン、アルト、オルヴァ、マラード、ルバーブ、カーティスなどが含まれる（原文では「六人の王」と記述されるが、登場人物はこれら複数）。
- 関係: 【死人の森】の女王倒壊後に暴走し、コルセスカを巡って互いに激突している。ヴァージルは他の王たちを敵に回して行動している。
- 引用: 「六人の王による同時転生。」 / 「復活した六王たちは【死人の森の女王】が倒れた途端に暴走を始めた。」

### イアテム
- 何であるか: 呪術師（一級言語魔術師）。声は圧殺され、空間ごと引き裂かれて肉塊となるなど、激しい被害を受けている。
- 関係: ヴァージルや他の王たちの攻撃対象。イアテムの群が「線の嵐」でずたずたに引き裂かれている。
- 引用: 「イアテムの声は圧倒的な六王の力によって圧殺された。」 / 「残ったイアテムたちが『線の嵐』としか形容しようのない呪術でずたずたに引き裂かれていった。」

### 【死人の森】
- 何であるか: 砕かれた場所・概念。正統な王権保持者にしか解除できない「太陰の封印」が解けている。
- 関係: ブウテトの力を削ぐ要因となった。ヴァージルによって再生されようとしている（逆位置の『王国』）。
- 引用: 「【死人の森】は砕かれ、ブウテトはその力を大きく削がれたものの、当面の敵は撃退できた。」 / 「【死人の森】は再生する――逆位置の『王国』、さかしまのテテリビナ、原初の歌を紡げ九罪源の断章」

### ブウテト
- 何であるか: 豚の姿をした存在。気を失っており、コルセスカによって一時的に凍結封印されている。
- 関係: クレイが救出しようとしていた。マラードの手の中で光り輝き、コルセスカへと姿を入れ替えた（逆転現象）。
- 引用: 「横たわる豚を救出しようとしている」 / 「ブウテトから人へ。ブウテトからコルセスカへと。」

### クレイ
- 何であるか: 倒れている人物。唇を噛んで理性を保とうとし、震える手で立ち上がろうとしている。
- 関係: ブウテトの救出を試みているが、ヴァージルの行動に絶叫して制止しようとした。呪力が弱まっている。
- 引用: 「クレイが唇を噛んで必死に理性を保とうとしている。」 / 「腕を振って斬撃を飛ばすが、サイザクタートに触れると稲光が弾けて無効化されてしまった。」

### ヴァージル
- 何であるか: 紅顔の美少年。雷によって構成された三頭犬（サイザクタート）を駆使し、天に雷を放つなど圧倒的な呪力を持つ。
- 関係: ガロアンディアンの敵として行動し、ちびシューラを奪取しようとしている。カーティスの「夜の民の触手呪文」で追い込まれるが、破壊を巻き戻す能力を持つ。
- 引用: 「跳躍したヴァージルの足下に、雷によって構成された三頭犬が出現する。」 / 「厳密に言えば、一度全身が引き裂かれた直後、一瞬にして破壊が無かったことになったのである。」

### サイザクタート
- 何であるか: 雷によって構成された三頭犬。中央の頭部は初代サイザクタート（祖父）、左右の頭部は子孫（ディーとダム）。
- 関係: ヴァージルの使役する存在。破壊を巻き戻す能力を持つ。「発勁用意」などの戦闘技術とは異なる神秘の業を使う。
- 引用: 「中央の頭部が目を見開いて大気を震わせた。」 / 「先程まで眠っていたサイザクタートの左右の頭部が目覚めていた。互いを『ディー』『ダム』と呼び合う頭部の瞳が朱色に輝くと」

### パーン
- 何であるか: 眼鏡をかけた人物。右腕は義肢（波動に包まれている）。低出力の波動でアキラを吹き飛ばすなど、冷静な判断と戦闘能力を持つ。
- 関係: アキラ（俺）を制止し、ルバーブと激突する。巨人の力を解放しようとするがヴァージルに妨害される。
- 引用: 「横合いから叩き込まれた低出力の波動が俺を吹き飛ばす。パーンの横槍だ。」 / 「空高く飛び上がったパーンが右腕を掲げて巨大な藍色の光球を生み出す。」

### アルト
- 何であるか: 氷爪を使う王。叫びそのものが【吐息（ブレス）】となる極寒の呪力を操る。
- 関係: ヴァージルやパーンなどの攻撃を凍結させる。トリシューラを下がらせるなど、戦場を統制しようとする動きを見せる。
- 引用: 「マラードとルバーブが、アルトが、オルヴァが、揃って制止しようと一斉攻撃を加える。」 / 「アルトの叫びそのものが【吐息（ブレス）】となって吐き出され、全てを凍結させる極寒の呪力が吹き荒れる。」

### オルヴァ
- 何であるか: 大賢者。カシュラム十字の形に輝く瞳を持ち、未来を見通す能力を持つ。イアテムの時間を停止させて足場にするなど高度な移動技術を使う。
- 関係: ブレイスヴァ（キシャル）を巡ってオルヴァが叫ぶ。マラードの大地支配に対して無傷で回避する。
- 引用: 「鋭い槍の連撃も流れるような動きで回避していった。カシュラム十字の形に輝く瞳が未来を見通しているのだ。」 / 「おお、ブレイスヴァ！ 私からまたしてもキシャルを奪うのか！」

### マラード
- 何であるか: 美貌を持つ王。大地そのものを使い魔とする支配者で、局地的な地震を引き起こす。コルセスカに執着し、暴言を吐く。
- 関係: コルセスカを抱きかかえ、彼女を「俺だけのセレス」と呼ぶ。ルバーブに守られているが、アキラからは殺意の対象とされている。
- 引用: 「マラードは、大地そのものを使い魔とする支配者だったのだ。」 / 「いい加減、この俺のものになるがいい。あなたがこの美貌に屈したがっているのは分かっている」

### ルバーブ
- 何であるか: 巨体を持つ武術家。「元祖サイバーカラテ・ラフディ相撲」を修め、頭髪で相手の腕を絡め取るなど複合的な体技を使う。【サイバーカラテ道場】をインストールしている。
- 関係: マラードの忠臣として彼を守る。パーンと激突し、アキラ（俺）とも戦う。「陛下の願いを叶えるのみ」と述べる。
- 引用: 「ルバーブは自らの頭髪を自在に動かしてパーンの腕を絡め取ると、そのまま捻りを加えて投げ飛ばす。」 / 「私は、陛下の願いを叶えるのみ」

### カーティス
- 何であるか: 影に紛
