# 観察ページ ch00326__4-95　ガイノイドの魔女②.md

### ミヒトネッセ
- 何であるか: 片足立ちから独楽のように高速回転し、竜巻のような激しさで旋回して呪力を撒き散らすガイノイドの魔女。首にぜんまいばねが刺さっており、侍女服（エプロンドレス）を着用している。
- 関係: トリシューラの幼なじみであり、彼女への狂おしい愛を告白する。「号は足蹴の砂茶色、性は淫乱メイドロボ、卑しい起源はガイノイド」という宣名を持つ。TSX-8ミヒトネッセという名称も持つ。
- 引用: 「ミヒトネッセが片足立ちの状態のまま急速な回転を開始した。」 / 「号は足蹴の砂茶色、性は淫乱メイドロボ、卑しい起源はガイノイド」

### トリシューラ
- 何であるか: ミヒトネッセから「がらくた」「ぽんこつ」と罵倒され、殺意を漲らせる杖の魔女。朗らかな笑顔を貼り付けた透徹とした無表情を見せるが、ミヒトネッセの発言に激怒し血相を変える場面もある。
- 関係: ミヒトネッセの幼なじみであり、かつて「呪槍銃」でミヒトネッセを貫いたとされる（ミヒトネッセはこれを性的メタファーと解釈）。アキラくんに射撃して追い込むよう指示を出す。
- 引用: 「朗らかな笑顔を顔に貼り付けた、透徹とした無表情。殺意が漲っていた。」 / 「私がいない間、散々失敗ばかりだったみたいじゃない？」

### ちびシューラ
- 何であるか: アキラくんの視界隅にいる存在で、トリシューラの視界を表示したり、アキラくんに指示やツッコミを入れたりする。ミヒトネッセの発言に怒髪天を衝く勢いで真っ赤になるなど感情豊か。
- 関係: アキラくんと対話する（脳内でのやり取り）。ミヒトネッセの魅了呪術に対してアキラくんを叱咤激励し、対抗呪文を発動させる役割を果たす。
- 引用: 「ちびシューラ経由でトリシューラの視界を表示すると」 / （ちょっとぉっ！ もう、めんどくさいっ！ 今回は責めないけどむかつくー！ アキラくん気をしっかり持って！）

### ぜんまいばね
- 何であるか: ミヒトネッセの頭に斜めの角度で突き刺さっており、「ギリギリ」と音を立てて回転している物体。
- 関係: ミヒトネッセの身体の一部（頭部を貫くもの）。アキラくんがミヒトネッセに魅了された際、その容貌の一部として認識される。
- 引用: 「ギリギリ、と音を立てて頭に斜めの角度で突き刺さったぜんまいばねが回転していた。」

### 球形の呪術障壁
- 何であるか: ミヒトネッセが周囲に展開する巨大な防御結界。高速回転しており、チェーンソーなどの攻撃を受け流す仕組みになっている。
- 関係: ミヒトネッセがミヒトネッセ自身を守るために使用。トリシューラの銃弾を阻み、明後日の方向へ跳ねさせる。真上からの攻撃（影の投射など）が有効と推測される弱点を持つ。
- 引用: 「周囲に巨大な球形の呪術障壁を展開して警戒はしているようだが」 / 「チェーンソーで突破できないように障壁自体が高速回転して攻撃を受け流す仕組みになっているようだ。」

### 閃光符
- 何であるか: ミヒトネッセが足下に落とした呪符。影を真上に投射する狙いがあると推測される。
- 関係: ミヒトネッセの戦術の一部。球形障壁の弱点を突くための準備として配置されている可能性がある。
- 引用: 「先程さりげない動きで足下に落とした呪符が気になる。見間違えでなければあれは閃光符だ。」

- 関係: ミヒトネッセがトリシューラへの求愛の証として用意したもの。「トリシューラの追加パーツ」として機能させる狙いがある。最終的にミヒトネッセによって放り出され、球状障壁に巻き込まれて肉片となる。
- 引用: 「首飾りのように、男根が数珠つなぎになって並んでいる。」 / 「頑張って集めたの――けど聞いて！ これは浮気じゃないわ。だって全てトリシューラの追加パーツとして用意したものだから。」

- 引用: 「粉塵の向こうに蜂蜜色の髪を見つけた。怪我は無いようで安心する。」 / 「今の私はルウテトではありません。アキラ様のでりかしーの無い発言にぷんすこしてるブウテトです。ぷぎー」

- 引用: 「すると彼女は頬を膨らませて不満そうに答えた。」 / 「今の私はルウテトではありません。アキラ様のでりかしーの無い発言にぷんすこしてるブウテトです。ぷぎー」

- 関係: ミヒトネッセの得意技を支える力。資料に記述されている内容であり、アキラくんも事前に知っていた設定。
