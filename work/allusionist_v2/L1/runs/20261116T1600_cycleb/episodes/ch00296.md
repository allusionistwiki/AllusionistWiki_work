# 観察ページ ch00296__4-65　死人の森の断章8　calling.md

### 第二浄界――【コキュートス】
- 何であるか: コルセスカが創世した新しい秩序を持つ世界。凍り付いた生命（ゲーム）であり、絶対の裁定者による運命の停止を意味する「氷血（コールドゲーム）」として機能している。
- 関係: コルセスカの浄界。シナモリ・アキラに降ろされた神（プレイヤー）としてのコルセスカが構築した世界。
- 引用: 「聖（ヒエロス）――」私が願い。「――婚（ガモス）」俺が受け止める。そうして、コルセスカの浄界【コキュートス】が新しい秩序を創世する。

### シナモリ・アキラ / 俺 / 私
- 何であるか: 物語の中心となる人物。現在は「俺」と「私」の二つの視点（一人称と三人称/ゲーム操作視点）が混在し、重なり合っている。「俺」はキャラクターとしての側面、「私」はプレイヤー・神としての側面を持つ。
- 関係: コルセスカ（プレイヤー/神）に操られ、同時に没入している主人公。トリシューラや妹たちと共闘する。
- 引用: 「私は未来を幻視する。それが俺たちの見たい世界で、あるべき未来の形だ。」 / 「対戦相手は地上きっての超人ゲーマー、グレンデルヒ・ライニンサル。使用キャラはゾーイ・アキラ。」

### コルセスカ
- 何であるか: シナモリ・アキラを操る「プレイヤー」であり、「神」。ゲームの視点から主人公を操作し、同時に没入する存在。「陛下」と呼ばれることもある。
- 関係: アキラの主人（ご主人様）。浄界【コキュートス】の創造者。アキラと二重憑依している。
- 引用: 「シナモリアキラという操作可能キャラクターをコルセスカというプレイヤーが神の視点から操り、同時に主人公と一体化してゲームの中に没入していく。」

### トリシューラ / ちびシューラ
- 何であるか: アキラの左腕の中で喜びの声上げる存在。「ちびシューラ」とも呼ばれる。アキラのご主人様の一人。
- 関係: アキラに寄り添い、冷たさに共感できる存在。コルセスカと共にアキラを導く。
- 引用: 「（そうだよ！　だって、セスカとシューラはアキラくんのご主人様だもの！）」 / 「俺とトリシューラはお前の冷たさに寄り添えるって、知っているだろう。」

### フィレクティ
- 何であるか: 竜を宿した転生者。アキラたちと対峙する敵の一人。
- 関係: アキラ（私）に瞬時に敗北し、「十年早い」と叫ばれて失神する。セレクティによって運ばれる。
- 引用: 「構えを取るフィレクティ。その身に竜を宿した転生者の動きは、しかし私にとって欠伸が出るものだった。」 / 「何故かフィレクティが白目を剥いて失神した。」

### セレクティ
- 何であるか: カッサリオの主人。召喚の呪文を使う。妹（カッサリオ？）を気遣うような言動を見せる。
- 関係: フィレクティを運ぶためにカッサリオに命じて撤退する。カッサリオに「王獣を名乗るのであれば、その誇りを示しなさい」と厳しく指示する。
- 引用: 「続いて、セレクティが構えを取る。召喚の呪文。」 / 「悔しいですか。ならばそれをばねに更なる高みを目指しなさい。」

### カッサリオ
- 何であるか: セレクティの使い魔であり「王獣」。この時代ではまだ小さな幼獣（イッカクのような姿）。気圧や温度を感知する感覚器兼砲身を持つ牙で衝撃波を放つ。
- 関係: パーン・ガレニス・クロウサーに圧倒されるが、セレクティの叱咤激励を受ける。アキラの【氷腕】ではその破壊の確信を止められない。
- 引用: 「角と見紛うばかりの雄々しい門歯を持った四本脚のイッカクが出現する。」 / 「幼いカッサリオは目の端に涙を溜めながらも立ち上がり、愚直に突進をしてはあっけなくパーンに打ちのめされてしまう。」

### パーン・ガレニス・クロウサー
- 何であるか: 吸血鬼の王。超次元の存在であり、巨人の幻肢や波動の歩法を駆使する怪物。
- 関係: カーティスと決着をつけるために乱入し、カッサリオを撃破する。ミシャルヒに対して「その自由を縛る神を打ち倒し、お前を奪う」と宣言する。
- 引用: 「吸血鬼の王を片端から叩き潰していくパーン・ガレニス・クロウサーは今日も出鱈目に高みから全てを睥睨する。」 / 「独特な波動の歩法で瞬時に間合いを詰めると、邪視者の認識の死角に潜り込むという対邪視者戦闘の高等技法を駆使して奇襲を成功させる。」

### ミシャルヒ
- 何であるか: 幽鬼（レイス）。カーティスの傍で迷いを抱えた表情のまま目を伏せている。
- 関係: パーンに「お前の居場所はそこではないだろう」と指摘される。パーンが奪いに来る対象。
- 引用: 「カーティスの傍で迷いを抱えた表情のまま、目を伏せる幽鬼（レイス）が一人。」

### カーティス
- 何であるか: パーンの敵対者。パーンによって駆逐・決着をつけられる対象。
- 関係: パーンが「さあ決着の時だ」と挑む相手。
- 引用: 「乱舞する薔薇がカーティスたちを駆逐して、荒れ狂う巨人の幻肢が神々を吹き飛ばす。」 / 「来てやったぞ、カーティス！　さあ決着の時だ！」

### グレンデルヒ・ライニンサル
- 何であるか: 地上きっての超人ゲーマー。アキラ（私）の対戦相手。
- 関係: アキラが「私の舞台（ゲーム）」で戦う最終的な敵。
- 引用: 「対戦相手は地上きっての超人ゲーマー、グレンデルヒ・ライニンサル。」

### 紀元槍
- 何であるか: 世界構築に関わる重要な物体。制御盤としての機能を持つ。
- 関係: 七冊目（言理の妖精）が刻まれており、八冊目と繋がっている。コルセスカやスキリシアの浄界の基盤でもある。
- 引用: 「外部性である七冊目が言理の妖精として紀元槍に刻まれてしまった今、それと繋がった八冊の本もまた紀元槍と繋がった制御盤に他ならない。」

### 死人の森の断章
- 何であるか: アキラ（私）が再現・書き上げた物語。全8冊（失われた【氷槍】を除く）。
- 関係: 世界構築の呪術の一部であり、アキラの生還への意思を支えるもの。
- 引用: 「失われた【氷槍】を除いた八つを制御出来る私は、同様に八冊の死人の森の断章をはじめから再現することができた。」

### 冥道の幼姫
- 何であるか: アキラが前世の記憶に基づき書き記した物語の主人公。アキラに宿る六つの名の一つ。
- 関係: 九冊の本（紀元槍の制御盤）を遺した存在。アキラの中に「名前」として入り込む。
- 引用: 「八冊目――私が前世の記憶を基にして書き記した冥道の幼姫の物語。」 / 「【銀の森の魔女】、【死人の森の女王】、そして【冥道の幼姫】という名前がそこに連なり」

### 邪視者
- 何であるか: 己の世界観を世界に押しつけ、思うとおりの世界を構築する能力を持つ者。アキラ（私）はその一人。
- 関係: パーンは「対邪視者戦闘の高等技法」を用いてアキラ（カッサリオ経由？）の死角を突く。
- 引用: 「浄界とは、己の世界観を世界に押しつけて、思うとおりの世界を構築する邪視の奥義だ。」 / 「邪視者の認識の死角に潜り込むという対邪視者戦闘の高等技法」
