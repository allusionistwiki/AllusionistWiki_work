# 観察ページ ch00282__4-51　死人の森の断章3　寝取られ王.md

### オルヴァ
- 何であるか: 王の地位にある青年。線の細い容貌で、気鬱と不安に苛まれ、隠者ウォレスに甘えを指摘される。後に髪が異様に伸びて全身を覆い、左腕が病的に線が細い状態となる。
- 関係: ウォレスの友であり助言を受ける対象。キシャルの夫。「寝取られ王」の異名を持つ。カシュラムの王。
- 引用: 「オルヴァはどこか病的な口調で呟いた。」 / 「もとより線の細い青年である。」

### ウォレス
- 何であるか: 宮廷付き隠者。ぼろを纏い、やせ細った老人。王の助言者として中庭の小屋に暮らす。首が伸び放題の髪と髭で締め上げられ、正気を失って「絆」や「仲間」を叫び続ける状態になる。
- 関係: オルヴァの友。「ウォレス＝グレンデルヒ」とも呼ばれる。黒い本を持ち、「地位の断章」に関与する。キシャルへの襲撃を企てる。
- 引用: 「いわゆる宮廷付き隠者であるウォレスは、普段は世捨て人としてひっそりと中庭で暮らしながら、時に王の助言者としてオルヴァを支えていた。」 / 「伸び放題になった隠者の髪の毛と髭が、まるで蛇や長虫のように自ら動いて、老人の首に巻き付いたのである。」

### キシャル
- 何であるか: オルヴァの妻となる王妃。マシュラム人。打撲と裂傷で満身創痍となりながらも柔らかな微笑みを王に向ける。顔が腐り落ちるなどの異常な現象を示す。
- 関係: オルヴァの妻。「哲学的ゾンビ（しびと）」を論じる。ウォレスに「地位の断章」を所望する。「レストロオセ」と名乗る存在と関連がある。
- 引用: 「キシャルという名の王妃は、打撲と裂傷で満身創痍となりながらも柔らかな微笑みを王に向けた。」 / 「たとえば、とキシャルは顔の右半分を手で覆った。その手が降ろされると、美しい少女の顔が見るも無惨に腐り落ちていく。」

### 王宮の中にある噴水と庭木が十字に配列された美しい庭園
- 何であるか: オルヴァとウォレスが語らう場所。小さな畑が存在し、その隣に隠者の小屋がある。
- 関係: オルヴァが「心の支えを失った」後、近付かなくなる場所。後に崩壊する舞台の一つ。
- 引用: 「そこは王宮の中にある噴水と庭木が十字に配列された美しい庭園である。」 / 「畑の隣、庭園の片隅に、煌びやかな王宮内に相応しからぬ小屋が建っている。」

### 隠者の小屋
- 何であるか: 庭園の片隅にある、王宮内では相応しくないぼろぼろの小屋。ウォレスが暮らす場所。
- 関係: ウォレスの住居。後に瓦礫の下で唯一無事だった場所として現れる。
- 引用: 「畑の隣、庭園の片隅に、煌びやかな王宮内に相応しからぬ小屋が建っている。」 / 「瓦礫の下、どうしてかその一ヶ所だけが無事だった中庭の小屋から、みすぼらしい姿の老人が現れる。」

### 伸び放題になった隠者の髪の毛と髭
- 何であるか: ウォレスの首に巻き付き、締め上げる蛇や長虫のようなもの。正気を失ったウォレスの口から出てくる粘液と共に溶ける異様な軟らかさを持つ髪。
- 関係: ウォレスを拘束し、操る要因となる。オルヴァの掌にこびり付く。後にキシャルの身体に蔦のように這う。
- 引用: 「伸び放題になった隠者の髪の毛と髭が、まるで蛇や長虫のように自ら動いて、老人の首に巻き付いたのである。」 / 「手の中には、長い髪が皮膚にこびり付くようにしてびっしりと収まっていた。」

### 哲学的ゾンビ（しびと）
- 何であるか: キシャルが定義する概念。「人は絶対にわかり合えない」という決定的断絶の象徴。魂なき死人。
- 関係: キシャルがオルヴァに伝える思想の核。キシャル自身の存在を説明するための比喩として使われる。
- 引用: 「私が魂無き死人（哲学的ゾンビ）であったとしても、私が貴方様と同じ言葉を紡ぎ、同じように振る舞う限り、人と区別はつきません。」 / 「哲学的ゾンビ（しびと）というのはね、『人は絶対にわかり合えない』という決定的断絶の象徴なのです。」

### ブレイスヴァ
- 何であるか: オルヴァが言及する、この世の全てを食い尽くす存在。愛や絆をも破壊するもの。
- 関係: オルヴァの絶望と虚無感の根源にある概念。「空にブレイスヴァが」と叫ばれる。
- 引用: 「愛の誓いなどいずれブレイスヴァに食らい尽くされるものに過ぎないのだ。」 / 「永遠の絆などと言った所で、それも全てブレイスヴァによって食い尽くされて、ああ、ああ！ 空に、空にブレイスヴァが！」

### 赤毛と青い血
- 何であるか: 地面を這って人の形をとるもの。オルヴァの再構成された身体の一部となる。左腕を含む人体を形成する流体。
- 関係: オルヴァの「目障りな」左腕を構成する要素。キシャルが嫌う「内実を伴わない呪文」の現れ。
- 引用: 「血のように赤い頭髪が生きているかのように地面を這ってキシャルに近付くと、その眼前で持ち上がって人の形をとった。」 / 「赤毛と青い血によって構成されたどろどろの塊の中に、生身の左腕が混ざっていたからである。」

### 剥き出しの左腕
- 何であるか: オルヴァの身体に現れた、病的に線の細い王には不釣り合いな腕。拳は固く握られている。後に髪で完全に覆い隠される。
- 関係: キシャルが「目障りだ」と指摘する部位。オルヴァがキシャルを追いかける際の駆動力となる。
- 引用: 「ただひとつ違っていたのは、剥き出しの左腕。」 / 「それは彼の全身にまとわりつき、ついには左腕の全てを完全に覆い隠すまでになってしまっていた。」

### 地位の断章
- 何であるか: ウォレスが持つ黒い本に関連する概念。領域と空間、場面を掌握し、世界を書き換える力を持つ。
- 関係: キシャルがウォレスから所望するもの。「ヒロインの『地位』など添え物」として扱われる脚本的な要素。
- 引用: 「隠者ウォレスは手に黒い本を持っており、それを開くと何事かもごもごと呟き始めた。」 / 「『地位の断章』は領域と空間、そして場面すら掌握する。」

### テフィド＝ラーム
- 何であるか: オルヴァが戦場で食い止めねばならない憎き敵国。後世でラフディと呼ばれる。まあるいハリモグラのような存在として描かれる。
- 関係: オルヴァの戦場の相手。キシャルの不貞を疑うための口実（戦場への赴任）となる。
- 引用: 「私はこれから東部国境へ赴き、憎きテフィド＝ラームの侵攻を食い止めねばならぬ！」 / 「あの忌々しく肥え太ったまあるいハリモグラどもを墓穴に送っている間」

### 寝取られ王
- 何であるか: オルヴァが得た異名。妻の不貞を想像し狂乱する姿から人々が彼をこう呼び、恐れた。
- 関係: オルヴァの呼称。彼の恐怖と絶望の象徴。
- 引用: 「妻の名を呼び、慟哭しながら腕の一振りで千の軍勢を吹き飛ばすその姿から、人は彼を【寝取られ王】の異名で呼び、恐れたという。」

### 黒蛇
- 何であるか: 空から舞い降りる腐臭を伴う存在。カシュラム滅亡の際に人々を喰らう怪物。
- 関係: オルヴァの絶望と恐怖が引き起こした天変地異の一部。カシュラムを破壊する要因。
- 引用: 「腐臭と共に、空から黒蛇が舞い降りた。」 / 「巨大な黒蛇が人々を喰らった。」
