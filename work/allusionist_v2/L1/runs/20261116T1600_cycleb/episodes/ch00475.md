# 観察ページ ch00475__5-5　第一の誘拐②.md

### ユディーア
- 何であるか: 仮面を被った槍使い。天眼という種族的才能を持ち、戦場全域の知覚と情報収集を行う。右腕が亜竜の腕に変容し、「剥落の鉤爪」を持つ。
- 関係: クナータを救出する立場にある。仮面の男（敵）と激しい槍のぶつけ合いを演じている。灰神（パルム）たちを強引に叩き起こして時間停止能力を発動させる。
- 引用: 「天眼を研ぎ澄まし、敵の一挙一動をつぶさに捉える。」 / 「剥き出しとなった亜竜の腕には『剥落の鉤爪』。」

### 仮面の男（敵）
- 何であるか: ユディーアと対峙する槍使い。天眼の精度においてユディーアを凌駕している。魔槍「氷血のコルセスカ」を持ち、時間停止能力を持つ。
- 関係: ユディーアの敵。ユディーアの時間停止に対し、「凍レ、『氷血のコルセスカ』」と宣名して対抗する。
- 引用: 「天眼の精度という種族的才能と修練が合わさった一点において相手は自分を凌駕している。」 / 「仮面の男が魔槍の銘を開帳すると同時、時空が凍り付き、世界は静寂に包まれる。」

### クレイ
- 何であるか: 盲目の男。石化を無効化しつつ岩の槍を回避する。「死人の森の王子」と呼ばれる。左腕の手刀が折れるが、トロメリアとの連携で星々の光を集めた巨大な剣を生み出す。
- 関係: トロメリアと一心同体のパートナーシップを結んでいる。双頭トロル（ベフォニス）と戦う。「ラウスの戦槌」を持つ巨神に打ち砕かれる。
- 引用: 「相変わらずおんぶに抱っこか、トロメリアぁ！」 / 「虚空に散らばっていた全ての光がクレイに従属し、巨大な剣となって屹立した。」

### トロメリア
- 何であるか: クレイのパートナー。クレイが戦っている間に密かに相手の浄界を改竄する下準備を行う。「星読みの賢者」として王（クレイ）を支える役割を担う。虹犬の貴婦人との因縁がある。
- 関係: クレイと協力し、双頭トロルの邪視による石化空間を侵食する。クレイに「キングメーカー」のあり方について説く。
- 引用: 「トロメリアは密かに相手の浄界を改竄する下準備を済ませていた。」 / 「星読みの賢者は王たる貴種に道を示すのが役目だ。」

### 双頭トロル（ベフォニス）
- 何であるか: 邪視による石化と岩の呪術を使う呪術師。二つの心を持つが、年季と練度でクレイたちを上回る。「報復」の基本呪術で手刀を弾く。巨大な欲望から使い魔（巨人）を呼び出す。
- 関係: クレイとトロメリアの敵。旧知の間柄であるトロメリアに激しく反発する。「ベフォニス家」の当主を自称し、アルテミシアを組み込んで完璧な王を作ろうとする。
- 引用: 「岩肌の呪術師は、単騎で軍勢の如き火力を発揮していた。」 / 「黙れっ！　トロルはおらの種族だ、おらのやり方に指図すんなっ」

### 巨人（使い魔）
- 何であるか: 双頭トロルが地の底から呼び出した使い魔。ビルよりも巨大なヒト型で、全身が呪宝石の塊。「ラウスの戦槌」と呼ばれる石と木のハンマーを持つ。
- 関係: クレイの巨大な剣を「轟け、『ラウスの戦槌』」という宣名で打ち砕き、大地を陥没させる。世界槍の一部を砕くことも可能なほどの呪力を持つ。
- 引用: 「ビルよりも巨大なヒト型は、その全身の隅から隅まで余さず呪宝石の塊だった。」 / 「圧縮された神話の奔流は容易く剣を打ち砕き、真下にいたクレイごと大地を陥没させた。」

### セリアック＝ニア
- 何であるか: 猫と犬の戦闘に関わる人物（猫姫）。傘の防御で無数の犬の炸裂を受け止める。香水呪術が雨で無効化される相性の悪さにより苦戦する。呪宝石が底を尽き、敗北する。
- 関係: パピヨン虹犬の貴婦人と対峙する。「下」の種族（ジャッフハリム）への認識を持つが、貴婦人はそれを否定する。最終的に溶解した猫騎士甲冑の残骸を残して消滅する。
- 引用: 「セリアック＝ニアは『下』がイコールでジャッフハリムだと認識しているようだが、そうではないことをユディーアは知っていた。」 / 「後に残されたのは、溶解した猫騎士甲冑の残骸、そして価値を失った石ころのみ。」

### パピヨン虹犬の貴婦人
- 何であるか: 虹犬（レメス神に創造された奉仕種族）の女性。傘を武器とし、「レメスの穹弩（きゅうど）」という宣名で光の雨を撃つ。保守反動派であり、家畜としての序列化と管理を主張する。
- 関係: セリアック＝ニアの敵。ナーグストールを知っているふうだが、セリアック＝ニアは頓着しない。「レメス」への忠誠と序列を重視し、異民族を滅殺するための報復として攻撃を行う。
- 引用: 「蒼天撃ち抜け、『レメスの穹弩（きゅうど）』」 / 「我ら虹犬は生まれながらに神の飼育動物。家畜種族の在るべき規範を、この堕落した都に示しましょう。」

### ナーグストール
- 何であるか: セリアック＝ニアの腕（使い魔？）。無数の犬が球化し宝石に変換され炸裂する攻撃を行う。一撃で行動不能、止めで戦闘不能に至る打撃を持つ。
- 関係: セリアック＝ニアの防御と攻撃を担う存在。貴婦人との因縁があると言及される。
- 引用: 「無数の犬が球化し、宝石に変換され、呪力を撒き散らしながら炸裂する。」 / 「一撃で行動不能、続く止めで戦闘不能に至るナーグストールの打撃。」

### カーイン（ロウ・カーイン）
- 何であるか: 薔薇の麗人と対峙する勇士。表向き霊長類系の無徴種族だが、テテリビナの血を引く秘密を持つ。「誇り高き勇士、ロウ・カーイン」と名乗る。茨に絡め取られ戦闘不能になる。
- 関係: 薔薇の麗人（本物のカーインの子孫？）と対峙する。麗人の父が兄に名を受け継がせ、自分には鞭を授けたという過去を持つ。「正統」の存在に動揺する。
- 引用: 「私は、誇り高き勇士、ロウ・カーインだ」 / 「父上は美しく人心を惹き付ける力を持った我が兄にその名を受け継がせた。」

### 薔薇の麗人（テテリビナ）
- 何であるか: カーインと対峙する人物。茨や蔦による呪術を使う。「妖華絢爛螺衣光鞭（ビューティーウィップ）」という宣名で、頭部が赤薔薇に変容し巨大な花の姿になる。「テテリビナ」を自称する原初の妖精（アールヴ）「花のアヴロノ」の生き残り。
- 関係: カーインを騙りとして糾弾し、その存在を養分として吸収しようとする。カーインの父との因縁を持つ。プリエステラをも凌駕する樹木系呪術の使い手。
- 引用: 「咲き誇れ、『妖華絢爛螺衣光鞭（ビューティーウィップ）』！！」 / 「すなわち世界がまだずっと単純だった頃、物質界の楔を植物に選んだ原初の妖精（アールヴ）たち、『花のアヴロノ』の生き残りである。」

### 天眼
- 何であるか: ユディーアと仮面の男が持つ種族的才能。戦場全域の知覚、敵の一挙一動の把握、石化空間の侵食などに用いられる。精度の差が勝負を分ける要素となる。
- 関係: ユディーアは天眼への負荷を度外視して極限まで引き上げ、時間停止能力を発動させる
