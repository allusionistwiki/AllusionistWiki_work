# 観察ページ ch00221__3-96　それは、世界がこんなにも光に満ち溢れているから②.md

### ピッチャールー
- 何であるか: 第九魔将。古代ジャッフハリムで作られた兵器であり、多腕を持つ巨大な存在。無機質な瞳を持ち、人の物語を感知しない。
- 関係: 主人公（アズ）とメイファーラの連携によって機能停止させられる。歌姫とプリエステラの攻撃も受けている。
- 引用: 「第九魔将ピッチャールー。」 / 「機能停止してゆっくりと目を閉じる古代兵器の横を通り過ぎた。」

### 射影即興喜劇（アトリビュート）・天眼透徹（アイアゲート）
- 何であるか: 主人公が第四の金鎖を砕いて発動する技。左手が灰色に輝き、過去を視る能力と超人的な先読み・体捌きを得る。
- 関係: メイファーラの情報収集と一体化し、「遡って、フィリス！」というコマンドでピッチャールーの来歴を解析・解体する。
- 引用: 「射影即興喜劇（アトリビュート）・天眼透徹（アイアゲート）」 / 「灰色の左手から伝わってくる、膨大な情報量。過去を視る能力。」

### メイファーラ
- 何であるか: 主人公と「遡る」という類似点で繋がっている存在。情報を集め、主人公がそれを元に解体する役割を担う。
- 関係: 主人公の左手に膨大な情報を送り、「必殺技」の一部として機能する。ミルーニャのような過度な負担はかけない完璧な同調を行う。
- 引用: 「メイファーラが情報を集めて、私がそれを元に解体する。」 / 「『アズ、受け取ってっ』」

### ナト
- 何であるか: サイザクタートと戦っている人物（双子の片割れ）。遠隔誘導攻撃端末を操り、両腕を射出して鉤爪で攻撃する。
- 関係: サイザクタートの夢として存在していたが、その認識が崩壊し致命傷を与える側に回る。最終的に神働装甲が限界を迎え倒れる。
- 引用: 「左手の方向で、激しくナトとサイザクタートが戦っている。」 / 「ナトの両腕が射出され、呪力を纏った鉤爪がサイザクタートの中央の頭部を狙う。」

### サイザクタート
- 何であるか: 三つ首犬の魔将。結界を張り、朱色の靄で傷を癒す。ナトと双子として「夢」の世界に存在していた。
- 関係: ナトとの連動する自己認識が崩壊し致命傷を負う。クエスドレム（朱）に見守られながら灰となる。
- 引用: 「結界を貫通した攻撃端末が三つ首犬の全身を引き裂いていく。」 / 「『自分たちは夢の世界の住人である』という無敵の自己認識が崩壊していく。」

### クエスドレム（朱）
- 何であるか: 第四階層の掌握者、朱大公。壮年の男で朱色の長衣を纏う。亜竜ダエモデクに乗って登場し、分裂能力を持つ。
- 関係: サイザクタートの死を悼み、主人公に殺意を向ける。使い魔召喚や合成獣化を行うが、リールエルバの吸血鬼軍勢に敗れ灰となる。
- 引用: 「漆黒の亜竜の名は魔将ダエモデク。その頭部に乗っているのは朱色の長衣を纏った壮年の男、魔将クエスドレムだった。」 / 「後はこの朱のクエスドレムに任せよ――貴様ら、残らず打ち首にしてくれる！」

### クエスドレム（黒）
- 何であるか: もう一人のクエスドレム。黒い衣を纏い、黒ずんだ棍棒を持つ。ナトと戦っていたがネドラドに胸を貫かれ消滅する。
- 関係: 朱のクエスドレムとは分裂した存在。第十三魔将として言及される。
- 引用: 「そして、亜竜に乗ったクエスドレムの背後から、もう一人のクエスドレムが姿を現した。」 / 「守護の九槍第八位、ネドラドの腕がクエスドレムの胸を貫通していた。」

### ダエモデク
- 何であるか: 瘴気の翼を生やした巨大な黒々とした亜竜。クエスドレム（朱）が騎乗している。
- 関係: リーナとリールエルバが合体した「吸血雲」に吸収され、生命を奪われて消滅する。
- 引用: 「夜空から飛翔してくるのは黒々とした靄――瘴気の翼を生やした巨大な大蜥蜴だった。」 / 「弱々しい声を上げて、暗雲の中に飲み込まれていくダエモデク。」

### リーナ
- 何であるか: 三角帽子に箒の魔女。空圧を撒き散らし速度操作を行う。雲に変身する能力を持つ（空の民）。
- 関係: 主人公と呪力を同調させ「言理飛翔・十倍減速」を発動する。リールエルバと合体し吸血雲となる。
- 引用: 「【空圧】をばら撒きながら使い魔たちを次々と吹っ飛ばしていく三角帽子に箒の魔女。」 / 「リーナとリールエルバが一つになり、黒々とした巨大な暗雲になる。」

### リールエルバ
- 何であるか: 緑色の髪と赤い瞳を持つ吸血鬼。禍々しい牙を持ち、蝙蝠や霧に変身する。大量の従者（吸血鬼）を支配している。
- 関係: クエスドレムの使い魔たちを吸血衝動で支配・感染させ勝利する。リーナと合体しダエモデクを撃破する。
- 引用: 「深遠の彼方から現れたのは鮮やかな緑色の髪と禍々しい赤色の瞳を持った少女、リールエルバ。」 / 「影の世界から攻めあがった吸血鬼の軍勢はクエスドレムの軍勢を蹂躙し、感染し、支配下に置いた。」

### 射影即興喜劇（アトリビュート）・明藍飛翔（スカイストーン）
- 何であるか: 主人公が五つ目の金鎖を砕いて発動する技。左手が明るい藍色に輝き、速度と質量を操作する呪文となる。
- 関係: ナトの攻撃端末の影を巨大化・加速させ、サイザクタートを撃破する。クエスドレムの強制空間移動を質量増加で無効化する。
- 引用: 「五つ目の金鎖を砕いて、明るい藍色に輝く左手を前に出す。」 / 「速度と質量を操作する呪文がナトの攻撃端末に干渉。」

### 射影即興喜劇（アトリビュート）・真翠玉（エメラルド）
- 何であるか: 主人公が六つ目の金鎖を砕いて発動する技。枝角に鮮やかな緑色が宿る。
- 関係: リールエルバと吸血鬼の従者たちを影の世界から呼び出すトリガーとなる。
- 引用: 「六つ目の金鎖が砕け散った。枝角にプリエステラの時よりも鮮やかな緑色が宿る。」 / 「そして、共鳴する呪力が影の世界で待機していた仲間を呼んだ。」

### 射影即興喜劇（アトリビュート）・真琥珀（アンバー）
- 何であるか: 主人公が第七の金鎖を砕いて発動する技。左手に透き通るような黄色い輝きが宿る。
- 関係: リーナから受け取った呪石弾を呪宝石に変化させ、エスフェイルへの攻撃威力を強化する。
- 引用: 「第七の金鎖が砕け散った。透き通るような黄色い輝きが左手に宿り」 / 「凄まじい数の敵に対処しているエスフェイルの回避が遅れ、二重の防御障壁すら貫通して極大の威力が炸裂する。」

### ベフォニス
- 何であるか: 魔将。プリエステラやペイルを追撃し、エスフェイルを庇うために現れる。岩肌のような外見を持つ。
- 関係: 主人公の「ナーグストール」によって体内の呪宝石からセリアック＝ニアが出現し、内部から破壊され灰となる。
- 引用: 「プリエステラやペイルの追撃を振り切って、エスフェイルを助けるためにここまでやってきたベフォニスは」 / 「全身を内部から破裂させられては岩の硬度を持つ肌も意味をなさない。」
