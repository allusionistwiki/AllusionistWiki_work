# 観察ページ ch00357__4-126　王と物乞い③.md

### ルバーブ
- 何であるか: 陛下に仕える臣下であり、物語の語り手。卑しい貧民から貴族身分を得て結婚したが、その過程で人狼を迫害するなどの罪を犯したと自認している。
- 関係: 陛下（マラード）の忠臣を自称するが、内心では欲望に塗れた存在だと述べている。オルヴァとは「六王同士」であり、敵であり友でもあるとされる。トリシューラによって死体が解体され、契約の対象となる。
- 引用: 「私が操る、彼を愛する女の振りをした偽りの恋人。」 / 「第六断章、その名は【愛情】。」

### 陛下（マラード）
- 何であるか: ラフディの王。美しく、恋愛や結婚に関心を示すようになっているが、ルバーブによって結婚を遠ざけられている。
- 関係: ルバーブが仕える対象。「真の王」であり「卑しき僣主」ではないとされる存在。アレッテ・イヴニルに「マラード」と呼ばれる。
- 引用: 「誰よりも美しい王の素晴らしき統治。」 / 「あの魔女の言うとおり、マラードは本当は不器量な王でしかなかった」

### オルヴァ
- 何であるか: 賢者。十字の瞳を持ち、時間と空間の感覚が定まらない世界でルバーブと対話する。「未来転生者」と呼ばれる。
- 関係: ルバーブに結婚の欺瞞を指摘し、「六王同士」の友として別れの挨拶をする。ブレイスヴァという名を持つ（推測: 「普段のブレイスヴァの名を呼び続ける狂態」という記述から、オルヴァ＝ブレイスヴァである可能性が高い）。
- 引用: 「十字の瞳に理性を宿して、賢者オルヴァが語りかけてくる。」 / 「感謝する。ではさようならだ、未来転生者オルヴァよ」

### 結婚（男同士の儀式）
- 何であるか: ルバーブが定義する政治的・呪術的な儀式。男同士が血を交わり、家族の使い魔となること。
- 関係: 陛下が避けるべきものとして描かれる。父と父が向かい合い、球神に誓いを立てる。
- 引用: 「結婚とは男と男、父と父、家長と家長の『血の交わり』のことにございます。」 / 「裸身となって身を清めた後、互いの胸に己の血で文字を描き、杯を酌み交わす。」

### バーガンディア
- 何であるか: 始祖ディルトーワの妻。竜王国から下賜された娘。塔に閉じ込められ、最後は行方不明（死亡確定ではない）となる。
- 関係: 王宮における結婚への恐怖や呪いの象徴。その魂が怨霊として彷徨っているという噂がある。
- 引用: 「始祖ディルトーワは亜竜王アルトから娘を下賜されてラフディの王となった。」 / 「かの魔眼竜は、正確には死亡が確定してはいない。行方不明なのだ。」

### ディルトーワ
- 何であるか: ラフディの始祖王。バーガンディアを塔に閉じ込め、赤眼騎士団を処刑した非道な王。
- 関係: バーガンディアの夫。最期は墜落死であり、バーガンディアの呪いの一因とされる。
- 引用: 「美貌が翳る様が見ていられないと、ディルトーワはバーガンディアを塔の中に閉じ込めた。」 / 「新たな妃を迎えたディルトーワ王の最期が墜落死であったということも」

### 尖塔（塔）
- 何であるか: 王宮の隅に聳え立つ、王国を呪縛する忌まわしい遺物。バーガンディアが閉じ込められた場所。
- 関係: バーガンディアの幽閉場所であり、その首級が飾られた場所でもある。
- 引用: 「すると、王宮の隅にひっそりと聳え立つ尖塔が目に入った。」 / 「その首を塔の天辺に飾った。」

### 赤眼騎士団
- 何であるか: バーガンディアの護衛であり、ラフディの軍事力の要であった騎士団。
- 関係: ディルトーワによって残らず処刑された。団長はソムワムン。
- 引用: 「強き夫という自らの在り方を印象づける為、彼はバーガンディアの護衛でありラフディの軍事力の要であった『赤眼騎士団』を残らず処刑した。」

### ソムワムン
- 何であるか: 赤眼騎士団の団長。王妃解放を訴えたが、姦通の疑いで死罪となった。
- 関係: スメーキフによって拷問され精神を狂わされた。
- 引用: 「王妃の解放を訴える騎士団長ソムワムンに、残酷なディルトーワ王は王妃と姦通したという疑いをかけて死罪を言い渡した。」

### スメーキフ
- 何であるか: 忠実な処刑者。ソムワムンを拷問し、騎士たちを斬首した。後に【処刑者スメーキフ】として召喚される。
- 関係: ディルトーワの命令に従う。アレッテ・イヴニルによって呼び出される存在の一つ。
- 引用: 「忠実な処刑者スメーキフはまずソムワムンを拷問して精神を狂わせ、連座で精強なる騎士たちを斬首。」 / 「おいでなさい、【棘の王カルメダージ】、【処刑者スメーキフ】」

### 死骸人形
- 何であるか: 王妃バーガンディアの世話をするために塔に出入りしていた人形。一説では騎士の屍で作られたもの。
- 関係: 死体操りの呪術が禁忌となる遠因を作った。
- 引用: 「塔に出入りするのは身の回りの世話をする人形たちだけ。」 / 「それは王妃の為に命を落とした騎士の屍で作られた『死骸人形』であったと言われている。」

### 人狼
- 何であるか: ラフディに招かれた種族。闇の呪術（死体の操作など）を得意とするが、迫害される。
- 関係: ルバーブによって国内から姿を消させられた（離散・流浪）。シェボリズは人狼の部族長。
- 引用: 「死体の操作は皮肉にも王妃が王国に招いた人狼たちが得意とする闇の呪術であり、彼らが迫害される遠因となった。」 / 「私はエスフェイルと名付けられた子供に呪詛をかけた。」

### シェボリズ
- 何であるか: 霊王フィフウィブレスとの戦いで功績を上げた英雄。人狼の部族長。
- 関係: ルバーブによって罠にかけられ、子供のエスフェイルを救うために中原へ旅立ち、呪力を消耗して弱体化した。陛下排除の動きに関与していた可能性が示唆される。
- 引用: 「外敵である霊王フィフウィブレスとの戦いで功績を上げた英雄シェボリズ。」 / 「シェボリズは子供を救う手立てが国内には無いと知ると、より優れた呪術医を求めて中原に旅立った。」

### エスフェイル
- 何であるか: シェボリズの子。ルバーブによって死病の呪いをかけられ、肉体が腐り続ける苦しみの中にいる。
- 関係: シェボリズが呪力を注ぎ中和し続けている。シェボリズをラフディから引き離すための道具として使われた。
- 引用: 「私はエスフェイルと名付けられた子供に呪詛をかけた。」 / 「死病の呪いに冒されたエスフェイルは絶えず肉体が腐っていくという苦しみに苛まれ」

### 霊王フィフウィブレス
- 何であるか: ラフディを襲来した外敵。死霊を操る闇の呪術を使う強大な敵。
- 関係: 撃退されたが、その後の混乱で人狼の発言力が増す原因を作った。
- 引用: 「恐るべき外敵、霊王フィフウィブレスの襲来。」 / 「地の底から呼び起こされた亡霊たちは墓の下に封じ込められた」
