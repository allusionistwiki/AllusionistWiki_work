# 観察ページ ch00419__4-188　狂姫と狂犬②.md

### コルセスカ
- 何であるか: 「氷のマイク」を手にする新人アイドルであり、女神養成機関『星見の塔』に通う女神候補生。第五階層に現れ、世界を「朝」のような清々しさで染め上げる。
- 関係: トリシューラの仲間（姉妹的関係）。シナモリアキラを取り返すために戦う。「冬の魔女（フルブライト）」とも呼ばれる。カーティス＝リールエルバの対立者。
- 引用: 「氷のマイクを手にする彼女の名はコルセスカ。」 / 「私、コルセスカは女神養成機関、『星見の塔』に通う女神候補生。」

### トリシューラ
- 何であるか: コルセスカの相棒であり、緑色のカメラアイを持つ魔女。創造（クラフト）権限を持ち、照明や念写機などのセットを作る。コルセスカを「セスカ」と呼ぶ。
- 関係: コルセスカと視線を交わし、互いの存在を確認する。シナモリアキラの世話役だった。「完成品（トリシューラ）」とも呼ばれる。
- 引用: 「それを聞いたトリシューラが何かに気付く。」 / 「それウチのじゃなくて『セレスティアルゲイズ』の衣装じゃーん！」

### リールエルバ
- 何であるか: ドラトリア公国のプリンセスであり、第五階層のアイドルランキング一位。「死人の森の女王」の権限を奪い取った。カーティス一世として男装し王として振る舞う側面を持つ。
- 関係: コルセスカから「ノーライフクイーンズコーデ」を奪った敵。シナモリアキラを支配・吸血する。「狂姫」とも呼ばれる。魔竜レーレンタークを操る。
- 引用: 「突然現れたのはドラトリア公国のプリンセス、リールエルバ。」 / 「私は本来の己に立ち返っただけよ。俗人は聖域を崇め、穢れへの畏怖は神を宿す。」

### シナモリアキラ（アキラ）
- 何であるか: リールエルバの使い魔であり、かつて魔女姉妹（コルセスカとトリシューラ）に仕えていた少年。リールエルバに支配され、プロテクトが解除されている。
- 関係: コルセスカとトリシューラにとって「アキラくん」と呼ばれる存在。リールエルバに吸血され、意識を朦朧とさせている。「使い魔」。
- 引用: 「ごめんね、セスカが留守のあいだアキラくんのしつけ頑張ったけど、悪い病気うつされちゃった。」 / 「あ――コルセスカ、か――？」

### 魔竜レーレンターク（紀竜）
- 何であるか: リールエルバが操る七つの頭を持つ巨大なネズミ状の生物（竜）。豊穣と繁栄を喰らう瘴気や穢れに関係する存在。咆哮で世界を改変し、呪術を解体する。
- 関係: リールエルバの配下であり、彼女が「カーティス」として振る舞う際の乗り物でもある。コルセスカとトリシューラを攻撃する。
- 引用: 「魔竜レーレンターク。伝承によれば、豊穣と繁栄を喰らうとされている穢れや瘴気に関係する紀竜である」 / 「ネズミが鳴いた。七つの頭に七つの叫び。」

### 氷の竜
- 何であるか: コルセスカに乗って第五階層の空を舞う竜。ビルディングの屋上に着陸し、落下するコルセスカやシナモリアキラをキャッチする。
- 関係: コルセスカの移動手段および保護者。トリシューラの下に滑空してくる。
- 引用: 「第五階層の空を舞う氷の竜が肯定するように一声鳴いた。」 / 「落下するコルセスカを氷の竜がキャッチする。」

### ノーライフクイーンズコーデ
- 何であるか: コルセスカが所有していた衣装（コーデ）。リールエルバに奪われた。
- 関係: コルセスカが地下アイドルデビューして奪い返そうとしている対象。
- 引用: 「彼女は私の『ノーライフクイーンズコーデ』を奪うと、地下アイドル界のトップに立ったのです。」

### ミルキーウェイ・リユニオンコーデ
- 何であるか: コルセスカがステージで着用している衣装。「セレスティアルゲイズ」の衣装。星と瞳のイメージを散りばめた光のドレス。
- 関係: トリシューラが「ウチのじゃなくて」と指摘するもの。コルセスカのアイドルとしての装い。
- 引用: 「星と瞳のイメージを散りばめたミルキーウェイ・リユニオンコーデを身に纏ったその姿はまさしく舞台のお姫様。」

### 死人の森（ドラトリア）
- 何であるか: リールエルバの権限によって第五階層に出現した、糸杉が林立する死の森。都市を内側から食い破るように溢れ出す。
- 関係: リールエルバが「カーティス」として支配する領域。「闇の王国」。世界槍による侵食の対象。
- 引用: 「私は『死人の森（ドラトリア）』を天地双方の世界に拡大、侵食させる。」 / 「林立する死。都市の中心に、森が出現していた。」

### 世界槍
- 何であるか: 世界の穿孔と侵食を行う装置であり、ある世界観を攻撃するための兵器。義国圏と鈴国圏が保有し、現在も争いに使われている。
- 関係: リールエルバが掌握したいと願うもの。「大断絶」の際に使用された歴史的事実に関わる。
- 引用: 「世界槍はね、世界の穿孔と侵食を行う装置なの。ある世界観である世界観を攻撃するための兵器。」

### カーティス一世（カーティス）
- 何であるか: リールエルバが男装し、王として振る舞う際の人格・役名。「狂姫」の有り様を覆すもの。緑色の髪を束ね、軍装のようなモノトーンの衣装を着用する。
- 関係: リールエルバの側面（男装した姿）。シナモリアキラに吸血行為を行う主体。
- 引用: 「リールエルバはカーティス一世を名乗り王として振る舞うことで、人格の根幹とも言える『狂姫』の有り様を覆してみせた。」

### 大断絶
- 何であるか: かつて天地を引き裂いた出来事。人類の世界認識が曖昧だった時期に、言語支配者によって「空洞説」がねじ込まれた事件。
- 関係: リールエルバが語る歴史的背景。「義国圏」と「鈴国圏」の分裂の起点。
- 引用: 「かつて天地を引き裂いた『大断絶』の際、人類の世界に対する認識は非常に曖昧だった。」

### 義国圏
- 何であるか: アルセミットを中心とした槍神教国家群。地底を異界として切り離し、聖罰という名目で侵攻した勢力。
- 関係: 「大断絶」後の世界二分構造の一方。「鈴国圏」と対立する。
- 引用: 「アルセミットを中心とした槍神教国家群――義国圏。」

### 鈴国圏
- 何であるか: ジャッフハリムを中心とした反槍主義国家群。地底に放逐・上書きされた文明。
- 関係: 「大断絶」後の世界二分構造の一方。「義国圏」と対立する。
- 引用: 「ジャッフハリムを中心とした反槍主義国家群――鈴国圏。」

### アンスロピック・プリンシパル
- 何であるか: コルセスカが歌う曲（ライブパフォーマンス）。
- 関係: コルセスカのステージの演目。リールエルバによって中断される。
- 引用: 「聴いて下さい――『アンスロピック・プリンシパル』」

### 創造（クラフト）
- 何であるか: 世界や空間を改変する権限・能力。トリシューラが照明セットを作るために使用し、リールエルバが第五階層を「死人の森」に変貌させるために使用した。
- 関係: トリシューラとリールエルバが持つ力。「掌握者による大規模な『創造（クラフト）』」。
- 引用: 「トリシューラは照明や念写機などのセットを『創造（クラフト）』してください」 / 「掌握者による大規模な『創造（クラフト）』――かつてガロアンディアンであったものが、『死人の森』であり『ドラトリア』でもある闇
