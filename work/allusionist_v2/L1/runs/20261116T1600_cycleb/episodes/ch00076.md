- 関係: アキラに感謝している人物。「先生」（トリシューラ）の指示で活動している。半年前にアキラが見た「綺麗な言葉を紡ぐひと」の記憶と重ねられている。
- 引用: 「ふしぎですよねー、と首を捻るレオは殺人的に可愛らしい。」 / 「アキラさんは確かに僕を助けてくれました。だから、僕も誰かの為にできることがしたいなって思ったんです。」

- 関係: レオと会話する。トリシューラに仕えることを宣言する。キロンを倒す計画を立てる。店員さん（クレープ屋）の常連客。
- 引用: 「今の俺は、戸籍とかその他諸々が無いアウトローだ。」 / 「聖騎士キロンは、俺が倒す。」

### トリシューラ
- 何であるか: アキラの主人であり魔女。アキラを「使い魔」として扱う。セスカ（コルセスカ）との勝負に勝利を望みつつも、その生存も願っている複雑な感情を持つ。服装センスは気まぐれでシンプル。
- 関係: アキラの意思を読み取れる。「先生」と呼ばれる。キロンが追っている対象。セスカの敵手であり愛称で呼ぶ相手。
- 引用: 「トリシューラは、俺の意思を精確に察して、もう何度目になるかも分からない溜息を吐いた。」 / 「それでも、トリシューラは敵手であるコルセスカを、愛称で呼ぶのだ。」

### キロン
- 何であるか: 聖騎士。アキラにとって「最悪の相性」を持つ敵。トリシューラを追跡している。アキラが倒す対象として設定されている。
- 関係: アキラが倒そうとしている相手。トリシューラを付け狙い続けている。アキラが「強制された決断」として拒絶する存在。
- 引用: 「悪いがキロン。強制された決断なんざクソ喰らえだ。」 / 「聖騎士キロンは、俺が倒す。」

### コルセスカ（セスカ）

- 関係: トリシューラの勝負の相手。「セスカ」という愛称で呼ばれる。アキラが「どうする？」と問われる対象。
- 引用: 「ねえ、本当は私がセスカより弱くて、勝ち目が薄そうだからこっちについてくれたんでしょう？」 / 「もし私が勝ったら、アキラくんはセスカをどうするの？」

- 関係: アキラの精神的な支え（傷ついた心を癒す）。アキラが「足場」を定めたいと考える場所の一つ。キロンとの待ち合わせ場所に近接している。
- 引用: 「俺が居て欲しいと思った時に常に現れて荒んだ心を癒してくれる、まさに女神のような人である。」 / 「今日のこの時間はクレープ屋さんのお仕事なんです。お客様はよくお会いしますから、買って下さったらちょっとおまけしちゃいますよ」
