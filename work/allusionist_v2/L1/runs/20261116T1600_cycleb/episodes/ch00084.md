# 観察ページ ch00084__2-63　転生者殺し⑨.md

### アキラ
- 何であるか: 物語の視点人物（「俺」）。転生者としての特質を失い、この世界の人間になったことで言語を理解できるようになった。両腕を失い無力な状態にある。
- 関係: コルセスカに抱えられている。トリシューラから「アキラくん」と呼ばれる。キロンに殺されかけた存在。
- 引用: 「アキラ、貴方、彼の言葉が」 / 「コルセスカ、俺はいいからトリシューラを助けに行ってやってくれ」

### コルセスカ
- 何であるか: アキラを抱えている女性。「冬の魔女」とも呼ばれる。時間そのものを奪って宇宙全体を停止させる呪術を使う。
- 関係: アキラの保護者・案内人。キロンからは「冬の魔女」「きぐるみの魔女」と呼ばれ忌み嫌われている。トリシューラとは敵対関係にある（アキラを巡って）。
- 引用: 「コルセスカ。まさかこの呪術、何の代償も無しに使っているわけじゃないんだろう？」 / 「逃げられたか――まあいい。そもそも、冬の魔女と事を構える意味など無い」

### キロン
- 何であるか: 巨大な蝶の翅を持つ男。「松明の騎士団」に所属する。片目を傷つけ、涙を流しながら少年たちの幻影（人形）に語りかける狂気的な側面を持つ。
- 関係: アキラとトリシューラの敵。転生者の魂を逆に取り込んで能力を得た。サイバーカラテなどのスキルを使用する。
- 引用: 「巨大な蝶の翅をはためかせながら、キロンはふらふらと浮遊していく。」 / 「俺はただ抵抗しただけだよ。最初に転生者を倒せたのはただの偶然だった――奴は死んだ後、魂だけになって俺の肉体を奪おうとした。」

### トリシューラ
- 何であるか: 深紅の髪と翠玉の瞳を持つ美貌の少女。アンドロイド（機械の身体）でありながら鮮血を流す。「きぐるみの魔女」と呼ばれる。呪術医の針や鮮血呪を使う。
- 関係: アキラを「アキラくん」と呼び、保護・所有の対象としている。キロンと激しく戦闘する。巡槍艦ノアズアークの拠点主。
- 引用: 「現れたのは、深紅の髪を靡かせて、細い指先に無数の針を握りしめた、すらりとした細身をシンプルなブラウスとロングスカートで飾る美貌の少女。」 / 「よくも、私のものを壊してくれたな。私のアキラくんを殺したな」

### 第五階層
- 何であるか: 物語の舞台となる場所の一つ。キロンが「この階層から異獣を残らず根絶やしにして」と言及する。巡槍艦が大地を透過して出現する場所でもある。
- 関係: キロン、トリシューラ、アキラ、コルセスカが存在する空間。第四階層との狭間へ追放される起点となる。
- 引用: 「薄膜の外側に見える第五階層は、俺が灰となった直後から再び動き出す。」 / 「まずはこの階層から異獣を残らず根絶やしにして」

### 巡槍艦ノアズアーク
- 何であるか: トリシューラの拠点であり呪術医院。超巨大な船で、階層の狭間を潜行する能力を持つ。鋼鉄の船首が出現しキロンを突き上げる。
- 関係: トリシューラが所有・運用する。キロンを第四階層との狭間に追放するために使用される。
- 引用: 「巡槍艦ノアズアーク。トリシューラの拠点にして呪術医院、階層の狭間を潜行する超巨大な船。」

### 少年達（人形）
- 何であるか: キロンの周囲に現れる無垢で純粋な美貌の少年たちの立体映像。人間ではなく生者でもない。キロンが操る人形であり、武器に宿る力を利用した幻想。
- 関係: キロンの部下であると見せかけられているが、実際は死んだ仲間達（またはその幻影）である。キロンは彼らを「殺した」と罪悪感を抱いている。
- 引用: 「表示されたのは、無垢で純粋な、美貌の少年たち。」 / 「彼らは人間ではない。そして生者ですら無い。武具に重ねられた立体映像だ。」

### 針
- 何であるか: トリシューラが使用する極めて小さく細い凶器。左手首を切り裂いて流れた鮮血から生成される。キロンに対して治癒不能な軽傷を負わせる。
- 関係: トリシューラの武器。キロンの肩に突き刺さる。キロンは「弾道予報」スキルでこれを掴み取る。
- 引用: 「針。極めて小さく細い、殺傷能力などありそうもない、ただの針だ。」 / 「手に握ったメスで、左手首を勢いよく切り裂くと、そこから赤い水滴がこぼれ落ちる。」

### サイバーカラテ
- 何であるか: キロンが使用する戦闘術。機械化人体や義肢の運用を前提とし、関節や感覚器などの弱所を狙う戦術パターンを含む。
- 関係: アキラがかつて使っていたアプリ/スキルであり、キロンが転生者の魂を取り込むことでコピーした能力。トリシューラ（アンドロイド）にとって最悪の天敵となる技術。
- 引用: 「【サイバーカラテ】だと――！」 / 「サイバーカラテは機械化人体、義肢の運用を前提とした戦闘術。」

### 弾道予報
- 何であるか: キロンが習得したスキル。トリシューラが投擲する血の針を正面から全て掴み取るために使用される。
- 関係: キロンの戦闘能力の一部。「ポイントを空間制御に振り直し」という発言から、ポイント消費でスキルを管理していることが示唆される。
- 引用: 「なるほど、やはり【弾道予報】はかなり有用なスキルだな。」

### 転生者（ゼノグラシア）
- 何であるか: アキラがかつて持っていた「この世界の人間ではない」という特質・固有性。現在は失われている。トリシューラがアキラに期待していた属性でもある。
- 関係: キロンは過去に転生者を倒し、その魂を取り込んで力を得た。コルセスカはアキラが転生者としての特质を失ったことを指摘する。
- 引用: 「【転生者】としての特質、固有性が消えて、この世界で生まれた人間になってしまったから」 / 「ただ、貴方が期待する転生者（ゼノグラシア）としては、もう」

### 憑依事故
- 何であるか: 転生者が肉体を奪おうとして失敗し、逆に魂が取り込まれる現象。現在では主流の再構成タイプに比べ危険性が高く廃れている。
- 関係: キロンが転生者の力を得た経緯（背景）。アキラの記憶の奥底にある知識として登場する。
- 引用: 「憑依事故。」 / 「最初に転生者を倒せたのはただの偶然だった――奴は死んだ後、魂だけになって俺の肉体を奪おうとした。」

### 慈悲の殺人
- 何であるか: 魅了の呪術を受けた仲間を殺す行為に対する社会的な意味付け。「手向け」とされ、罪悪感に耐えるための正当化。
- 関係: キロンが少年達（幻影）を殺したと告白する背景にある概念。コルセスカが説明する。
- 引用: 「そうした殺人は慈悲であり、仲間へのせめてもの手向けであるとされる。」

### 松明の騎士団
- 何であるか: キロンが所属し、勝利を誓う組織。「人類の勝利」を目指す。
- 関係: キロンの行動原理・所属先。異端の駆逐を目的としている。
- 引用: 「人類の勝利、【松明の騎士団】の勝利。」

### 第四階層との狭間
- 何であるか: 第五階層の天井の向こう側にある空間。巡槍艦がキロンを追放するために潜行する場所。
- 関係: キロンが最終的に押し流され消滅した（と見なされる）場所。
- 引用: 「その先の第四階層との狭間に潜行すべく、空間を歪曲させ始める。」

### 強化外骨格
- 何であるか: トリシューラの戦闘力の象徴であった装備。キロンとの戦いでは見当たらず、機能を停止したまま放置されている。
- 関係: トリシューラが使用していた（と推測される）装備。アキラが「あそこから抜け出せたのか」と疑問視する対象。
- 引用: 「その戦闘力の象徴である強化外骨格は見当たらない。」
