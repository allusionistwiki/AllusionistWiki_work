# work ページ層（work 統合ページ・自由ページ層）— L2 正規化の実施場

- `chapters/<chNNNN>.md` — work 統合ページ（章ごと）: 観測名義、採用判定と
  使用した情報（引用¶）、その登場人物の関連 ch 想起リスト、照応解決（彼/彼女→实体）。
  実読バッチ（`scripts/l2_name_resolution.py`）の JSONL から生成・追記専用。
- `entities/<entity_id>.md` — 实体統合ページ: 判定履歴（ch→証拠→統合/分離/維持）、
  IdentityLink（ユディーア/キニス型の相互想起）、名義系譜、同一名 collision 情報。
- `free/<slug>.md` — 自由ページ層: 生成物が語る自由記述（仮説・考察）。追記専用、
  根拠となる章/实体ページへのリンク必須。
- `data/` — 構造化データ（narrators.json、照応解決、collision 判定）。
- 恒久: 一般呼称（俺/彼…）はここでは解決するが L2 統合には使わない。
  同一名の別人物は分離（`__S1/S2`）＋明示証拠でのみ統合。
